range 不包含終點

for 會逐一取得 range 產生的整數。range(1, 4) 從 1 開始，在 4 之前停止。迴圈內的程式同樣要縮排。

範例 · 先讀再預測
for i in range(1, 4):
    print(i)
想好結果了？展開核對
執行結果
1
2
3

range(4) 等同從 0 到 3，共四次。要印 1 到 n，終點寫 n + 1。

02 / 05

累加器記住目前總和

把 total 先設為 0。每次迴圈把新數字加進去，再存回 total。最後才輸出。

範例 · 先讀再預測
total = 0
for i in range(1, 5):
    total = total + i
print(total)
想好結果了？展開核對
執行結果
10

total += i 是同樣意思。若把 total = 0 放進迴圈，每次都歸零，無法累積；若把 print 放進迴圈，就會印出每次的中間結果。

03 / 05

在迴圈裡加上判斷

每次拿到 i 後再判斷。只有符合條件的數才累加。if 在 for 裡縮排 4 格，if 的內容再多縮排 4 格。

範例 · 先讀再預測
total = 0
for i in range(1, 7):
    if i % 2 == 0:
        total += i
print(total)
想好結果了？展開核對
執行結果
12

6 以內偶數是 2、4、6，總和 12。先用小資料手算，再比較程式結果。

04 / 05

知道幾筆，就讀幾次

有 n 筆資料時，用 range(n) 重複讀取。下方範例固定兩筆，執行後依序輸入 8、12。

範例 · 先讀再預測
total = 0
for i in range(2):
    value = int(input())
    total += value
print(total)
想好結果了？展開核對
執行結果
20

input 放在迴圈內，每次會讀新的資料。先讀 n，再重複讀 n 次，是常見格式；n 本身不是要加總的資料。

05 / 05

同時維護總和與數量

想知道總金額與筆數，就用不同變數，各自負責一件事。範例加總 1 到 4，並計算其中大於 2 的個數。

範例 · 先讀再預測
total = 0
count = 0
for i in range(1, 5):
    total += i
    if i > 2:
        count += 1
print(total)
print(count)
想好結果了？展開核對
執行結果
10
2

最後輸出的順序必須和題目相同。可以用一張表逐輪記下 i、total、count，找出自己從哪一步開始算錯。
