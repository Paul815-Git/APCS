UNIT A / E

A｜連續乾燥日

連續乾燥日和連續合格批次共享狀態結構，但乾燥的條件是雨量等於零，不能套成大於門檻。先用一句話寫出何時延長、何時重設，再實作。最後一天仍乾燥時最長片段可能在結尾，答案更新應每一步都做，才能避免只在下雨時才結算的遺漏。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
rain = [0, 0, 3]
print(rain[0] == 0, rain[2] == 0)
展開範例結果
True False

UNIT B / E

B｜借閱次數相同先比長度

統計次數的方法沒有改變，但同分優先規則新增名稱長度，再比較字母順序。把三層條件寫成排序鍵，能避免巢狀if漏掉第三層。同時確認題目計的是紀錄筆數，不是名字長度總和；名稱長度只用在同次數時決定先後，不參與頻率統計。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = {"pear": 2, "fig": 2}
def key(name):
    return (-count[name], len(name), name)
print(min(count, key=key))
展開範例結果
fig

UNIT C / E

C｜區間損壞比例

比例比較也能用整數交叉相乘，不必先算浮點小數。先把損壞標記轉成前綴計數，取得區間損壞數，再比較損壞數乘一百與百分比門檻乘長度。這裡要求嚴格超過，因此等於門檻仍輸出正常；用一半損壞搭配百分之五十檢查等號。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
broken, length, percent = 1, 2, 50
print(broken * 100 > length * percent)
展開範例結果
False

UNIT D / E

D｜一次掃描找局部高點

局部高點只比較左右鄰居，與全體最大值不同。只有同時有兩個鄰居的位置才參與，因此長度一或二時答案為零。判斷使用兩個嚴格大於，平頂不算高點；先畫一個有兩個山峰的小序列，檢查程式是否錯把全域最大值當成唯一答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 4, 2]
print(a[1] > a[0] and a[1] > a[2])
展開範例結果
True

UNIT E / E

E｜淨額可能全部為負

累計淨額允許負數後，挑最大值仍應從實際名稱開始，而不能把最佳值預設為零。零不是一定存在的候選，會讓全負資料找不到答案。先合併名稱的所有正負變化，再以淨額遞減與名稱遞增作比較；重複出現時也不能只保留最後一筆。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
totals = {"a": -5, "b": -2}
print(max(totals.values()))
展開範例結果
-2
