UNIT A / E

A｜每次減二的加總

遞迴每次減二時，奇數會到一，偶數會到零，所以基底必須同時接住兩條路徑。把零以下回傳零，再加上目前非負數，就能統一處理。觀察參數嚴格縮小是停止的證據；只寫參數等於零，卻讓奇數一路越過零，會造成無法終止。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def total(n):
    if n <= 0:
        return 0
    return n + total(n - 2)
print(total(5))
展開範例結果

UNIT B / E

B｜反向輸出在回程

若先遞迴處理下一個索引，等回來才輸出目前值，印出的順序就會反轉。基底索引等於長度時直接返回，表示沒有值可印。這題不用切片複製剩餘陣列，參數只傳索引，能更清楚看見每層共用同一份資料、但各自保留不同索引的關係。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def show(a, i):
    if i == len(a):
        return
    show(a, i + 1)
    print(a[i])
show([2, 5], 0)
展開範例結果
5
2

UNIT C / E

C｜歐幾里得的交換

最大公因數的遞迴把問題換成第二個數及餘數，直到第二個數為零。餘數比正除數小，因此參數持續縮小；回傳的是剩下那個數。輸入允許第一個數較小，也允許其中一個為零，不必自行先排序，但兩個都是零的情形由規格排除。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def gcd(a, b):
    if b == 0:
        return a
    return gcd(b, a % b)
print(gcd(18, 12))
展開範例結果
6

UNIT D / E

D｜二分切開再加總

分治加總把索引區間拆成左右兩半，各自回傳總和後相加。空區間回傳零，單元素直接回傳該值，才能讓所有分支停止。區間仍採左閉右開，中點屬於右半邊；兩半不重疊且完整覆蓋原區間，是確認沒有重複計算或遺漏元素的關鍵。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def total(a, lo, hi):
    if lo == hi:
        return 0
    if hi - lo == 1:
        return a[lo]
    mid = (lo + hi) // 2
    return total(a, lo, mid) + total(a, mid, hi)
print(total([1, 3, 5], 0, 3))
展開範例結果
9

UNIT E / E

E｜保留第一次匹配

線性遞迴搜尋每層處理一個位置，先檢查空範圍，再判斷當前值是否符合，最後才交給下一層。這個順序保證回傳第一次出現的位置，也避免先遞迴到底才意外保留最後一次。本題限制長度很小，用來檢查回傳流程，不是推薦大型資料採用深遞迴。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def find(a, t, i):
    if i == len(a):
        return -1
    if a[i] == t:
        return i
    return find(a, t, i + 1)
print(find([4, 2, 4], 4, 0))
展開範例結果
0
