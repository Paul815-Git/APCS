UNIT A / E

A｜統計四周亮燈數

四鄰格只包含上、下、左、右，不含斜角也不含自己。對每個位置套用同一組位移，先檢查新座標是否合法，再讀取格子。輸出矩陣的每一格是獨立的統計結果，因此不應把已算出的數量寫回原矩陣，否則後面會把數量當成原來的零與一。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [[1, 0], [1, 1]]
total = 0
for dr, dc in [(-1, 0), (1, 0), (0, -1), (0, 1)]:
    r, c = dr, dc
    if 0 <= r < 2 and 0 <= c < 2:
        total += grid[r][c]
print(total)
展開範例結果
1

UNIT B / E

B｜一輪訊號擴散

同步擴散表示本輪新亮起的格子，要到下一輪才能影響別人。若邊掃描邊修改原矩陣，訊號會沿掃描方向在同一輪走很多格，違反規則。建立新列時只讀grid，保留原本的1，並檢查是否存在亮燈鄰格，全部完成後才得到下一輪的狀態。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
old = [1, 0, 0]
new = old[:]
for i in range(1, len(old)):
    if old[i-1] == 1:
        new[i] = 1
print(*new)
展開範例結果
1 1 0

UNIT C / E

C｜依鄰居數重新開關

有些同步規則會關閉原本的燈，不能只把零改成一。先算原四鄰格中亮燈數，再單獨根據規則決定新值；原格是否亮不一定參與判斷。本題只在鄰居恰有兩盞燈時亮起，所以零、單一鄰居或三盞以上都要寫成零，不能沿用舊值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for count in [1, 2, 3]:
    value = 0
    if count == 2:
        value = 1
    print(value)
展開範例結果
0
1
0

UNIT D / E

D｜角落的平均只除實際格數

平均濾波若包含自己與四鄰格，角落只會有三格，單格矩陣則只有自己，不能一律除以五。每加入一個合法鄰格，同時增加總和與格數，最後以整除取向下整數。本題數值非負，結果容易手算；原資料仍須保持不變，才能保證每格使用同一輪溫度。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
values = [6, 3, 0]
print(sum(values) // len(values))
展開範例結果
3

UNIT E / E

E｜障礙格不傳遞訊號

把障礙值與訊號值分開定義，才能避免把所有非零格都當作訊號來源。此題只問本輪新增數量，可以直接統計符合條件的空地，不必保存新矩陣；原訊號與障礙都不算新增。continue會跳過目前這格的剩餘程式，進入最近一層迴圈的下一格，適合先略過非空地。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
neighbors = [-1, 0, 1]
found = False
for value in neighbors:
    if value == 1:
        found = True
print(found)
展開範例結果
True
