UNIT A / E

A｜括號序列的合法前綴

合法括號序列任一前綴的右括號數都不能超過左括號數，最後兩種數量相等。搜尋時只加入不會破壞這兩條限制的字元，可以避免產生大量必定不合法的完整字串。每次增加一個字元，長度有明確上限；這是把既有括號規則用來限制回溯分支。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def count(opened, closed, n):
    if closed == n:
        return 1
    total = 0
    if opened < n:
        total += count(opened + 1, closed, n)
    if closed < opened:
        total += count(opened, closed + 1, n)
    return total
print(count(0, 0, 3))
展開範例結果
5

UNIT B / E

B｜小資料的分組最接近

把每個物品分到甲組或乙組，可以只記甲組總和，乙組就是全部總和減甲組。兩組差距是總和減兩倍甲組和的絕對值。每物品做選或不選即可完整搜尋；本題只求最小差，不需把交換組名視為不同答案，也不需要儲存所有分法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
values = [3, 5, 7]
total = sum(values)
chosen = 8
print(abs(total - 2 * chosen))
展開範例結果
1

UNIT C / E

C｜只能順指定方向移動

搜尋方法與移動規則可以分開：BFS的距離層次不變，但鄰格集合改成題目允許的方向。只能向右或向下時，不可偷偷加入向左或向上繞路。先寫合法移動清單，再用相同的邊界與牆檢查；一格地圖起終點重合仍需要零步。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
moves = [(0, 1), (1, 0)]
x, y = 1, 2
for dx, dy in moves:
    print(x + dx, y + dy)
展開範例結果
1 3
2 2

UNIT D / E

D｜禁用節點先排除

圖上有暫停使用的節點時，不能只在輸出時略過，搜尋也不得穿越它們。加入鄰居前檢查是否禁用，便能保證所有路徑都合法。起終點本身若禁用，沒有合法路徑；這個邊界需要在初始化時處理，否則被禁用起點仍可能向外擴張。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
blocked = {2}
for neighbor in [1, 2, 3]:
    if neighbor not in blocked:
        print(neighbor)
展開範例結果
1
3

UNIT E / E

E｜由外側找可到達空地

地圖邊界的每個可走格都可以視為外界入口，一起放入搜尋後，標記的就是能通向外面的空地。最後計算未被標記的可走格，即得到封閉空地數。這把多源初始化與一般走訪結合；不需要從每個空格重跑搜尋，也不要求最短步數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = ['###', '#.#', '###']
seen = set()
inside = 0
for x in range(3):
    for y in range(3):
        if grid[x][y] == '.' and (x, y) not in seen:
            inside += 1
print(inside)
展開範例結果
1
