UNIT A / E

A｜第一個只出現一次的字

本題同時需要總次數與原本順序。只看字典中哪個鍵最小會改變題意，只在第一次遇到時決定答案又不知道它是否稍後重複。先統計完整次數，再依原字串順序找第一個符合者，兩次掃描各自負責一項資訊，方法就會清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s = "abac"
count = {}
for ch in s:
    count[ch] = count.get(ch, 0) + 1
print(count["b"])
展開範例結果
1

UNIT B / E

B｜相鄰差的同分規則

排序後最接近的一對一定能在相鄰位置找到，但相同最小差可能出現多次。題目要求值較小的一對時，遞增掃描並且只在嚴格更好時更新，就能自然保留較早的答案。值相同但來自不同位置仍可配對，所以去重會改變本題可選的候選。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = sorted([8, 2, 5])
print(a[1] - a[0], a[2] - a[1])
展開範例結果
3 3

UNIT C / E

C｜缺席名單扣除重複簽到

本題要找沒有出現的編號，不需要保存簽到次數。先建立實到者集合，再從合法全體逐一查詢，可以自然依編號順序輸出。輸入第二行即使沒有任何人也仍存在；保留這一空行的讀取規格，能避免把缺資料和空集合混為一談。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
present = set([2, 2])
missing = []
for person in range(1, 4):
    if person not in present:
        missing.append(person)
print(*missing)
展開範例結果
1 3

UNIT D / E

D｜門檻內有多少筆

查詢問的是數值是否落在範圍內，而不是某段位置的總和。資料可以先排序一次，再用上下界取得符合者的連續區間長度。若每次都重排或重新掃描，大量查詢會增加不必要工作；重複數值仍是不同資料筆數，不能先轉集合。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [2, 2, 5]
print(bisect_right(a, 2) - bisect_left(a, 2))
展開範例結果
2

UNIT E / E

E｜返回上一頁

瀏覽紀錄的返回操作會取消最近一次進入，適合用堆疊保存目前路徑。首頁是不可被移除的底層，因此合法返回的條件是長度大於一，不只是非空。這個底層保護與括號配對略有不同，讀題後要重新決定可彈出的條件，而不是直接套用模板。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
history = ["home", "news"]
if len(history) > 1:
    history.pop()
print(history[-1])
展開範例結果
home
