UNIT A / E

A｜每列循環右移

循環右移要讓每個原元素恰好出現一次，不能移動時覆蓋還沒讀取的元素。先把位移對欄數取模，再切開尾段與前段接回，就能處理大位移。位移為零時特別容易把切片正負零搞混，因此可直接使用分界欄數減位移的寫法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = [1, 2, 3]
k = 1
print(*(row[len(row)-k:] + row[:len(row)-k]))
展開範例結果
3 1 2

UNIT B / E

B｜交換兩欄

交換欄代表每一列都要交換同樣兩個位置；只交換外層兩個元素則變成交換列。Python 的同時賦值會先取得右邊兩個舊值，再一起寫回，所以不需要額外暫存變數。兩個欄號相同時應保持原樣，這也是合法操作，不應被判成錯誤輸入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = [1, 2, 3]
a, b = 0, 2
row[a], row[b] = row[b], row[a]
print(*row)
展開範例結果
3 2 1

UNIT C / E

C｜順時針旋轉長方形

旋轉後列數與欄數交換，所以方形範例不足以驗證維度是否正確。順時針旋轉的新一列來自原本一欄，由下往上讀取。先固定原欄，再讓原列反向走訪，就能直接組好每一列輸出；不用在舊矩陣中原地交換，避免尚未使用的值被覆蓋。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = [[1, 2, 3], [4, 5, 6]]
for c in range(3):
    row = []
    for r in range(1, -1, -1):
        row.append(g[r][c])
    print(*row)
展開範例結果
4 1
5 2
6 3

UNIT D / E

D｜左右鏡像是否相同

檢查左右對稱時，每列左邊的元素要與同列右邊對應位置比較，列與列之間沒有互相交換。可以直接把每列與反向副本比較，也可以只比一半。奇數欄中央格會對到自己，永遠不造成不對稱；找到一列失敗後仍須把後續輸入讀完。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = [1, 2, 1]
print(row == row[::-1])
展開範例結果
True

UNIT E / E

E｜開關燈逐步操作

翻轉表示零變一、一變零，重複兩次會回到原狀。列指令與欄指令都直接改目前矩陣，交叉格可能被翻轉多次，不能只記錄是否曾被操作。先確認每條指令指定的是哪個維度，再走另一個維度；最後統計亮燈數，能驗證所有操作是否完整套用。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = [[0, 0], [0, 0]]
for j in range(2):
    g[0][j] = 1 - g[0][j]
for i in range(2):
    g[i][1] = 1 - g[i][1]
print(*g[0])
print(*g[1])
展開範例結果
1 0
0 1
