UNIT A / E

A｜每層重新看所有未用元素

排列與組合不同，下一個值不必更大，所以每層都從所有候選重新嘗試。為避免同一數字用兩次，加入 used 標記，選前設真、回來後設假；路徑也要同時加入與彈出。兩種狀態都恢復，下一個分支才從乾淨的狀態開始。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
used = [False, False, False]
used[1] = True
for x in range(1, 3):
    if not used[x]:
        print(x)
used[1] = False
print(used[1])
展開範例結果
2
False

UNIT B / E

B｜位置權重使順序重要

如果第幾個位置會改變貢獻，選同一批數的不同排列便可能得到不同分數。遞迴參數保存目前分數，選值後加上位置乘該值，再交給下一層。分數用整數參數傳遞不需額外撤回，但 used 是共享串列，仍必須在分支結束後復原。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 5]
print(1 * a[0] + 2 * a[1])
print(1 * a[1] + 2 * a[0])
展開範例結果
12
9

UNIT C / E

C｜重複值只走一個同層分支

輸入可能有重複字元時，依位置枚舉會重複產生相同字串。先排序字元，若目前字元等於前一個而前一個尚未使用，就跳過目前位置，讓同一層只選最左可用副本。前一副本已在路徑中時則可再選，才能保留需要多個相同字元的排列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
chars = sorted('aba')
used = [False] * 3
for i in range(3):
    if i > 0 and chars[i] == chars[i - 1] and not used[i - 1]:
        continue
    print(chars[i])
展開範例結果
a
b

UNIT D / E

D｜禁止回到原位置

錯排要求每個編號都不能放在同編號位置。這是選候選時就能判斷的局部限制，遇到相同編號直接略過，不需要等整個排列完成才檢查。仍須使用 used 防止同一編號放在多個位置；位置限制與元素使用限制是兩件不同的事。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
position = 2
for number in range(1, 4):
    if number != position:
        print(number)
展開範例結果
1
3

UNIT E / E

E｜相鄰差距限制的排列

限制只涉及新值與前一個值時，加入新值前即可檢查，不合法的分支不必往下走。第一個位置沒有前一個值，要另外允許，不能任意設一個假的前值參與比較。合法性檢查只減少分支，完整路徑仍由排列的 used 狀態保證不重複使用元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
path = [1]
for x in [2, 3, 4]:
    if abs(path[-1] - x) >= 2:
        print(x)
展開範例結果
3
4
