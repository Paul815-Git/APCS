UNIT A / E

A｜十進位轉二進位

反覆除以二取得的餘數，依序是最低位、次低位，因此收集後必須反轉才是正常的二進位表示。整除後的商作為下一輪數字，直到商為零。原輸入就是零時不會進迴圈，但零仍需要一個字元表示，所以要獨立補上，不能輸出空字串。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 6
digits = []
while n > 0:
    digits.append(str(n % 2))
    n //= 2
print("".join(digits[::-1]))
展開範例結果
110

UNIT B / E

B｜由左往右讀進位數字

讀入一個新位數時，原先所有位數都往左移一位，因此目前值先乘底數，再加新位數。二進位讀110的過程是1、3、6，不必先計算每一位的次方。前導零只讓目前值維持零，之後仍照常累積，所以同一方法自然支援有前導零的輸入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
value = 0
for ch in "110":
    value = value * 2 + int(ch)
print(value)
展開範例結果
6

UNIT C / E

C｜字母表示十到十五

底數超過十時，一個位數可能大於九，因此用A到F表示十到十五。建立"0123456789ABCDEF"對照字串，以餘數作索引就能得到對應字元；逆向解析則用index找位置。這個對照只負責單一位數，整體轉換仍是上一題的除法與反轉流程。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
symbols = "0123456789ABCDEF"
print(symbols[10])
print(symbols.index("F"))
展開範例結果
A
15

UNIT D / E

D｜固定寬度與無法容納

固定寬度輸出先完成正常轉換，再比較位數。短於寬度時，在左側補零，不是右側；右補零會改變數值。長於寬度時不能截掉高位，因為那會變成另一個數字，必須按題意輸出溢位訊息。零的正常表示長度是一，仍要參與相同檢查。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
text, width = "101", 5
print("0" * (width - len(text)) + text)
展開範例結果
00101

UNIT E / E

E｜同底數加法的轉換流程

跨表示法運算可以分成解碼、運算、編碼三步。先用乘底數累加把兩個字串轉為整數，相加後再以除底數方式轉回。兩個轉換函式的方向與輸入型別不同，要用名稱表達清楚。Python支援大整數，但輸出仍必須遵守題目指定底數與大寫字母格式。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
symbols = "0123456789ABCDEF"
value = 0
for ch in "1A":
    value = value * 16 + symbols.index(ch)
print(value + 5)
展開範例結果
31
