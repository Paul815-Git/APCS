UNIT A / E

A｜邊清單轉成鄰居清單

圖用節點代表物件，用邊表示可移動關係。鄰接串列為每個節點保存一份鄰居清單；無向邊兩端都要加入，因為可以雙向移動。每個清單必須獨立建立，不能用共用內層串列。本題保證無重邊與自環，清單長度就等於節點度數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
adj = [[] for _ in range(4)]
for u, v in [(1, 2), (2, 3)]:
    adj[u].append(v)
    adj[v].append(u)
print(*adj[2])
print(len(adj[1]))
展開範例結果
1 3
1

UNIT B / E

B｜循環不應造成重複加入

一般圖可能有環，沿邊走可能回到已到過的節點，所以已發現標記仍不可少。入佇列時就標記能保證每個節點最多進入一次。輸出可達節點若要求編號排序，就在走訪完成後按編號掃標記，不能把佇列走訪順序誤當排序結果。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
seen = [False, True, False, True]
answer = []
for u in range(1, len(seen)):
    if seen[u]:
        answer.append(u)
print(*answer)
展開範例結果
1 3

UNIT C / E

C｜邊數就是最短距離

每條邊成本相同時，圖上的廣度優先搜尋和格子版本完全相同，只把鄰格迴圈換成鄰接串列。起點距離零，未發現為負一，第一次發現 v 時設為 u 的距離加一。圖不保證連通，所以搜尋完仍為負一的節點必須保留不可達意義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dist = [-1, 0, 1, -1]
u, v = 2, 3
dist[v] = dist[u] + 1
print(dist[v])
展開範例結果
2

UNIT D / E

D｜單向通道不能反向走

有向圖的邊 u 到 v 只允許由 u 移動到 v，建表時只能加入 adj[u]。搜尋本身不需要改寫，方向差異已由鄰接資料表達。若照無向圖習慣加上反向邊，程式可能把無法抵達的終點誤判為可達，測資應包含只有反向通道的情況。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
adj = [[] for _ in range(3)]
adj[1].append(2)
print(adj[1])
print(adj[2])
展開範例結果
[2]
[]

UNIT E / E

E｜最近服務站與最差距離

多源點BFS也能用在一般無向圖。先把所有服務站距離設零，擴張後每個節點得到最近服務站距離。若任何節點仍不可達，就無法用有限距離服務全圖；只有全部可達時，才取最大距離作最差服務距離，不能把負一當小數值直接忽略。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dist = [0, 2, 1, -1]
if -1 in dist:
    print('UNREACHABLE')
else:
    print(max(dist))
展開範例結果
UNREACHABLE
