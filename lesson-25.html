UNIT A / E

A｜原地排序與新串列

b=a只增加一個名稱，不複製內容。a.sort()直接改a，sorted(a)則建立新串列；兩者都能排序，但保留原順序的能力不同。本題在排序後再次輸出原資料，讓你直接檢查是否不小心改到原件。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[3,1]
b=sorted(a)
print(*a)
print(*b)
展開範例結果
3 1
1 3

UNIT B / E

B｜一維快照與後續修改

快照記住的是某個時間點的資料。對只含整數的一維串列，a[:]複製外層便足夠；之後改a的元素不會改snapshot。若使用snapshot=a，兩者會共用物件，快照就失去意義。用先修改再比較的測試證明獨立性。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[1,2]
snapshot=a[:]
a[0]=9
print(*snapshot)
print(*a)
展開範例結果
1 2
9 2

UNIT C / E

C｜每一列都要獨立建立

用[[0]*C]*R會把同一列參照重複多次，修改一格可能讓多列一起改。你可以用迴圈每次append一個新的[0]*C，這和原第12課逐行讀取的原理相同。先從全零矩陣開始，連續設定兩列同欄最容易看出共用錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g=[]
for _ in range(2):
    g.append([0]*2)
g[0][0]=7
print(*g[0])
print(*g[1])
展開範例結果
7 0
0 0

UNIT D / E

D｜複製外層不等於複製每列

二維整數矩陣g[:]只有新外層，每列仍與原件共用。需要逐列row[:]再加入新外層，才能安全修改副本。這裡格子是整數，所以複製到列就足夠；若格子還放串列，就得再分析更深一層。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[[1,2],[3,4]]
b=[]
for row in a:
    b.append(row[:])
b[0][0]=9
print(a[0][0],b[0][0])
展開範例結果
1 9

UNIT E / E

E｜保存可還原的編輯狀態

第19課的堆疊可以保存每次修改前的完整快照。UNDO彈出最近快照，直接回到上一個狀態；UNDO本身不再新增快照。這種方法容易理解但會複製整個串列，適合本題小限制，之後再學只保存反操作來節省空間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[1,2]
history=[a[:]]
a[0]=8
a=history.pop()
print(*a)
展開範例結果
1 2
