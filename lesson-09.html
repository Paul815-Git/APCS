03 / 05

測試不只跑範例

至少測一般資料、最小規模、邊界和特殊排列。以下錯誤常見：最大值設成 0、迴圈少最後一筆、滿額門檻少了等號。

先手算每組預期答案，再執行。若結果不同，逐步追蹤變數。需要除錯輸出時可以暫時加入，但交作業前移除。

範例 · 先讀再預測
nums = [-5, -2]
best = nums[0]
for v in nums:
    if v > best:
        best = v
print(best)
想好結果了？展開核對
執行結果
-2

04 / 05

資料量影響做法

走訪 n 筆資料一次，工作量通常隨 n 增加；兩層各跑 n 次則約做 n×n 次。這是理解效率的起點。只要數相鄰變化，不必讓每兩筆都互相比較。

範例 · 先讀再預測
nums = [10, 12, 11, 15]
count = 0
for i in range(1, len(nums)):
    if nums[i] > nums[i - 1]:
        count += 1
print(count)
想好結果了？展開核對
執行結果
2

比較的是 12>10、11>12、15>11，共兩次上升。從索引 1 開始，才有前一筆可比較；只有一筆時不會進入迴圈。

05 / 05

完整解題流程

先讀輸入和輸出格式，再確認資料範圍。接著手算小例子、列出步驟、寫程式、測試邊界，最後保存。下面示範用 total 與 qualified 同時整理資料。

範例 · 先讀再預測
nums = [40, 60, 90]
total = 0
qualified = 0
for score in nums:
    total += score
    if score >= 60:
        qualified += 1
print(total, qualified)
想好結果了？展開核對
執行結果
190 2

完整程式必須自備所有輸入和初始化，不能依賴上一題。Colab 用來交作業；你在 IDLE 的練習則用 .py 保存，兩邊的程式內容應一致。
