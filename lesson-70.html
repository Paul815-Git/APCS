UNIT A / E

A｜值域中的數值總和

查詢數值範圍時，先排序才能讓合法元素聚成連續片段，再用二分找到兩個位置，最後用前綴和取總和。三份資訊必須對齊同一份排序結果。重複數值應逐筆加入前綴和，負數也可加總，因為本題沒有用總和的單調性進行搜尋。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [-2, 3, 3, 8]
p = [0]
for x in a:
    p.append(p[-1] + x)
print(p[bisect_right(a, 3)] - p[bisect_left(a, -2)])
展開範例結果
4

UNIT B / E

B｜可拆工作的最低速度

給定速度後，每項工作所需時間要向上取整，因為不足一單位時間也占一單位。速度提高只會讓總時間減少或持平，所以可以二分最小可行速度。每項至少一單位時間，因此題目保證時間上限不小於項目數，才能確保解存在。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
work = [4, 7]
speed = 3
hours = 0
for x in work:
    hours += (x + speed - 1) // speed
print(hours)
展開範例結果
5

UNIT C / E

C｜兩來源最近的數值

若要從兩個來源各選一筆，不能將全部混在一起後只看相鄰，因為最接近兩筆可能來自同一來源。將兩列各自排序並比較目前兩值，更新差距後移動較小值一側；較小值留著只會遇到更大的對方值，無法改善距離。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = [1, 8], [5, 10]
i, j, best = 0, 0, 100
while i < len(a) and j < len(b):
    best = min(best, abs(a[i] - b[j]))
    if a[i] < b[j]:
        i += 1
    else:
        j += 1
print(best)
展開範例結果
2

UNIT D / E

D｜第一個超載時刻

超載是否發生可以在事件掃描後立刻判斷，但必須先合併同時刻的增減，才不會把瞬間交接誤報成超載。由於時間已排序，第一次符合條件就是最早時刻，找到後可停止。沒有任何超載時刻要輸出指定文字，不能沿用初始時間當答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
changes = {1: 2, 3: 0, 5: -2}
active = 0
for t in sorted(changes):
    active += changes[t]
    print(t, active > 2)
展開範例結果
1 False
3 False
5 False

UNIT E / E

E｜先滿足門檻再安排活動

同一題可能需要先做條件篩選，再進行排序貪心。資格分數只決定能否參加，通過後每場活動都同樣計一場，因此仍可依最早結束安排。若把分數當獎金加總，目標就改變了。先將題目的門檻與最佳化目標分開，才能選對方法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
threshold = 60
events = []
for start, end, score in [(0, 2, 59), (1, 3, 60)]:
    if score >= threshold:
        events.append((end, start))
print(events)
展開範例結果
[(3, 1)]
