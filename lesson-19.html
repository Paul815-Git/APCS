單元 B / E

退格是取消最近一個字

可把一般字元推入堆疊，遇到 # 就移除最後字元。空堆疊遇到 # 依本題規則忽略，不是錯誤。最後 join 還原文字。

範例 · 先預測，再核對
stack = []
for ch in "ab#c":
    if ch == "#":
        if stack:
            stack.pop()
    else:
        stack.append(ch)
print("".join(stack))
展開範例結果
ac

單元 C / E

左右括號的配對

遇左括號推入；遇右括號必須有左括號可彈出。掃完也必須沒有剩餘左括號。只檢查左右總數相等不夠，)( 就不合法。

範例 · 先預測，再核對
stack = []
valid = True
for ch in "(())":
    if ch == "(":
        stack.append(ch)
    elif stack:
        stack.pop()
    else:
        valid = False
        break
print(valid and not stack)
展開範例結果
True

單元 D / E

佇列：先放入先取出

collections.deque 是標準函式庫的雙端佇列。append 從右邊加入，popleft 從左邊取出。比用串列 pop(0) 更適合大量前端移除，因為不用搬移後方全部元素。

範例 · 先預測，再核對
from collections import deque
queue = deque([10, 20])
queue.append(30)
print(queue.popleft())
print(queue.popleft())
展開範例結果
10
20

單元 E / E

輪流處理直到完成

剩餘工作量為正，就放回隊尾；完成則不放回。每輪至少減少一份工作，且起始工作有限，所以最終會停止。

範例 · 先預測，再核對
from collections import deque
q = deque([[1, 2], [2, 1]])
while q:
    job, remaining = q.popleft()
    remaining -= 1
    if remaining == 0:
        print(job)
    else:
        q.append([job, remaining])
展開範例結果
2
1
