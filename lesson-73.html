UNIT A / E

A｜兩半的最大值再比較

分治把問題切成互不重疊的兩半，各自求答案，再合併。最大值的合併只要比較兩邊最大值，單一元素就是基底。使用半開區間時，中點同時是左半終點和右半起點，既不重複也不漏掉元素；空區間沒有最大值，本題因此保證非空。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def maximum(a, lo, hi):
    if hi - lo == 1:
        return a[lo]
    mid = (lo + hi) // 2
    return max(maximum(a, lo, mid), maximum(a, mid, hi))
print(maximum([-4, -2, -9], 0, 3))
展開範例結果
-2

UNIT B / E

B｜合併多項摘要資訊

子問題可以回傳不只一個數，例如一段的最小值與最大值。把左右的最小值取小、最大值取大，就得到整段摘要，再計算範圍寬度。回傳元組後用兩個變數接收，能把每個結果的意義寫清楚；不需要重複遞迴兩次分別求最小與最大。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def bounds(a, lo, hi):
    if hi - lo == 1:
        return a[lo], a[lo]
    mid = (lo + hi) // 2
    low1, high1 = bounds(a, lo, mid)
    low2, high2 = bounds(a, mid, hi)
    return min(low1, low2), max(high1, high2)
print(bounds([5, -1, 8], 0, 3))
展開範例結果
(-1, 8)

UNIT C / E

C｜遞迴只決定合併順序

合併排序的合併步驟已在第六十九課學過；現在只將「先排好左右兩半」交給遞迴。長度零或一已經有序，可以直接回傳。每層合併仍用雙指標，不能因為改成遞迴就忘記尾段。遞迴負責工作順序，正確性仍依賴兩個輸入段有序。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def split_sizes(n):
    if n <= 1:
        return [n]
    mid = n // 2
    return split_sizes(mid) + split_sizes(n - mid)
print(*split_sizes(5))
展開範例結果
1 1 1 1 1

UNIT D / E

D｜同一個子答案只算一次

計算乘方時，偶數次方可由半次方相乘，奇數再多乘一次底數。先把半次方存進區域變數，再使用兩次，才能每層只做一次子呼叫；若直接寫兩個相同呼叫，就會重複展開。本題每步取餘數控制整數大小，底數與指數都可很大。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def power(a, k, m):
    if k == 0:
        return 1 % m
    half = power(a, k // 2, m)
    result = half * half % m
    if k % 2:
        result = result * a % m
    return result
print(power(3, 5, 7))
展開範例結果
5

UNIT E / E

E｜排序時順便數跨段逆序

逆序對分成左半內、右半內與跨兩半三類，彼此不重複。合併時若右值小於左值，左半尚未取出的所有值都比它大，可一次增加剩餘個數。相等不算逆序，所以相等時先取左邊；這把第六十八課的逐次搬移，改成整批計數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
left, right_value, i = [2, 5, 8], 4, 1
print(left[i] > right_value)
print(len(left) - i)
展開範例結果
True
