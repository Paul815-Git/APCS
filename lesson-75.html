UNIT A / E

A｜下一個只能往後選

組合只看選了哪些元素，不看選取順序。讓下一個編號一定大於目前編號，就不會同時產生一二與二一兩種寫法。路徑長度等於需求數時才完成一組；各層從小到大嘗試，輸出便自然是字典順序，不需事後用集合去除重複。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def choose(start, n, k, path):
    if len(path) == k:
        print(*path)
        return
    for x in range(start, n + 1):
        path.append(x)
        choose(x + 1, n, k, path)
        path.pop()
choose(1, 3, 2, [])
展開範例結果
1 2
1 3
2 3

UNIT B / E

B｜固定數量與總和一起判斷

固定選 k 個元素時，位置、剩餘名額與目前總和各有不同意義。名額用完才檢查總和，不能只因中途總和碰到目標就結束，因為後面還必須補足數量。用原索引遞增選取，重複數值的不同位置仍會產生不同組合。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def count(a, start, left, total, target):
    if left == 0:
        return 1 if total == target else 0
    answer = 0
    for i in range(start, len(a)):
        answer += count(a, i + 1, left - 1, total + a[i], target)
    return answer
print(count([1, 2, 2, 3], 0, 2, 0, 4))
展開範例結果
2

UNIT C / E

C｜允許重複時保留目前索引

若同種類可以反覆選，下一層仍從目前種類開始，而不是從下一種開始。這會產生非遞減序列，每種數量組合只出現一次。遞迴仍會停止，因為剩餘選取數每層減一；不能只靠起始索引變大作為所有遞迴都會停止的理由。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def repeat(start, n, left, path):
    if left == 0:
        print(*path)
        return
    for x in range(start, n + 1):
        path.append(x)
        repeat(x, n, left - 1, path)
        path.pop()
repeat(1, 2, 2, [])
展開範例結果

1 2
2 2

UNIT D / E

D｜剩餘元素不足就停止

還要選的數量若多於剩下的候選數，該分支必定不可能完成，可以提前回傳零。這項剪枝不涉及數值大小，負數或重複值都不影響。先檢查需要零個的基底，再檢查不足，才能把空組合正確算成一種，而不是一律當成沒有答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def ways(start, n, left):
    if left == 0:
        return 1
    if n - start < left:
        return 0
    return ways(start + 1, n, left) + ways(start + 1, n, left - 1)
print(ways(0, 4, 2))
展開範例結果
6

UNIT E / E

E｜有最小編號間距的組合

條件是任兩個連續選定編號至少相差 d 時，選 x 後下一層可直接從 x+d 開始，省去必定違規的候選。因為路徑本來遞增，只檢查相鄰選定編號就能保證所有編號對都滿足下限。這是把題目限制轉成搜尋起點，而非完成後才大量丟棄。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def ways(start, n, left, gap):
    if left == 0:
        return 1
    total = 0
    for x in range(start, n + 1):
        total += ways(x + gap, n, left - 1, gap)
    return total
print(ways(1, 5, 2, 2))
展開範例結果
6
