UNIT A / E

A｜牆壁會阻擋移動

矩陣座標的列號向下增加，因此U的列位移是負一，D是正一。每次移動先檢查邊界，合法才檢查是不是牆壁；這個順序可避免非法索引。被牆擋住時保留原位置，下一個指令仍從原位置執行，不會把整段路線一併取消。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [".#", ".."]
r, c = 0, 0
nr, nc = r, c + 1
if 0 <= nr < 2 and 0 <= nc < 2 and grid[nr][nc] != "#":
    r, c = nr, nc
print(r, c)
展開範例結果
0 0

UNIT B / E

B｜金幣只能領一次

位置更新與格子內容更新是兩種狀態。走到有金幣的位置後，增加所得並把該格改成空地，重走才不會重複領取。字串不能直接修改單一字元，因此讀入每列時用list轉成字元串列。起點也要領取一次，因為尚未執行指令就已站在該格。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = list(".C.")
coins = 0
if row[1] == "C":
    coins += 1
    row[1] = "."
print(coins, "".join(row))
展開範例結果
1 ...

UNIT C / E

C｜環狀地圖從另一邊出現

環狀地圖不拒絕越界，而是把新列號對列數取餘數、新欄號對欄數取餘數。從第一列往上會到最後一列，從最右欄往右會回到第一欄。列數與欄數可能不同，兩個餘數不能使用同一個尺寸，單列或單欄地圖也能用同一公式處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
r, c = 2, 3
x, y = 0, 2
x = (x - 1) % r
y = (y + 1) % c
print(x, y)
展開範例結果
1 0

UNIT D / E

D｜零輪擴散保持原狀

多輪同步更新要在每一輪開始建立全新的結果矩陣，全部格子算完才把它指定回grid。若指定發生在內層，就會混用新舊資料。輪數為零時完全不執行更新迴圈，直接計算原矩陣；這個邊界能檢查程式是否誤把讀入資料後自動做一次更新。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [[1, 0]]
for turn in range(0):
    grid = [[1, 1]]
print(*grid[0])
展開範例結果
1 0

UNIT E / E

E｜移動後判定是否相遇

兩個角色同時移動時，必須先算出兩人的候選位置，再一起更新。本題只把每步結束站在同格視為相遇，途中交叉不算；起點不同，因此從第一步開始記錄。若答案是第一次相遇的步數，找到後仍可讀完資料，但不能用後面的相遇覆蓋第一次。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = 0, 2
next_a, next_b = a + 1, b - 1
a, b = next_a, next_b
print(a == b)
展開範例結果
True
