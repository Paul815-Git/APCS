UNIT A / E

A｜需要多少起始準備金

最低累積變化決定需要多少起始準備金，讓整個過程從不低於零。先假設從零開始，追蹤所有前綴的最低值，若最低為負，補上其相反數即可。最終總和可能為正仍需要準備金，因此只看結尾不夠；空變化序列不需準備金，答案自然為零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
prefix, lowest = 0, 0
for x in [-3, 5, -1]:
    prefix += x
    lowest = min(lowest, prefix)
print(-lowest)
展開範例結果
3

UNIT B / E

B｜總量最大的欄

矩陣欄加總要讓每列的第j個值累加到同一個欄位計數器，而不是每讀一列就把答案重設。所有欄總和完成後再選最大欄，同量時保留較小索引。初始化最佳欄為零號欄而不是把最佳總量設零，才能正確處理每欄都為負數的情況。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
totals = [-5, -2, -2]
best = 0
for j in range(1, len(totals)):
    if totals[j] > totals[best]:
        best = j
print(best)
展開範例結果
1

UNIT C / E

C｜最久等待的人

完成時間與等待時間不是同一個量。每人的等待是服務開始減到達，自己的服務時長不算等待；服務開始仍取目前完成時間與到達時間較大者。保存最長等待及其輸入編號，平手保留較早到達次序。中間有空檔的人等待為零，不可把空閒時間計入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
finish, arrival = 7, 4
start = max(finish, arrival)
print(start - arrival)
展開範例結果
3

UNIT D / E

D｜最後一次紀錄才有效

不是所有重複名稱都應累加。本題每次紀錄代表完整的新設定，後來一筆覆蓋前一筆；若沿用配送加總模板，就會把歷史設定全部疊在一起。先確認資料是增量還是最新狀態，再決定字典更新方式。最後輸出順序仍按名稱排序，和覆蓋規則互不衝突。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
latest = {}
latest["a"] = 3
latest["a"] = 7
print(latest["a"])
展開範例結果
7

UNIT E / E

E｜相鄰反向操作互相抵消

這題相鄰的操作若互為反向就抵消，消除後新形成的相鄰關係還可能繼續抵消。堆疊隨時保存已處理前綴的簡化結果，只比較目前指令與頂端即可。反向對由字典明確列出，不能只看字元不同就消除；例如U與R並不是反向。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
opposite = {"U":"D", "D":"U", "L":"R", "R":"L"}
print(opposite["U"] == "D")
展開範例結果
True
