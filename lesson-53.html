UNIT A / E

A｜相鄰差再累加會回到原值

差分保存目前值減前一值，第一個值則視為減零。把差分從左到右累加，相鄰正負項會抵消，便還原原序列。這種表示法沒有壓縮資料量，而是改變更新一整段時要動到的位置。先用小序列驗證還原，才能理解後續只改端點為何有效。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
difference = [3, -1, 4]
current = 0
for value in difference:
    current += value
    print(current)
展開範例結果
3
2
6

UNIT B / E

B｜整段增加只改兩個端點

對閉區間[l,r]加上v，相當於從l開始讓累積值多v，到了r+1再減回v。每次更新只改兩格，全部更新完成後再累加即可還原。若逐格更新，最壞需要n乘q工作；差分把它改成n加q，但不適合在每次更新後立刻要求任意區間總和。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
d = [0] * 5
d[1] += 3
d[3] -= 3
current = 0
for i in range(1, 4):
    current += d[i]
    print(current)
展開範例結果
3
3
0

UNIT C / E

C｜半開區間的結束位置不同

差分端點必須依區間定義決定。對半開區間[l,r)加一，在l開始，在r停止，所以減一的位置就是r，不是r+1。若把閉區間公式直接搬過來，會多涵蓋一個時段。時間格以0起算時，最後合法結束點可以等於n，但它只是停止標記，不是可輸出的時段。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
d = [0] * 5
d[1] += 1
d[3] -= 1
current = 0
for i in range(4):
    current += d[i]
    print(current)
展開範例結果
0
1
1
0

UNIT D / E

D｜原始數值與增量分開處理

資料不一定從零開始。可以先保留原串列，只用差分記錄所有更新帶來的增量，最後把累積增量加回原值。這樣不必先把原序列改成差分，兩種資訊的意義也較清楚。沒有更新時增量全為零，答案應原樣輸出，負增量也用同一套加法處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
original, changes = [8, 3], [0, -5]
for i in range(2):
    print(original[i] + changes[i])
展開範例結果
8
-2

UNIT E / E

E｜統計同時使用量達門檻的時間

若最後只問達到門檻的時段數，還原差分時就能直接統計，不必保存整份使用量。每個半開預約在開始加一、結束減一，累積值代表該時間格同時存在的預約數。相接的兩個預約不會在端點重疊，因為結束標記與開始標記會在同一格一起作用。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
loads = [1, 2, 2, 1]
count = 0
for load in loads:
    if load >= 2:
        count += 1
print(count)
展開範例結果
2
