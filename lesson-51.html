UNIT A / E

A｜區間奇數有幾個

每次查詢都掃描整個區間，最壞需要n乘q次判斷。若先把奇數轉成一、偶數轉成零，再建立前綴和，區間相減就能得到奇數數量。前綴表存的是計數而不是原數值總和；負奇數對二的餘數也不為零，所以同一條件能處理正負輸入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = [0]
for value in [3, 4, -5]:
    flag = 0
    if value % 2 != 0:
        flag = 1
    p.append(p[-1] + flag)
print(p[3] - p[1])
展開範例結果
1

UNIT B / E

B｜每筆紀錄先乘權重

加權總和可以先把每筆資料轉成「值乘權重」，再使用普通前綴和。權重屬於該筆紀錄，必須在建立前綴表時就乘好，不能查詢後把區間值總和乘權重總和，那會多算跨紀錄的乘積。資料不變且查詢很多時，這個預處理才有價值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
values, weights = [4, 7], [2, 3]
p = [0]
for i in range(2):
    p.append(p[-1] + values[i] * weights[i])
print(p[-1])
展開範例結果
29

UNIT C / E

C｜三種類別各自有一張表

一個前綴數字不能同時保留三種分類的數量，所以為每種類別分別建立一張計數表。讀到一個字元時，三張表都往前延伸，其中一張加一，其餘加零。查詢時分別相減就得到三種數量；三者總和應等於區間長度，可作為自我檢查。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [0, 1, 1, 1]
b = [0, 0, 1, 1]
c = [0, 0, 0, 1]
print(a[3]-a[1], b[3]-b[1], c[3]-c[1])
展開範例結果
0 1 1

UNIT D / E

D｜平均比較不必使用小數

區間平均是否至少為t，可以把平均式兩邊乘以正的區間長度，改成總和≥t乘長度。這樣只用整數，不會因為小數表示出現誤差。區間長度是r-l+1，單一元素時為一而不是零；資料可為負數，但長度始終正，所以不等號方向不變。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total, length, target = 9, 3, 3
print(total >= target * length)
展開範例結果
True

UNIT E / E

E｜總件數與銷售額一起查

同一區間可能需要多種統計，應各建一張前綴表，而不是查詢時重新掃描。數量前綴累加件數，金額前綴累加件數乘單價，兩者單位不同。查詢同時輸出它們可直接看出資料意義；即使某筆賣出零件，位置仍存在，不能從序列中刪去。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
quantity, price = 3, 8
print(quantity, quantity * price)
展開範例結果
3 24
