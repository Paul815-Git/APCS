UNIT A / E

A｜入度是尚有多少直接前置

有向邊 u 到 v 在本課代表 u 必須先於 v。v 的入度就是直接指向它的邊數，表示尚未處理時有多少直接先修；不是所有祖先數，也不是最短距離。初始入度零的節點可以立即開始，沒有任何邊的節點同樣符合條件，必須列入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
indegree = [0] * 4
for u, v in [(1, 3), (2, 3)]:
    indegree[v] += 1
print(*indegree[1:])
展開範例結果
0 0 2

UNIT B / E

B｜移除完成節點的影響

取出可開始的節點後，它的每個後繼就少了一個未完成先修，因此入度各減一。只有降到零時才放入佇列，不能只要某一個前置完成就加入。本題指定初始按編號、後繼按輸入順序入隊，讓多種合法拓樸順序中有固定可核對的輸出。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
indegree = [0, 0, 0, 2]
indegree[3] -= 1
print(indegree[3] == 0)
indegree[3] -= 1
print(indegree[3] == 0)
展開範例結果
False
True

UNIT C / E

C｜佇列空不代表全部完成

如果剩下的節點互相等待，便再也沒有零入度節點，佇列會提早變空。比較已處理數與總節點數，就能判斷是否存在循環。不能只檢查初始有沒有可開始節點，因為圖的一部分可能可完成，另一部分仍有環，最後才看得出處理不完整。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 5
processed = [1, 2]
print('YES' if len(processed) == n else 'NO')
展開範例結果
NO

UNIT D / E

D｜可開始者中選最小編號

若要求字典順序最小的拓樸排列，每一步都要從目前所有可開始節點選最小編號。一般佇列只能保證先加入先處理，不符合這個新條件；把可開始集合改成最小堆即可。新的可開始節點可能比已等待者更小，因此不能只將初始候選排一次序。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
ready = [2, 5]
heapq.heapify(ready)
heapq.heappush(ready, 1)
print(heapq.heappop(ready))
展開範例結果
1

UNIT E / E

E｜同一輪可並行完成

每項任務都花一輪且資源無限制時，本輪開始時已無先修的任務可以同時完成。先固定本輪佇列長度，只處理這些節點；本輪新解鎖的任務留到下一輪。若一邊加入一邊全部處理，就會把有先後依賴的任務誤算在同一輪內。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from collections import deque
queue = deque([1, 2])
this_round = len(queue)
for _ in range(this_round):
    u = queue.popleft()
    if u == 1:
        queue.append(3)
print(list(queue))
展開範例結果
[3]
