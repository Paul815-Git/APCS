UNIT A / E

A｜反覆餘數求最大公因數

若a除以b餘r，a與b的共同因數也會整除r，因此gcd(a,b)=gcd(b,r)。每次把數對換成b與a%b，第二個數會變小，直到它為零；此時第一個數就是答案。多重指定右邊先用舊值計算，能避免先改a後算出錯誤餘數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = 18, 12
while b != 0:
    a, b = b, a % b
print(a)
展開範例結果
6

UNIT B / E

B｜最小公倍數先除再乘

兩正整數的最小公倍數等於a*b除以最大公因數，因為共同的質因數在乘積裡被重複計算。程式可先算a//g再乘b，保持中間值較小。雖然Python整數可自動變大，先除後乘仍能表達整除關係，並讓轉換到其他語言時較不容易溢位。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b, g = 6, 8, 2
print(a // g * b)
展開範例結果
24

UNIT C / E

C｜整串數字的共同尺度

多個數的最大公因數可以逐個合併：目前g表示已讀資料的共同因數，再用gcd(g,x)納入下一筆。初值設零很方便，因為gcd(0,x)=x，不需要特別取第一個元素。每次合併後g都同時整除已處理的全部數字，這就是累積狀態的意義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
g = 0
for x in [12, 18, 30]:
    g = gcd(g, x)
print(g)
展開範例結果
6

UNIT D / E

D｜零的最小公倍數約定

含零時，正整數版本的公式可能發生除以零，尤其兩個輸入都為零。本題採常用程式約定，只要任一數為零就回傳零，非零時才使用gcd公式。先處理特殊值再進主公式，可以把函式的合法輸入範圍寫完整，而不是依賴測資剛好避開問題。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = 0, 0
if a == 0 or b == 0:
    print(0)
展開範例結果
0

UNIT E / E

E｜互質讀值配對

兩個正整數的最大公因數為一時稱為互質，不要求兩個數本身都是質數，例如8與9就互質。把gcd放進配對枚舉，能直接檢查每一組不同位置。數值一與任何正整數都互質，兩個一也成立；這些例子可以防止誤把互質寫成「兩個質數」。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def gcd(a, b):
    while b:
        a, b = b, a % b
    return a
print(gcd(8, 9) == 1)
print(gcd(6, 9) == 1)
展開範例結果
True
False
