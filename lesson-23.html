UNIT A / E

A｜半開區間總和

區間[l,r)包含l、不含r，因此長度是r-l。當l=r時區間為空，總和為0。沿用前綴p[i]表示前i筆總和時，0起算半開區間直接用p[r]-p[l]；不要再減l-1，否則會套到另一種座標定義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[3,5,7]
print(sum(a[1:3]))
print(sum(a[2:2]))
展開範例結果
12
0

UNIT B / E

B｜環狀索引

環狀位置離開末尾會回到開頭，用餘數把任何整數位置映射到0到n-1。向左位移可以是負數；在n為正時，Python的餘數仍位於合法範圍。先說清起點是索引還是第幾個位置，不能混用。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n=4
print((0-1)%n)
print((3+2)%n)
展開範例結果
3
1

UNIT C / E

C｜端點附近的合法鄰居

一般直線串列與環狀串列不同，首項沒有左鄰、末項沒有右鄰。Python負索引雖能讀值，卻不符合本題的鄰居定義。對每個候選位置先檢查0≤j<n，再加入總和；只有一筆時沒有任何鄰居。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[2,5,8]
i=0
for j in [i-1,i+1]:
    if 0<=j<len(a):
        print(a[j])
展開範例結果
5

UNIT D / E

D｜閉區間內的整數點

兩個閉區間相交的左端是兩個起點的較大者，右端是兩個終點的較小者。這次算整數點數，不是連續時間長度，所以合法交集要加1。若右端小於左端，交集為空，不能輸出負的點數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
left=max(1,3)
right=min(3,5)
print(max(0,right-left+1))
展開範例結果
1

UNIT E / E

E｜刪除一段字串

題目的第l到第r個字元含兩端，對應Python索引l-1到r-1。刪除後留下左側s[:l-1]與右側s[r:]，兩段接起來即可。字串不可直接刪改某格，建立新字串是自然做法。刪掉全部時仍要輸出換行。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s="abcdef"
l,r=2,4
print(s[:l-1]+s[r:])
展開範例結果
aef
