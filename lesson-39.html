UNIT A / E

A｜把最近一次加法撤回

復原可以保存相反操作，也可以保存操作之前的狀態。先練後者：每次ADD前把目前數值放進堆疊，UNDO時取出最後保存的值。堆疊空時沒有可回復的狀態，應保持不變。UNDO本身不加入歷史，否則連續復原會在兩個狀態間來回跳動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
value = 3
history = []
history.append(value)
value += 5
value = history.pop()
print(value)
展開範例結果
3

UNIT B / E

B｜文字編輯保存操作前版本

字串不可變，保存舊字串後再建立新字串，不會連帶改掉歷史版本，因此很適合練習復原。新增文字與刪尾字都是編輯，成功前都要保存舊版本；空字串上的刪除沒有產生改變，本題定義為忽略，不應占用一次可復原操作的位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
text = "ab"
history = [text]
text = text[:-1]
print(text)
print(history.pop())
展開範例結果
a
ab

UNIT C / E

C｜加入重做的第二個堆疊

復原時，把離開的目前狀態放到redo堆疊，之後就能重做。重做時則把目前狀態放回undo堆疊，兩邊互相搬移。若復原後出現新的編輯，原本的未來版本就不再是這條歷史的下一步，因此必須清空redo；單純查詢不需要清空任何歷史。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
undo, redo = [0], []
value = 7
redo.append(value)
value = undo.pop()
print(value, redo[-1])
展開範例結果
0 7

UNIT D / E

D｜失敗提款不占復原紀錄

「收到指令」與「完成操作」不是同一件事。提款失敗時沒有改變餘額，所以不能新增歷史，下一次UNDO仍應撤回前一次成功提款。檢查合法條件必須早於保存狀態。這個邊界能分辨堆疊究竟保存所有輸入事件，還是真正需要復原的狀態變化。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
balance = 4
history = []
if 7 <= balance:
    history.append(balance)
    balance -= 7
print(balance, len(history))
展開範例結果
4 0

UNIT E / E

E｜串列快照必須建立副本

若把可修改串列直接append進歷史，保存的是同一個物件，後續修改會連歷史一起改掉。對一維整數串列可用[:]建立獨立副本，再進行設定。復原時把最新快照取回作為目前串列；下一次編輯仍先複製，就能保持剩餘歷史不受影響。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 2]
history = [a[:]]
a[0] = 9
print(*history[-1])
print(*a)
展開範例結果
1 2
9 2
