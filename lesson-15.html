單元 A / E

集合只保留不同的值

set(nums) 建立集合，重複值只留一份。集合沒有串列的位置索引，不能用 s[0]。空集合用 set()，{} 是空字典。

範例 · 先預測，再核對
s = set([3, 1, 3])
print(len(s))
print(3 in s)
展開範例結果
2
True

單元 C / E

交集與聯集

a & b 取得兩邊都有的值；a | b 取得至少一邊有的值。兩種結果都不會記錄出現次數。

範例 · 先預測，再核對
a = {1, 2, 3}
b = {2, 3, 4}
print(*sorted(a & b))
print(*sorted(a | b))
展開範例結果
2 3
1 2 3 4

單元 D / E

差集有方向

a-b 保留在 a 卻不在 b 的值。a-b 與 b-a 不一定相同，讀題要先決定誰是全體、誰是已完成。

範例 · 先預測，再核對
all_ids = {1, 2, 3}
finished = {2}
print(*sorted(all_ids - finished))

單元 E / E

第一次遇到重複就停

seen 保存已看過的值。每讀到一個值，先查是否在 seen，再 add；若反過來先加，查詢就總會成立。此處 if missing 或 if seen 是判斷集合是否非空。

範例 · 先預測，再核對
seen = set()
for value in [4, 2, 4, 2]:
    if value in seen:
        print(value)
        break
    seen.add(value)
展開範例結果
4
