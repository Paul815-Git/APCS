UNIT A / E

A｜最大面額優先可能失敗

面額一、三、四要湊六時，先拿四會需要三枚，但兩個三只需兩枚，說明最大面額優先沒有普遍保證。令dp[x]為恰好湊x的最少枚數，最後一枚可逐種嘗試，取dp[x-coin]+1的最小值。面額皆為正整數，依金額遞增處理時，所依賴的小金額答案一定已算好。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
coins = [1, 3, 4]
dp = [0] + [99] * 6
for amount in range(1, 7):
    for coin in coins:
        if coin <= amount:
            dp[amount] = min(dp[amount], dp[amount - coin] + 1)
print(dp[6])
展開範例結果
2

UNIT B / E

B｜先只問能不能湊到

可行性與最少數量是兩種不同狀態。若只問某金額能否湊出，使用布林表即可：零元可行，只要存在一種硬幣使前一金額可行，目前金額就可行。硬幣可重複，所以遞增金額能接續同一面額；最後統計可行金額。sum處理布林值時，True算一、False算零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
coins = [2, 5]
reachable = [True] + [False] * 6
for x in range(1, 7):
    for coin in coins:
        if coin <= x and reachable[x - coin]:
            reachable[x] = True
print(*reachable)
展開範例結果
True False True False True True True

UNIT C / E

C｜不可達不是零枚

沒有一元硬幣時，某些金額可能無解。未達狀態要用比任何合法答案都大的值標記，不能設零，因為零枚只適用零元。正面額下，湊t元最多只需t枚才可能合法，因此t+1可當無解標記；更新前也先確認前一狀態可達，讓轉移語意清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
t = 3
infinity = t + 1
dp = [0, infinity, 1, infinity]
print(-1 if dp[t] == infinity else dp[t])
展開範例結果
-1

UNIT D / E

D｜哪些最後一枚仍能最佳

知道最少枚數後，可以檢查各面額是否可能當最佳方案的最後一枚。若前一金額可達，且其最少枚數加一等於目標答案，該面額就符合。這裡計的是不同面額選項，不是完整最佳組合數，也不把同一面額的不同實體硬幣重複計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
coins = [1, 3, 4]
dp = [0, 1, 2, 1, 1, 2, 2, 2]
options = []
for coin in coins:
    if dp[7 - coin] + 1 == dp[7]:
        options.append(coin)
print(*options)
展開範例結果
3 4

UNIT E / E

E｜保存選擇還原最佳方案

填表時除了最佳枚數，也記錄使答案改善的最後一枚。從目標反覆減去這枚硬幣，就能還原一個最佳方案。若枚數相同，本題要求最後一枚較小，先將面額排序且只在嚴格改善時更新即可。零元不需要硬幣，應輸出零枚與一個空行。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
chosen = [0, 1, 1, 3, 4, 1, 3]
amount, answer = 6, []
while amount > 0:
    coin = chosen[amount]
    answer.append(coin)
    amount -= coin
print(*answer)
展開範例結果
3 3
