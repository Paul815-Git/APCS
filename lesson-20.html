單元 C / E

挑戰：重複查詢該預先算什麼

本題問的是位置區間內的總額，不是數值落在哪個範圍。先看清楚查詢意義，再選前綴和或二分搜尋。除了總和，輸出格式也要核對。

COLAB 練習 C

挑戰：重複查詢該預先算什麼：自己做一次

第一行 n q（1–10000），第二行 n 個非負整數支出（0–100000）。接著 q 行 l r budget（1≤l≤r≤n，budget≥0），輸出該區間總支出及是否在預算內：總額≤budget 輸出 OK，否則 OVER。每筆輸出一行「總額 狀態」。

完成標準：程式能處理題目允許的資料，輸出格式正確；完成下面測試，再自選一組資料驗證，不直接印固定答案。

單元 D / E

挑戰：找最接近目標的值

在排序資料的下界附近，最接近目標者只可能是下界位置或其前一個位置。注意下界為 0 或 n 時，其中一側不存在。abs(x) 取得絕對值。

COLAB 練習 D

挑戰：找最接近目標的值：自己做一次

完成標準：程式能處理題目允許的資料，輸出格式正確；完成下面測試，再自選一組資料驗證，不直接印固定答案。
