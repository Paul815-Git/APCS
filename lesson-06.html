01 / 05

條件成立就繼續

for 適合已知次數；while 在每次執行前檢查條件。範例由 3 倒數到 1，每輪都讓 n 減少。

範例 · 先讀再預測
n = 3
while n > 0:
    print(n)
    n -= 1
想好結果了？展開核對
執行結果
3
2
1

先找出三件事：初始值、繼續條件、更新方式。漏掉 n -= 1，n 永遠是 3，就不會結束。在 Colab 可按執行區的停止按鈕中止。

02 / 05

不知道筆數的輸入

資料以特殊值結束時，不必先知道筆數。下例依序輸入 5、8、-1；-1 只當結束記號，不加入總和。

範例 · 先讀再預測
total = 0
value = int(input())
while value != -1:
    total += value
    value = int(input())
print(total)
想好結果了？展開核對
執行結果
13

迴圈前先讀第一筆，迴圈尾再讀下一筆。如果忘了讀下一筆，就會一直用同一筆值。測試「第一筆就是結束記號」。

03 / 05

break 立即離開迴圈

while True 本身不會因條件變假而停止，要明確安排 break。下方輸入 1 到 3 之間的整數才結束；例如先輸入 8，再輸入 2。

範例 · 先讀再預測
while True:
    choice = int(input())
    if choice >= 1 and choice <= 3:
        break
print(choice)
想好結果了？展開核對
執行結果
2

break 只離開它所在的那一層迴圈。這種輸入練習需保證最後會提供可結束的值，不要把 break 寫在永遠到不了的分支。

04 / 05

每一步改變剩餘量

每次拿掉相同數量，直到剩餘量不再大於 0，也可以用 while 模擬。以下每天讀 4 頁，要讀完 10 頁需 3 天。

範例 · 先讀再預測
remaining = 10
days = 0
while remaining > 0:
    remaining -= 4
    days += 1
print(days)
想好結果了？展開核對
執行結果
3

最後一天即使不到 4 頁，也算一天。更新後剩餘量可以為負，條件就會停止；不需強迫剛好等於 0。

05 / 05

逐位拆開整數

非負整數的個位數是 n % 10；n // 10 可以去掉個位數。重複這兩步即可逐位處理。

範例 · 先讀再預測
n = 352
total = 0
while n > 0:
    total += n % 10
    n //= 10
print(total)
想好結果了？展開核對
執行結果
10

352 → 35 → 3 → 0，取出的數字依序是 2、5、3。這裡會改變 n；若後面還需要原數字，先用另一個變數保存。
