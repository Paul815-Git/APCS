UNIT A / E

A｜視窗移動只換兩端

相鄰兩個長度k的區間共享k-1筆資料，不需要每次重新加總。先算前k筆，往右移一格時減去離開的a[right-k]，再加進a[right]。總和始終代表目前視窗，是每步應維持的不變量；第一個視窗在迴圈前就要輸出，否則會少掉起點零的結果。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, k = [2, 5, 1], 2
total = sum(a[:k])
print(total)
total += a[2] - a[0]
print(total)
展開範例結果
7
6

UNIT B / E

B｜最大總和及最早起點

固定視窗的總和即使含負數也能滾動更新，因為移出加入是精確代數，不依賴數值正負。最佳值先設為第一窗，之後只有嚴格更大才更新，便保留平手時最早的起點。索引right代表右端，新視窗左端是right-k+1，輸出若從一開始還要再加一。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
right, k = 4, 3
print(right-k+1)
print(right-k+2)
展開範例結果
2
3

UNIT C / E

C｜低於門檻的固定時段

視窗的移動方式與想統計的答案可以分開。維持目前總和後，只要檢查是否符合門檻，再累加符合的視窗數。每個起點算一個視窗，即使它和其他視窗大量重疊仍分別計數。不要把符合的資料筆數與符合的區間數混在一起，兩者輸出意義不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
sums, threshold = [5, 3, 7], 5
count = 0
for total in sums:
    if total <= threshold:
        count += 1
print(count)
展開範例結果
2

UNIT D / E

D｜環狀視窗恰有n個起點

環狀序列允許視窗跨過尾端回到開頭，因此合法起點恰好有n個。新加入元素的索引可對n取餘數，不一定要複製整份串列。限制k≤n可保證一個視窗不重複使用同一位置；k=n時每個起點總和都一樣，但仍只需比較n個候選。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [4, 1, 7]
start, k = 2, 2
print(a[start] + a[(start+1) % len(a)])
展開範例結果
11

UNIT E / E

E｜讓一段全部通過要改幾筆

固定視窗可以維護計數而非數值和。把不合格標記0轉成需要修改的一次成本，某個視窗內零的數量就是讓整段通過的修改次數。找成本最小的窗時，移出零就減一、加入零就加一，與普通滾動總和同理。這比真的修改每個候選字串更有效率。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s = "1010"
bad = 0
for ch in s[:3]:
    if ch == "0":
        bad += 1
print(bad)
展開範例結果
1
