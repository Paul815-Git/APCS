01 / 05

字串也是一串資料

字串可以用 len() 取得長度，用索引取得某個字元。索引從 0 開始，最後一個位置是長度減 1。以下先用英文字母說明。

範例 · 先讀再預測
word = "python"
print(len(word))
print(word[0])
print(word[5])
想好結果了？展開核對
執行結果
6
p
n

長度為 6，卻沒有 word[6]，超出範圍會出現 IndexError。空字串不能取第一個字元。本課題目會明確說明字串是否為空。

02 / 05

for 也能逐字讀取

不一定要自己計算索引；for ch in word 可以依序取得每一個字元。用 if 選出要計數的字元。

範例 · 先讀再預測
word = "banana"
count = 0
for ch in word:
    if ch == "a":
        count += 1
print(count)
想好結果了？展開核對
執行結果
3

大小寫不同：A 不等於 a。計數的變數放在迴圈外初始化，做法和前面的成績計數相同。

03 / 05

串列與 split

串列用中括號存放多筆資料。split() 依空白切開字串，得到文字的串列；再用迴圈搭配 int()，建立整數串列。範例輸入一行 8 3 10。

範例 · 先讀再預測
parts = input().split()
nums = []
for part in parts:
    nums.append(int(part))
print(nums)
print(nums[0])
想好結果了？展開核對
執行結果
[8, 3, 10]
8

[] 建立空串列，append() 把新資料加到最後。"10" 是文字，10 才是整數；轉好型別才能進行數字運算。

04 / 05

最大值從第一筆開始

找最大值時，先假設第一筆最大，逐一比較並更新。若資料可能都是負數，不能擅自以 0 當最大值。

範例 · 先讀再預測
nums = [-8, -3, -10]
best = nums[0]
for value in nums:
    if value > best:
        best = value
print(best)
想好結果了？展開核對
執行結果
-3

這種方法需要至少一筆資料。每次迴圈結束時，best 都是「目前看過」的最大值。這是逐步維護答案的方法。

05 / 05

先求總和，再走訪一次

某些問題要先看完整批資料才能判斷每一筆。例如先算平均，再數出超過平均的人數。可用 value × 人數 > 總和 避免小數比較。

範例 · 先讀再預測
nums = [10, 20, 30]
total = 0
for v in nums:
    total += v
count = 0
for v in nums:
    if v * len(nums) > total:
        count += 1
print(count)
想好結果了？展開核對
執行結果
1

第一輪取得總和，第二輪判斷每筆；不需要巢狀迴圈。剛好等於平均不算「超過」。
