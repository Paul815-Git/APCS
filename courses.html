LESSON 02 · 完成第 1 課後 · 約 40–50 分鐘

讓 Python 幫你算

認識四則運算、括號與變數，觀察 Colab 執行順序，完成點心購物單。

  • 先猜算式結果，再執行核對。
  • 使用變數記住單價和數量。
  • 修改程式後重新執行，理解值何時更新。
  • 獨立計算兩種商品的總價與找零。

完成後怎麼交作業？

  1. 保存自己的副本

    在 Colab 選「檔案 → 在雲端硬碟中儲存副本」，改名為「第2課_暱稱」。

  2. 保留程式與結果

    完成每個練習與文字紀錄，確認變更已保存。

  3. 分享給老師

    點「共用／分享」，加入老師帳號並設定檢視權限，再交出自己的副本連結。不要交原始教材網址。

Colab 找不到教材時

先下載本頁的筆記本，再到 Colab 選「檔案 → 上傳筆記本」。教師須先將本次檔案上傳到 GitHub 的 main 分支最外層，直達連結才會生效。
