UNIT A / E

A｜相近數值的位置配對

選兩個不同位置時令i小於j，就能保證不選自己，也不把顛倒順序算第二次。條件只看數值差，但答案計算的是位置配對；兩個相同數值在不同位置仍可配對。先列出全部位置，再用abs判斷差距，對小資料是最容易檢查是否漏算的方法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 2, 5]
for i in range(len(a)):
    for j in range(i+1, len(a)):
        if abs(a[i] - a[j]) <= 1:
            print(i, j)
展開範例結果
0 1

UNIT B / E

B｜矩形邊長不重複枚舉

若長寬交換視為同一矩形，就約定短邊a不超過長邊b，讓b從a開始。這裡a等於b的正方形合法，與選兩個不同位置時使用i小於j不同。先確定題意允不允許兩個值相等，再選迴圈起點，不能把所有無序問題都寫成嚴格小於。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for a in range(1, 4):
    for b in range(a, 4):
        if a * b == 6:
            print(a, b)
展開範例結果
2 3

UNIT C / E

C｜兩場活動能否相接

活動使用開始包含、結束不包含的區間，因此一場剛結束、另一場立刻開始仍不衝突。兩場不重疊有兩種順序：第一場先結束，或第二場先結束，條件要用or連接。輸入不保證排序，不能只檢查一個時間方向，否則會漏掉較晚讀入但較早開始的活動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s1, e1 = 5, 8
s2, e2 = 1, 5
print(e1 <= s2 or e2 <= s1)
展開範例結果
True

UNIT D / E

D｜沒有合法配對時怎麼表示

尋找最佳配對時，答案初值不能假裝某一組一定合法。本題用best=-1表示尚未找到，因為合法價格總和皆非負，負一不會與真正答案混淆。每次只更新不超過預算的總和；只有一件商品或所有組合超支時，保留負一正好符合無解輸出。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
best = -1
for total in [9, 12]:
    if total <= 10:
        best = max(best, total)
print(best)
展開範例結果
9

UNIT E / E

E｜最接近的兩個讀值與平手

完整最佳化規格除了目標值，也要處理平手。本題按照i再j的順序枚舉，若差距相同就不更新，最先找到的配對自然是索引字典序最小。這個技巧依賴枚舉順序已符合平手優先順序；若換了迴圈順序，就需要明確比較索引，不能盲目保留第一組。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
best = 3
new_gap = 3
if new_gap < best:
    best = new_gap
print(best)
展開範例結果
3
