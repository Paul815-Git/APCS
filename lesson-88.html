UNIT A / E

A｜正序讓同一種類繼續使用

完全背包每種類可以無限取用，與每件一次的限制不同。容量由小到大更新時，來源可能已使用過目前種類，這次再加一件正好符合題意。重量必須為正，否則不會往較小狀態推進；先用可達性觀察正序與倒序的差別，再處理價值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
reachable = [True] + [False] * 6
weight = 2
for used in range(weight, 7):
    if reachable[used - weight]:
        reachable[used] = True
print(*reachable)
展開範例結果
True False True False True False True

UNIT B / E

B｜可重複取用的最大價值

容量不超過上限的最大價值，初始每個容量都能以空選取得零。對某種類正序更新dp[c]，讓同一種類反覆接到已更新的較小容量結果。這與0/1背包只差迴圈方向，卻改變物品可用次數；驗證時應用一種物品且容量容得下兩件的例子。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dp = [0] * 5
for c in range(2, 5):
    dp[c] = max(dp[c], dp[c - 2] + 5)
print(*dp)
展開範例結果
0 0 5 5 10

UNIT C / E

C｜面額外層計算不分順序組合

若只看每種硬幣各用幾枚，面額處理順序固定，便不會把先一後二與先二後一算成兩組。面額放外層、金額正序，每格增加使用目前面額後的組合數。零元有一種空組合；面額必須互異，否則相同種類會被重複當成不同選擇。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
ways = [1, 0, 0, 0]
for coin in [1, 2]:
    for amount in range(coin, 4):
        ways[amount] += ways[amount - coin]
print(ways[3])
展開範例結果
2

UNIT D / E

D｜金額外層計算有順序序列

若拿取順序也算不同，每個金額的最後一枚可以是任一面額，因此應把金額放外層、面額放內層。這會把不同最後一枚的序列分開累加。與上一題只有迴圈次序不同，答案意義已改變；必須先寫狀態定義，不能為了方便任意交換兩層迴圈。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
ways = [1, 0, 0, 0]
for amount in range(1, 4):
    for coin in [1, 2]:
        if coin <= amount:
            ways[amount] += ways[amount - coin]
print(ways[3])
展開範例結果
3

UNIT E / E

E｜同價值時保留更多容量

若要求價值最大且平手時總重量最小，容量上限表只存價值會看不出實際用了多少重量。改存「恰好重量」的最大價值，無法湊出的重量用None標記，最後從小重量往上挑嚴格更好的價值。空集合價值零且重量零，也參與平手比較。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
values = [0, None, 5, 5, 10]
best_value, best_weight = 0, 0
for weight in range(len(values)):
    if values[weight] is not None and values[weight] > best_value:
        best_value, best_weight = values[weight], weight
print(best_value, best_weight)
展開範例結果
10 4
