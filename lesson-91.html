UNIT A / E

A｜商與餘數的方向

整數除法向負無限大取整，不是直接刪掉小數。除數為正時，餘數會落在零到除數減一之間，而且原數等於商乘除數再加餘數。把這個等式當檢查工具，比背負數範例可靠；先手算跨過零的情形，再測整除情形。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = -7, 3
print(a // b, a % b)
展開範例結果
-3 2

UNIT B / E

B｜短路保護分母

and 從左向右判斷，左邊已經是假時就不算右邊。這能讓非零檢查保護後面的取餘數，但交換兩個條件就失去保護。練習時分別追蹤分母為零、恰可整除及不能整除的三條路徑，確認每條路徑都有輸出。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
d = 0
print(d != 0 and 12 % d == 0)
展開範例結果
False

UNIT C / E

C｜索引前的兩道門

Python 的負索引合法，因此只檢查索引小於長度仍不夠。本題把位置合法與數值條件接在同一條短路判斷中；只有前兩個範圍條件成立才讀取元素。對照第一格、長度位置及負一位置，才能檢查上下兩端是否都受保護。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [6, 9]
i = -1
print(0 <= i < len(a) and a[i] == 9)
展開範例結果
False

UNIT D / E

D｜複合資格要加括號

and 的優先順序高於 or，但正式作答仍可用括號清楚標示兩種通過方式。先把題意拆成兩條完整規則，再把每條規則的必要條件接起來。測試不能只用兩條都成立的資料，還要分別讓其中一條單獨成立，避免寫成全部都要滿足。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
score, volunteer = 70, 1
print(score >= 80 or (score >= 60 and volunteer == 1))
展開範例結果
True

UNIT E / E

E｜連續條件統計

範圍條件和整除條件可以一起使用，但每個數值只能被計入一次。先確認閉區間包含兩端，再在範圍內篩選倍數。這裡除數保證為正，所以不需要額外處理除零；讀清楚輸入保證，可以讓程式保留真正需要的判斷並減少分支。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
x = 6
print(2 <= x <= 6 and x % 3 == 0)
展開範例結果
