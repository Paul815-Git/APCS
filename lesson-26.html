UNIT A / E

A｜enumerate提供位置和值

enumerate(a,1)每次給出一對編號與值，編號從1起，但不改a本身索引。它可取代先跑range再取a[i]的寫法。題目要求所有符合位置，不能只保存最後一個；沒有符合者要依規格輸出NONE。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for i,x in enumerate([40,80,60],1):
    if x>=60:
        print(i)
展開範例結果
2
3

UNIT B / E

B｜zip配對相同位置

zip(a,b)每次拿兩個序列相同位置的值。本題保證長度相同，因此每個位置都能被處理；若長度不同，zip預設只跑到較短者，不能自行假設資料完整。此處配對順序表示同一人的前後成績，不能先各自排序再比。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for before,after in zip([60,90],[70,80]):
    print(after-before)
展開範例結果
10
-10

UNIT C / E

C｜欄位一起存，才不會配錯

把姓名與分數存成一筆tuple，排序會整筆一起移動。若只排序分數串列再配原姓名，就會把人與成績錯配。排序鍵(-分數,姓名)先處理分數遞減，只有同分才按姓名；具名函式能把每個欄位的意義寫清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
records=[("Bob",80),("Amy",90)]
def key(row):
    return (-row[1],row[0])
for name,score in sorted(records,key=key):
    print(name,score)
展開範例結果
Amy 90
Bob 80

UNIT D / E

D｜同優先權保留輸入順序

並不是每道題同分都按姓名。本題相同優先權要先來先處理，可以明確保存輸入編號，排序鍵為(優先權,編號)。數值小代表優先的規則是本題約定，不是所有系統通用。先寫出比較方向再決定是否加負號。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
records=[(2,0,"b"),(1,1,"a"),(2,2,"c")]
for priority,index,name in sorted(records):
    print(name)
展開範例結果
a
b
c

UNIT E / E

E｜先彙整，再取排行榜前段

同一人的多次紀錄先累加成總分，再依總分排唯一名次。先排序原始紀錄會讓同一人占多個位置。輸入k可能超過不同姓名數，Python切片[:k]自然取全部，不需要製造不存在的人。這題整合字典、排序鍵與切片。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
d={"a":5,"b":8,"c":5}
def key(name):
    return (-d[name],name)
print(*sorted(d,key=key)[:2])
展開範例結果
b a
