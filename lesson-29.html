UNIT A / E

A｜連勝獎勵的更新順序

本題每次勝利得到目前連勝次數的分數，所以要先增加連勝，再加到總分。失敗只清除連勝，不取消已得總分。cur代表這次事件結束後的連勝次數，total代表全部事件累積分數，兩者不能混成同一個變數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
cur=total=0
for ch in "WWLW":
    if ch=="W":
        cur+=1
        total+=cur
    else:
        cur=0
print(total,cur)
展開範例結果
4 1

UNIT B / E

B｜有容量限制的停車場

狀態是目前車數，合法範圍為0到容量。IN滿場、OUT空場都是被拒絕的指令，不能把車數推到範圍外。每次完成後檢查不變量0≤cars≤capacity，就能快速發現先更新後判斷的錯誤。峰值還要與目前車數分開保存。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
capacity=2
cars=1
if cars<capacity:
    cars+=1
print(cars)
展開範例結果
2

UNIT C / E

C｜統一時間單位

同時追蹤分鐘進位與小時進位容易漏掉跨多日。先把起始時刻轉成分鐘，再加經過時間，最後以整除和餘數拆回日、時、分。一天1440分鐘；本題由第0天開始，恰好跨日00:00就是第1天。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total=23*60+50+20
day=total//1440
remaining=total%1440
print(day,remaining//60,remaining%60)
展開範例結果
1 0 10

UNIT D / E

D｜同步讀舊值、寫新值

同時更新代表全部格子只讀上一輪的值。若直接由左到右改原陣列，後面會讀到剛改的新值，變成另一種規則。本題只把每格換成左鄰，建立next_a再整輪替換就能避免混用；首格左鄰是末格，n=1也成立。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[1,2,3]
b=[]
for i in range(len(a)):
    b.append(a[(i-1)%len(a)])
print(*b)
展開範例結果
3 1 2

UNIT E / E

E｜先驗證候選，再改位置

機器人移動時先計算候選位置，合法才更新正式位置。無效指令依本題規則忽略，但仍計入拒絕次數。你可以在每一步後確認位置始終位於0到n-1，這比只看最後位置更容易找出錯誤。下一階段會將此模型擴展到二維。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n,pos=3,0
next_pos=pos-1
if 0<=next_pos<n:
    pos=next_pos
print(pos)
展開範例結果
0
