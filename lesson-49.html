UNIT A / E

A｜遮罩代表選了哪些位置

n個位置各有選或不選兩種狀態，一個n位遮罩就能表示一個子集合。第i位為一代表選第i個元素，與元素的數值大小無關。相同數值若在不同位置，仍由不同位元控制。遮罩零表示空集合，沒有任何位被選中，輸出時仍要遵守題目指定空行格式。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, mask = [7, 7, 9], 5
chosen = []
for i in range(len(a)):
    if (mask & (1 << i)) != 0:
        chosen.append(a[i])
print(*chosen)
展開範例結果
7 9

UNIT B / E

B｜枚舉所有集合的總和

所有n位遮罩恰好是零到2^n-1，所以range(1<<n)能逐一列出所有子集合，不會漏掉空集合。每個遮罩都要重新計算總和，避免把前一集合的數字帶進來。時間約為n乘2^n，成長很快，這題限制n≤18，不能直接套到幾萬筆資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for mask in range(1 << 2):
    total = 0
    for i in range(2):
        if (mask & (1 << i)) != 0:
            total += [2, 5][i]
    print(total)
展開範例結果
0
2
5
7

UNIT C / E

C｜同時限制選取個數

只有總和不能表達「恰好選k件」，還需要另一個計數器記錄選中幾個位置。每遇一個一位，同時增加數量與總和，最後兩個條件都成立才算答案。數值為零仍是一件，不能從總和推測選取數量；多個相同值也仍然代表不同位置的選擇。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
mask, size = 5, 0
for i in range(3):
    if (mask & (1 << i)) != 0:
        size += 1
print(size)
展開範例結果
2

UNIT D / E

D｜必須選取時不能讓空集合獲勝

最大和問題若允許空集合，全負數的最佳值會是零；若要求至少選一個，就必須排除遮罩零。答案也不能初始化為零，否則負數答案永遠無法更新。以第一個元素作為合法初值，再枚舉所有非空集合，可以確保最終答案確實來自題目允許的選擇。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
best = -5
for total in [-5, -2, -7]:
    best = max(best, total)
print(best)
展開範例結果
-2

UNIT E / E

E｜小規模預算選品

每件商品有價格與價值，總價格是合法性條件，總價值才是最佳化目標，兩者不能混在一個總和。逐遮罩累加兩項，只有未超過預算才更新最佳價值。空集合價格與價值都為零，題目允許不買時可作初始答案；這是完整枚舉的小資料基準解。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
cost, value = 0, 0
for item in [[3, 8], [2, 4]]:
    cost += item[0]
    value += item[1]
print(cost, value)
展開範例結果
5 12
