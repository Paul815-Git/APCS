讓電腦顯示一句話

程式是交給電腦的指令。print() 的工作是顯示內容。

把想顯示的文字放進引號，再用括號包起來。先看看範例，猜猜結果會不會包含引號。

範例 · 先讀再預測
print("你好")
想好結果了？展開核對
執行結果
你好

print 是指令；引號標記文字的範圍，不會跟著顯示出來。你可以把「你好」換成暱稱，保留其他符號。

使用英文半形 "、(、)，不要換成彎引號 “ ” 或全形括號 （ ）。

一行一個 print

想顯示兩行文字，可以寫兩行 print()。Python 會由上往下執行。

下方範例先顯示第一行，再顯示第二行。這一課不需要在行首加空格。

範例 · 先讀再預測
print("我是小安")
print("今天開始學 Python")
想好結果了？展開核對
執行結果
我是小安
今天開始學 Python

換行只是把程式分成下一行。每一行仍然需要完整的 print()、括號和引號。

在程式中，以 # 開頭的內容是註解，用來提醒自己，不會當成指令執行。作業本內的註解下方，就是你寫程式的位置。

文字和計算不一樣

比較下面兩行。第一行沒有引號，第二行有引號。先猜結果，再展開核對。

範例 · 先讀再預測
print(3 + 5)
print("3 + 5")
想好結果了？展開核對
執行結果
8
3 + 5

第一行把 3 + 5 當成算式，得到 8。第二行把引號內的 3 + 5 當成文字，原樣顯示。

所以「想算出答案」與「想顯示算式文字」，寫法不同。

04 / 05

遇到錯誤，先找符號

下面的程式少了一個引號。觀察文字左右，有沒有成對的符號？

print("我學會了)

這種寫法會出現 SyntaxError，表示程式語法有問題。錯誤訊息可能提到 unterminated string：文字還沒有結束。

修正時先找文字結尾，再檢查右括號前是否有引號。錯誤不會弄壞電腦；改好後重新執行即可。

完成標準：輸出恰好為「我學會了」，不再出現錯誤。

交作業

把你寫的程式交給老師

  1. 開啟 Colab 作業本，選「檔案 → 在雲端硬碟中儲存副本」，改名為「第1課_暱稱」。
  2. 依 A–E 題作答，確認程式、結果及學習紀錄已保存。
  3. 點「分享」，加入老師帳號，授予檢視或加註權限，再交出自己的副本連結。

只複製網址不會自動開放權限。要分享的是你寫過的副本，不是本頁的原始教材網址。

開啟原始作業本 ↗下載作業本
已經存過副本，或還在做舊版作業？

請從自己的 Google Drive 開啟原有副本，不要反覆建立新副本。舊版的程式仍在你自己的副本中；這次更新不會改掉你的答案。若要使用新的精簡版，另存新副本再自行搬移需要的程式。

Colab 找不到檔案？

教師需先將新版 ipynb 上傳到 GitHub main 分支。也可下載作業本，在 Colab 使用「檔案 → 上傳筆記本」。本課不需要安裝套件或付費 GPU。
