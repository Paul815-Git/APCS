UNIT A / E

A｜逗號分隔的成績紀錄

split(",")會依指定逗號切開，與不給參數的split不同：連續逗號會留下空欄位。解析後先為每個欄位命名，再把數字欄位轉成int，能避免用錯位置。此題保證兩個數字欄位存在，因此可以直接轉換；缺欄位的情況留到後面處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
name, first, second = "Amy,7,9".split(",")
print(name, int(first) + int(second))
展開範例結果
Amy 16

UNIT B / E

B｜小型計算機指令

指令可以有不同欄位數。先用split取得串列，再判斷第一欄的動作，只有需要數字的動作才讀第二欄。依輸入順序更新同一個累積值，SHOW只讀取目前狀態，不會把值清空。把解析與動作分開，可降低在無參數指令讀取不存在欄位的風險。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
value = 2
parts = "ADD 5".split()
if parts[0] == "ADD":
    value += int(parts[1])
print(value)
展開範例結果
7

UNIT C / E

C｜餘額不足就保留原狀

解析出提款金額不代表一定可以提款，還要先判斷它是否超過目前餘額。合法操作才改變狀態，拒絕時只記錄失敗次數。這讓餘額永遠保持非負，形成可隨時檢查的不變量。存款與提款即使使用同一數字欄位，更新前提也不相同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
balance = 8
amount = 10
if amount <= balance:
    balance -= amount
print(balance)
展開範例結果
8

UNIT D / E

D｜保留空欄位並補預設值

資料中空欄位與整列不存在不同。指定分隔符切割會保留空字串，因此先檢查欄位是否等於空字串，再決定能否轉成整數。不能直接使用int("")，那會發生錯誤。本題以零作為缺分數的預設值，但姓名始終存在，三欄的位置不會移動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parts = "Amy,,9".split(",")
print(len(parts))
print(parts[1] == "")
展開範例結果
3
True

UNIT E / E

E｜依商品名稱管理庫存

當狀態不只一個數字，可以用字典把商品名稱對應到庫存。尚未出現的商品用get取得零，成功進貨或出貨才寫回。查詢不會新增商品，也不改庫存。先確認每種指令的欄位數，再決定讀金額或讀名稱，能讓指令處理與資料更新保持清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stock = {"pen": 4}
print(stock.get("book", 0))
stock["pen"] -= 2
print(stock["pen"])
展開範例結果
0
2
