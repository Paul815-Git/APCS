input 接收文字

前兩課的資料寫在程式裡。input() 會等待你輸入一行，按 Enter 後，把文字交給左邊的變數。下方範例輸入 小安。

範例 · 先讀再預測
name = input()
print("你好", name)
想好結果了？展開核對
執行結果
你好 小安

print() 用逗號分開兩個項目，預設會在中間加一個空格。Colab 執行後會出現輸入框；先輸入再按 Enter，不要一直重按執行。

向使用者打招呼

完成標準：保留歡迎和暱稱之間的一個空格；換暱稱後仍正確。

02 / 05

文字先轉成整數

input() 取得的永遠是文字。int() 可以將像 "12" 這樣的整數文字轉成整數。範例輸入 12。

範例 · 先讀再預測
age = int(input())
print(age + 1)
想好結果了？展開核對
執行結果
13

若直接把 input() 的結果加上數字，會出現型別錯誤。int("abc") 或 int("2.5") 會出現 ValueError。本階段題目保證輸入是合規整數，不必另外處理無效文字。

03 / 05

一行接一行讀資料

一個 input() 讀一行。題目有兩行，就依序讀兩次。範例第一行輸入單價 15，第二行輸入數量 4。

範例 · 先讀再預測
price = int(input())
quantity = int(input())
print(price * quantity)
想好結果了？展開核對
執行結果
60

題目若說分成兩行，就不要把兩個數字一起填進同一個輸入框。之後會再學一行多個數字。每題都要自己讀取需要的資料，不借用前一題的變數。

04 / 05

整除與餘數

// 求整除的商，% 求餘數。例如 17 顆糖，每袋裝 5 顆，可以裝 3 袋，剩 2 顆。這裡先只處理非負整數，除數必須大於 0。

範例 · 先讀再預測
print(17 // 5)
print(17 % 5)
想好結果了？展開核對
執行結果
3
2

/ 會得到 3.4；// 得到 3。當數值非負時，可以把 // 理解為裝滿幾份。不要以 int(a / b) 取代整數的 //。

完成標準：135 得到 2／15；60 得到 1／0；0 得到 0／0。

05 / 05

先寫輸入、處理、輸出

開始打字前，先在紙上列出三件事：要讀什麼？怎麼算？要印什麼？例如金額 68 元，要用最多的 10 元硬幣，再用 1 元補齊。

範例 · 先讀再預測
money = 68
print(money // 10)
print(money % 10)
想好結果了？展開核對
執行結果
6
8

程式測試至少包含一般情況、整除、零。題目要求只印答案時，不加「答案是」等提示文字；input() 也可以不放提示字。

完成標準：23、6 得到 3／5；24、6 得到 4／0；0、6 得到 0／0。
