UNIT A / E

A｜不含終點的區間

同樣寫兩個位置，本題使用左閉右開區間，與先前一開始且含兩端的規格不同。先把索引定義抄在紙上，再決定 range 的兩個參數。左右相等代表空區間，總和應為零；右端等於長度則合法，因為程式不會真的讀取該索引。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [4, 5, 6]
print(sum(a[1:3]))
print(sum(a[2:2]))
展開範例結果
11
0

UNIT B / E

B｜尾端連續零

由後往前找連續零時，遇到第一個非零就停止；不能把整個串列所有零都算進去。索引遞減的 range 終點不包含，因此要走到第零格時終點寫負一。全零與最後一格非零是兩個相反邊界，可以檢查停止條件及是否漏掉第一格。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [0, 3, 0, 0]
count = 0
for i in range(len(a)-1, -1, -1):
    if a[i] != 0:
        break
    count += 1
print(count)
展開範例結果
2

UNIT C / E

C｜相鄰而非所有配對

只有相鄰位置形成題目的比較對，因此有一個元素時根本沒有配對。迴圈從第二個元素開始，每次與前一個比較；初始化次數為零便能自然處理單元素，不必額外補一筆。相等不算變號，且零不是正數或負數，需把這些定義寫進條件。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = -2, 3
print(a * b < 0)
展開範例結果
True

UNIT D / E

D｜整批分裝的最後一盒

整數除法給出完整盒數，但只要仍有餘數就需要多一盒。空物品不需要盒子，而恰好整除不應額外增加；這兩種情況最容易被無條件加一的寫法弄錯。以商與餘數分開思考，再用小例子核對，比直接背取整公式更能看清楚用途。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n, capacity = 6, 3
boxes = n // capacity
if n % capacity != 0:
    boxes += 1
print(boxes)
展開範例結果
2

UNIT E / E

E｜環狀位移允許負數

環狀位置移動後，取模可以把結果放回合法索引範圍。Python 對正的模數會得到非負餘數，所以向左移動也能使用同一公式，不需要反覆加減長度。先保留原位置再算新位置；長度一與位移整圈時，結果都應回到唯一或原本的位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n, position, shift = 5, 0, -1
print((position + shift) % n)
展開範例結果
4
