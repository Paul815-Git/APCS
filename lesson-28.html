UNIT A / E

A｜全負數的最大值

把best從0開始，對全負數資料會回報不存在的0。非空輸入最安全的初值通常是第一筆，因為它確定是合法候選。最大值與出現次數一起更新時，出現更大值要把次數重設為1，遇相等才累加。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[-5,-2,-2]
best=a[0]
for x in a:
    if x>best:
        best=x
print(best)
展開範例結果
-2

UNIT B / E

B｜最後一段也要結算

如果只在遇到0時更新最長連續1長度，資料以1結束就會漏掉最後一段。更簡單的方式是每讀一筆就更新cur，再更新best。cur只描述目前結尾的片段，遇0歸零；best描述歷史最佳，不可跟著歸零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
cur=best=0
for x in [1,0,1,1]:
    cur=cur+1 if x==1 else 0
    best=max(best,cur)
print(best)
展開範例結果
2

UNIT C / E

C｜不同位置不等於不同數值

第11課配對的限制是不同索引，不是值一定不同。兩個5可以合法相配，但只有一個5不能自己使用兩次。本題改找是否有兩個位置數值相同，集合可記錄先前看過的值；必須先檢查再加入，否則每筆都會和自己相同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
seen={3,5}
print(5 in seen)
print(2 in seen)
展開範例結果
True
False

UNIT D / E

D｜空堆疊與忽略指令

第19課退格題已知道空堆疊不可pop。本題增加清空指令，操作後仍可能連續刪除，必須每次重新判斷是否有內容。忽略無效刪除是一條明確規則，不是靠捕捉所有例外掩蓋其他程式錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stack=list("ab")
stack.clear()
if stack:
    stack.pop()
print(len(stack))
展開範例結果
0

UNIT E / E

E｜檢查排序結果有沒有遺失資料

一份排序結果必須同時有序且與原資料具有相同的值和次數。只檢查總和或集合不足以保證資料完整，例如[1,1,3]與[1,2,2]總和相同，內容卻不同。檢查器用兩個字典計次，再獨立檢查相鄰順序，較容易定位錯誤來源。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
print(sum([1,1,3])==sum([1,2,2]))
print([1,1,3]==[1,2,2])
展開範例結果
True
False
