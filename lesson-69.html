UNIT A / E

A｜兩邊最小未取值比較

兩列都已排序時，各自最前面的未取值就是該列最小候選。比較兩個候選，取較小者並只移動那一邊指標，便能保持輸出有序。有一列耗盡後，另一列剩下部分可直接接上；不必重新排序，也不可忘記尾段。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = [1, 4], [2, 4, 7]
i, j, result = 0, 0, []
while i < len(a) and j < len(b):
    if a[i] <= b[j]:
        result.append(a[i]); i += 1
    else:
        result.append(b[j]); j += 1
print(*(result + a[i:] + b[j:]))
展開範例結果
1 2 4 4 7

UNIT B / E

B｜交集保留最少出現次數

有序交集遇到相等值就各消耗一個，輸出一份；不相等時，只移動較小值那一側，因為它不可能再與另一側後面的值相等。這樣相同值輸出的次數等於兩列次數的較小者，與集合交集只保留一份的意義不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = [1, 2, 2], [2, 2, 2]
i, j, result = 0, 0, []
while i < len(a) and j < len(b):
    if a[i] == b[j]:
        result.append(a[i]); i += 1; j += 1
    elif a[i] < b[j]:
        i += 1
    else:
        j += 1
print(*result)
展開範例結果
2 2

UNIT C / E

C｜辨識現成有序段

原資料可能已包含一段段非遞減片段。從左到右，只在目前值嚴格小於前值時切開，就得到最長的自然有序段；相等不需切開。這一步只是辨識結構，還沒有合併。先能指出每段端點，後續才容易確認合併函式收到的前提成立。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 3, 2, 2, 5, 0]
start = 0
for i in range(1, len(a)):
    if a[i] < a[i - 1]:
        print(start, i)
        start = i
print(start, len(a))
展開範例結果
0 2
2 5
5 6

UNIT D / E

D｜一輪成對合併與不足尾段

每段已排序且段長最多為 w 時，一輪把相鄰兩段合併成最多二倍長的新段。尾端可能只剩一段，或第二段不足 w，切片會安全取得實際存在的元素。這裡使用迴圈控制所有段，不需要函式呼叫自己；前提是每個輸入段確實有序。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 4, 2, 3, 0]
width = 2
for start in range(0, len(a), 2 * width):
    print(a[start:start + width], a[start + width:start + 2 * width])
展開範例結果
[1, 4] [2, 3]
[0] []

UNIT E / E

E｜段長加倍完成排序

單一元素本來就有序，所以可以從段長一開始。每輪合併相鄰有序段，再將段長加倍；經過數輪就涵蓋整列。每輪總共處理所有元素一次，輪數約為對數，因此比插入排序最壞的平方工作量更適合大資料。本題用 while 完成，不提前引入遞迴。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
width, n = 1, 7
while width < n:
    print(width)
    width *= 2
展開範例結果
1
2
4
