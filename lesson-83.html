UNIT A / E

A｜堆頂最小不代表整列有序

heapq以一般串列保存最小堆，heappush加入，heappop取出最小值，heap[0]只查看最小值。它只保證堆頂最小，不保證整份串列遞增，不能直接輸出內部串列當排序。取出前仍要檢查是否為空；反覆插入與取出約需對數時間，因此適合持續到達的新資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
heap = []
for x in [5, 2, 7]:
    heapq.heappush(heap, x)
print(heap[0])
print(heapq.heappop(heap))
print(heapq.heappop(heap))
展開範例結果
2
2
5

UNIT B / E

B｜每次合併最短兩段

合併兩段的成本等於長度總和，新段還可能參與後續合併，因此早被合併的長度會重複付費。每次選最短兩段可讓較大的長度較晚加入；可以用交換理由把最短兩段安排為最深的兄弟葉。堆維持目前所有段，單一段不需任何合併成本。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
heap = [2, 3, 7]
heapq.heapify(heap)
merged = heapq.heappop(heap) + heapq.heappop(heap)
heapq.heappush(heap, merged)
print(merged)
print(heapq.heappop(heap))
展開範例結果
5
5

UNIT C / E

C｜只保留目前最大的k個

維持大小最多為 k 的最小堆，每加入一值，若超過 k 就移除目前最小值，剩下的便是已讀資料中最大的 k 個。最後堆頂是這些值中最小的，也就是整體第 k 大。重複值仍占不同排名，不能先用集合去重，負數也遵守相同大小關係。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
heap = []
for x in [4, 1, 8, 5]:
    heapq.heappush(heap, x)
    if len(heap) > 2:
        heapq.heappop(heap)
print(heap[0])
展開範例結果
5

UNIT D / E

D｜相同優先權依加入順序

堆可以存元組，先比較第一欄，相同再比較第二欄。若任務按優先值由小到大處理，同值先來先服務，就存優先值與遞增序號，再存名稱。不能直接讓姓名當第二排序條件，否則同優先權會改成字母順序，與加入時間無關。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
heap = []
heapq.heappush(heap, (2, 0, 'Zoe'))
heapq.heappush(heap, (2, 1, 'Amy'))
print(heapq.heappop(heap)[2])
展開範例結果
Zoe

UNIT E / E

E｜最早空閒機器的排程

任務按給定順序分配，每次挑最早空閒機器，不是重新排列任務求全域最優。堆保存各機器的空閒時間與編號，取出後加上新工作時間再放回。相同空閒時間選小編號，元組即可表示；最後完成時間是所有機器空閒時間的最大值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
heap = [(0, 1), (0, 2)]
for duration in [3, 2, 4]:
    free, machine = heapq.heappop(heap)
    heapq.heappush(heap, (free + duration, machine))
    print(machine, free + duration)
展開範例結果
1 3
2 2
2 6
