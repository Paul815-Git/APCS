UNIT A / E

A｜每件只有拿或不拿

每個物品最多一次時，處理新物品的可達重量應只依賴加入它之前的狀態。先複製舊表，代表全不拿這件，再由舊表產生拿它的重量，就不會在同一輪反覆使用。重量相同的兩件仍是不同物品，但本題只問是否可達，不計有多少選法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
reachable = [True, False, False, False, False]
weight = 2
next_row = reachable.copy()
for used in range(5 - weight):
    if reachable[used]:
        next_row[used + weight] = True
print(*next_row)
展開範例結果
True False True False False

UNIT B / E

B｜二維表看清選與不選

令dp[i][c]表示只看前i件、容量不超過c時的最大價值。第i件不選就取上一列同容量；選它就取上一列扣掉重量的容量，再加價值。兩個來源都來自上一列，直接表達每件只能一次。容量是上限，不要求裝滿，所以所有初始容量可用空集合取得零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
previous = [0, 0, 0, 0, 0]
weight, value = 2, 5
current = previous.copy()
for cap in range(weight, 5):
    current[cap] = max(previous[cap], previous[cap - weight] + value)
print(*current)
展開範例結果
0 0 5 5 5

UNIT C / E

C｜倒序容量避免同件重拿

將二維表壓成一維後，更新dp[c]時必須確保dp[c-w]仍屬於上一件處理完的狀態。容量由大到小走，較小位置尚未更新，因此滿足這個要求。若由小到大，同一物品剛產生的結果可能立刻再被使用，便把每件一次誤寫成可重複拿。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dp = [0] * 5
for c in range(4, 1, -1):
    dp[c] = max(dp[c], dp[c - 2] + 5)
print(*dp)
展開範例結果
0 0 5 5 5

UNIT D / E

D｜恰好裝滿需要不可達狀態

容量恰好用完與不超過容量不同。只有重量零的初始價值是零，其餘重量尚不可達；若全設零，就等於允許憑空補重量。用None表示不可達，轉移前先檢查來源。價值可為負時也不能用零當最佳下界，因為恰好裝滿可能只能得到負總價值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dp = [0, None, None, None]
weight, value = 3, -5
if dp[3 - weight] is not None:
    dp[3] = dp[3 - weight] + value
print(dp[3])
展開範例結果
-5

UNIT E / E

E｜用重量表改善分組搜尋

分成兩組的最小差曾用完整子集合搜尋，現在可先求哪些重量能由部分物品組成，再在所有可達重量中比較兩組差。每件仍只用一次，所以重量表倒序更新。工作量依總重量而非子集合數成長，適合物品多但總重量受限的題目。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total = 10
reachable = [0, 3, 7, 10]
best = total
for used in reachable:
    best = min(best, abs(total - 2 * used))
print(best)
展開範例結果
4
