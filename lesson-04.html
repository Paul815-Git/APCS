01 / 05

比較會得到真假

>、<、>=、<=、==、!= 用來比較，結果是 True 或 False。== 問是否相等；= 則是把值存進變數。

範例 · 先讀再預測
score = 60
print(score >= 60)
print(score == 100)
想好結果了？展開核對
執行結果
True
False

大於等於包含剛好等於；只有大於則不包含。讀題時特別注意「至少」「超過」等字眼。

02 / 05

if 與 else

if 後面寫條件並加冒號；成立時執行縮排的區塊，否則執行 else。縮排統一使用 4 個空格。

範例 · 先讀再預測
score = 59
if score >= 60:
    print("PASS")
else:
    print("RETRY")
想好結果了？展開核對
執行結果
RETRY

else 和 if 要對齊。少冒號可能產生 SyntaxError，縮排有誤可能產生 IndentationError。兩個分支只會選一個。

03 / 05

elif 處理多種結果

有三種以上的選擇時，用 elif 接續判斷。程式由上而下，遇到第一個成立的分支就執行，後面的分支不再判斷。

範例 · 先讀再預測
score = 85
if score >= 90:
    print("A")
elif score >= 60:
    print("B")
else:
    print("C")
想好結果了？展開核對
執行結果
B

若把 >= 60 放第一個，95 也會先進入它，永遠輪不到 >= 90。條件順序是程式的一部分。

04 / 05

and、or 組合條件

and 表示兩邊都成立；or 表示至少一邊成立；not 反轉真假。範例判斷年齡是否落在含端點的區間。

範例 · 先讀再預測
age = 15
if age >= 12 and age <= 18:
    print("YES")
else:
    print("NO")
想好結果了？展開核對
執行結果
YES

不要写 age == 12 or 18；18 自己不是一個年齡比較。應把左右兩個比較都寫完整。

05 / 05

把規則變成程式

每筆訂單總額滿 500 元免運，否則運費 60 元。先判斷運費，再把運費加進金額；避免在分支裡遺漏輸出。

範例 · 先讀再預測
amount = 500
if amount >= 500:
    shipping = 0
else:
    shipping = 60
print(amount + shipping)
想好結果了？展開核對
執行結果
500

測試 499、500、501，能檢查門檻是否寫錯。這類「剛好到門檻」的資料稱為邊界測試。
