UNIT A / E

A｜三個不同位置

三個不同位置且不分順序時，可以規定i<j<k。每一組位置只有一種遞增排列，因此不漏也不重複。三層迴圈的工作量大約隨資料量的三次方成長，所以這題限制n不大；先學會完整枚舉，再談如何縮減，才知道優化是否保留所有合法答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 2, 3, 4]
for i in range(len(a)):
    for j in range(i+1, len(a)):
        for k in range(j+1, len(a)):
            if a[i] + a[j] + a[k] == 6:
                print(i, j, k)
展開範例結果
0 1 2

UNIT B / E

B｜排序後檢查三角形

正邊長排序為a≤b≤c後，只要檢查a+b>c就能判斷三角形，另外兩個不等式已由正數與順序保證。等於時只會攤成一直線，不能算三角形。排序會改變索引順序，但本題只計位置組合數，每一根仍保留一份，即使長度相同也沒有被合併。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
sides = sorted([4, 2, 3])
print(sides[0] + sides[1] > sides[2])
展開範例結果
True

UNIT C / E

C｜由等式算出第三個值

若已知a+b+c等於固定目標，選定a和b後，c就只可能是目標減去前兩數，不必再走第三層迴圈。算出的c仍要檢查合法範圍，因為等式成立不代表符合題意。這是從限制推導出的縮減，與隨意跳過某些候選不同，能保證不漏答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
target, a, b = 8, 2, 3
c = target - a - b
print(c)
展開範例結果
3

UNIT D / E

D｜部分和超標何時能停止

只有當後續值不會讓部分和變小時，超標才代表可以停止。本題a、b、c皆非負且b遞增，若a+b已超過目標，後面的b只會更大，因此break合法。若資料允許任意負數，這個理由就失效。先把單調性的依據說清楚，再使用提前結束。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for b in range(5):
    if 2 + b > 3:
        break
    print(b)
展開範例結果
0
1

UNIT E / E

E｜總件數與總價一起限制

多條限制可以分工使用：先用總件數決定第三種商品的數量，再用總價檢查候選。三種數量都允許為零，所以迴圈必須包含零；同種商品的購買先後不影響組合。這樣只需要枚舉前兩種數量，而且第二種上限可縮到剩下的件數，避免出現負的第三種數量。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n, x, y = 4, 1, 2
z = n - x - y
print(z, 2*x + 3*y + 5*z)
展開範例結果
1 13
