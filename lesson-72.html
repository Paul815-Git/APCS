UNIT A / E

A｜呼叫前後的輸出順序

呼叫前的指令隨參數縮小依序執行，呼叫後的指令要等內層完成才執行，所以順序會反過來。可以把每層看成一張暫停的工作單，記住自己尚未完成的事。基底直接返回後，才會逐層恢復，不是把整個程式一次結束。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def trace(n):
    if n == 0:
        return
    print('IN', n)
    trace(n - 1)
    print('OUT', n)
trace(2)
展開範例結果
IN 2
IN 1
OUT 1
OUT 2

UNIT B / E

B｜每層各自保存區域變數

不同呼叫雖使用同樣變數名稱，卻各自保有自己的值。先取得子問題答案，再算本層答案並輸出，可以看見回傳由小到大的累積過程。不要用一個全域變數取代所有層，否則無法看清函式契約，也容易讓重複呼叫互相影響。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def total(n):
    if n == 0:
        return 0
    smaller = total(n - 1)
    answer = smaller + n
    print(n, answer)
    return answer
total(3)
展開範例結果
1 1
2 3
3 6

UNIT C / E

C｜兩個子呼叫都要完成

一層可以呼叫兩個較小問題，但它們是依程式順序逐個執行，不是同時執行。計算呼叫總數時，本層算一次，再加上左右子問題的呼叫數。這種展開可能重複處理同樣參數，成長很快；本題刻意限制輸入，先學會追蹤，不把它當高效率方法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def calls(n):
    if n <= 1:
        return 1
    return 1 + calls(n - 1) + calls(n - 2)
print(calls(3))
展開範例結果
5

UNIT D / E

D｜二分搜尋也有空區間基底

把二分搜尋寫成遞迴時，每層只負責一個半開區間。區間為空就回傳找不到；比較中點後，只呼叫仍可能包含目標的一半。子呼叫的答案要直接 return 回去，若只是呼叫卻沒有回傳，外層會得到 None，搜尋成功也無法交給主程式。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def find(a, x, lo, hi):
    if lo == hi:
        return -1
    mid = (lo + hi) // 2
    if a[mid] == x:
        return mid
    if a[mid] < x:
        return find(a, x, mid + 1, hi)
    return find(a, x, lo, mid)
print(find([2, 5, 9], 9, 0, 3))
展開範例結果
2

UNIT E / E

E｜成對縮小的回文判斷

回文檢查可以先比較兩端字元，不同就立即回傳假，相同才檢查中間部分。左右索引相遇或交錯代表剩下零個或一個字元，必然是回文。這個基底同時處理奇數、偶數和空字串；用索引避免每層建立新切片，並讓縮小方向明確。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def palindrome(s, left, right):
    if left >= right:
        return True
    if s[left] != s[right]:
        return False
    return palindrome(s, left + 1, right - 1)
print(palindrome('abba', 0, 3))
展開範例結果
True
