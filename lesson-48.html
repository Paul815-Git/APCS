UNIT A / E

A｜讀取第幾個開關

二進位最右邊是第零位。1<<k表示把一向左移k位，得到只有第k位為一的數；&是逐位且，兩邊都為一的位才保留。因此mask & (1<<k)非零就代表該開關開啟。這裡的&作用於整數位元，與條件判斷用的and不同，括號也能讓運算意圖更清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
mask = 10
print(1 << 1)
print((mask & (1 << 1)) != 0)
展開範例結果
2
True

UNIT B / E

B｜設定開關不能只做加法

位元或運算|只要任一邊為一，該位就變成一；把mask與1<<k做或，就能開啟第k位，其他位保持。即使原本已開啟，也不會變成二或產生進位。直接加上2^k只有在該位原本為零時才正確，因此不適合實作「無論原狀都設為開啟」的指令。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
mask = 2
mask = mask | (1 << 1)
print(mask)
展開範例結果
2

UNIT C / E

C｜清除指定開關

清除第k位可以先查詢它是否為一，若是再減去1<<k；為零時保持不變。這個版本只使用已介紹的位移與位元且，避免還沒定義固定寬度就引入補數的負數表示。先檢查再減也能防止借位，否則清除原本為零的位反而會改動其他位。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
mask, k = 7, 1
if (mask & (1 << k)) != 0:
    mask -= 1 << k
print(mask)
展開範例結果
5

UNIT D / E

D｜重複切換會恢復原狀

位元互斥或^在兩位不同時產生一，相同時產生零。mask ^ (1<<k)因此只反轉第k位，其他位保持原狀；連續切換同一位兩次會回到原值。不要把^當成次方，Python次方是**。本題所有數非負且位數固定，先用小二進位例子追蹤更容易理解。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
mask = 5
mask = mask ^ (1 << 0)
print(mask)
mask = mask ^ (1 << 0)
print(mask)
展開範例結果
4
5

UNIT E / E

E｜控制面板的完整指令

整合指令時先區分讀取與修改：ASK只顯示一位，ON、OFF、FLIP才更新整數。每個操作只應影響指定位置，這是可以隨時檢查的不變量。把同一個bit=1<<k先算好，能避免在多個分支寫出不同位移；最後輸出mask則提供整體狀態核對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
mask, k = 4, 2
bit = 1 << k
print((mask & bit) != 0)
print(mask | bit)
展開範例結果
True
