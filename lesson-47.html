UNIT A / E

A｜逐位取出數字總和

十進位整數對十取餘數可得到最後一位，整除十則刪掉最後一位。若只求各位數總和，讀取順序不影響答案，因此不必反轉。原數字為零時迴圈不執行，總和初值零正好是答案，和轉換表示時必須補字元零的需求不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n, total = 204, 0
while n > 0:
    total += n % 10
    n //= 10
print(total)
展開範例結果
6

UNIT B / E

B｜識別碼保留前導零

識別碼雖然只含數字，也不一定是用來運算的整數。把00120轉成int會遺失前面兩個零，反轉後也無法還原原長度。當題目要求逐字反轉並保留全部位置時，應直接用字串切片，輸出長度必須和輸入相同，不能在最後又轉回整數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
code = "00120"
print(code[::-1])
print(len(code))
展開範例結果
02100
5

UNIT C / E

C｜十個計數器的用途

十進位只有十種數字，可以用長度十的串列讓索引代表數字、內容代表出現次數，比字典更直接。逐字轉成單一整數不會丟掉其他位置的零，因此識別碼仍可保留前導零的計數。最後必須輸出十格，即使某個數字沒有出現也要輸出零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
counts = [0] * 10
for ch in "1001":
    counts[int(ch)] += 1
print(counts[0], counts[1], counts[2])
展開範例結果
2 2 0

UNIT D / E

D｜反覆相加直到只剩一位

重複數位和有兩層工作：內層把目前數字的每一位加起來，外層判斷是否還需要再做一輪。必須用暫存變數拆位，或在每輪結束把新總和指定回n，避免把最後留下的零誤當結果。當n本來就是單位數，包括零，都不需要執行任何一輪。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 99
for turn in range(2):
    total = 0
    for ch in str(n):
        total += int(ch)
    n = total
print(n)
展開範例結果
9

UNIT E / E

E｜位置加權校驗碼

校驗碼不只看有哪些數字，也看它們位在哪裡。以一開始的位置乘上各位數，再把總和取餘數，就能做出簡單檢查值。位置從一算而索引從零算，因此權重是i+1。前導零雖然乘積為零，仍占一個位置，不能先刪掉，否則後面權重會全部改變。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
code = "024"
total = 0
for i in range(len(code)):
    total += (i+1) * int(code[i])
print(total % 10)
展開範例結果
6
