本課操作與紀錄

本機演練清單

  1. 自選目前已能使用的編輯器或IDLE；建立專用資料夾，把A–E各存為不同的UTF-8 .py 檔，不使用題目名稱覆蓋其他檔。
  2. 以全新執行程序從檔案第一行開始跑。使用你電腦可用的Python啟動方式；在Windows若已安裝Python啟動器，可於檔案所在資料夾使用 py 題目A.py，或在IDLE開啟檔案後執行整份模組。這是本機練習方式，不代表考場環境。
  3. 依測資區塊逐行貼入，保留題目指定的空行；輸入完後確認程式會自然結束，沒有再等待多餘一行。
  4. 把實際輸出與預期輸出逐行比較：數字、順序、空格、換行、大小寫、前導零都要相同；移除暫時的除錯print與互動提示。
  5. 先跑一般測資，再跑空行、單元素、零、負數、重複值等本題允許的邊界。修改後重新跑全部已有測資。
  6. 保存後關閉再重開檔案，確認剛才的修正已存入；再從頭執行一次。程式不能依賴其他練習先執行或筆記本殘留變數。
  7. 留下紀錄：檔名、執行方式、通過測資、失敗時的完整錯誤訊息及對應行號。若電腦環境不同，使用已確認可用的工具，不在本課假設官方版本或可用套件。
  8. 實際報名前與考前，由官方當次公告核對環境、語言、時間及繳交方式；本教材不把課內建議當成官方規定。

UNIT A / E

A｜讀取數量與資料分行

在筆記本裡執行過的變數，不會自動存在於新啟動的程式中。本題先讀數量，再讀完整數列，所有狀態都由輸入建立。把程式保存後關閉執行環境再跑一次，確認沒有依賴舊變數；正式輸出只有題目要求的結果，不要印請輸入等提示文字。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

UNIT B / E

B｜多組資料要重新初始化

同一個程式執行多組測試時，各組答案必須重新初始化，不能沿用上一組的最大值或累加結果。最外層負責組數，內層讀取該組資料；先用第一組答案很大、第二組只有負數的測資，容易發現狀態殘留。每組固定輸出一行，也便於逐行比對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for a in [[9, 2], [-4]]:
    best = a[0]
    for x in a:
        best = max(best, x)
    print(best)
展開範例結果
9
-4

UNIT C / E

C｜空行也是合法資料

文字輸入可能包含空行，這不是程式應該跳過的雜訊。input 會取得不含行尾換行的內容，但保留其他空白；若任意加上strip，就會改變本題要統計的字元數。用空行、只含空格及一般文字各測一次，確認讀取方式保留了題目要求的資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s = " a "
print(len(s), len(s.strip()))
展開範例結果
3 1

UNIT D / E

D｜固定寬度的時間輸出

輸出格式本身也是規格。分鐘與秒數各要兩位，不足補零，不能因數值正確就忽略顯示形式。格式字串中的冒號零二d代表十進位整數至少兩位、左側補零；先算商與餘數，再處理排版，能把數學錯誤和格式錯誤分開定位。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
minutes, seconds = 2, 5
print(f"{minutes:02d}:{seconds:02d}")
展開範例結果
02:05

UNIT E / E

E｜查詢全部讀完才結束

每個查詢都要求一行結果，即使查不到也不能省略輸出，否則後續行會整體錯位。先建立計數表再逐筆回答，適合檢查本機多行輸入與輸出對照。測試時把找不到的查詢放在中間，而不是只放最後，才能看出程式是否提前結束或漏掉一行。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = {"a": 2}
for word in ["a", "z", "a"]:
