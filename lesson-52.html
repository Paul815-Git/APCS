UNIT A / E

A｜左上矩形的累積值

二維前綴p[i][j]表示前i列、前j欄的總和，多留第零列與第零欄為零。新格可由上方前綴加左方前綴，再減掉被重複加的左上矩形，最後加目前原值。先畫出重疊部分，就能理解減號的來源；每列都要新建串列，避免共用參照。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
top, left, overlap, cell = 3, 4, 1, 5
print(top + left - overlap + cell)
展開範例結果
11

UNIT B / E

B｜四角相減查詢矩形

每次逐格加總一個矩形，可能重複讀取大量相同格子。用二維前綴先取到右下角的大矩形，再減掉上方和左方多出的區域；左上區域被減了兩次，要加回一次。因此查詢只需四次取值，預處理後每個問題不再隨矩形面積變大。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = [[0,0,0],[0,1,3],[0,4,10]]
x1, y1, x2, y2 = 1, 2, 2, 2
print(p[x2][y2]-p[x1-1][y2]-p[x2][y1-1]+p[x1-1][y1-1])
展開範例結果
6

UNIT C / E

C｜障礙格數也是矩形和

前綴不必累加原本的字元。把障礙#轉成一、空地.轉成零，矩形總和就變成障礙數。查詢是否全空只要看總和是否為零，不必每次重掃區域。注意原輸入每列是連在一起的字串，直接讀input即可，不能套用空格分隔整數的讀法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = ".##."
flags = []
for ch in row:
    flag = 0
    if ch == "#":
        flag = 1
    flags.append(flag)
print(*flags)
展開範例結果
0 1 1 0

UNIT D / E

D｜全負數的最佳正方形

找最大矩形和時不能把最佳值設成零，因為合法區域可能全為負數。先用第一個k乘k區塊初始化，再枚舉所有右下角；每次以前綴公式求和。k等於整張方形邊長時只有一個候選，k等於一則每格都是候選，兩端都應使用同一套範圍。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
candidates = [-8, -3, -6]
best = candidates[0]
for value in candidates:
    best = max(best, value)
print(best)
展開範例結果
-3

UNIT E / E

E｜固定招牌能放在哪裡

矩形候選有固定高與寬時，可以枚舉它的右下角，用障礙前綴表一次判斷整塊是否乾淨。每個左上位置算一種放法，區域互相重疊也分別計數，因為題目只問可選位置，不要求同時放置。高寬不相等時，不能擅自旋轉招牌或交換兩個尺寸。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
rows, cols, height, width = 3, 4, 2, 3
print((rows-height+1) * (cols-width+1))
展開範例結果
4
