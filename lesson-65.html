UNIT A / E

A｜最小需求配最小足夠資源

先滿足最小需求時，應使用能滿足它的最小資源，留下較大的資源給較大需求。太小的資源連最小未滿足需求都無法處理，便可安全丟棄。這個貪心適用於資源只比較大小、每份只能使用一次的情況，不需要枚舉每種分配。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
needs = [2, 4]
resources = [1, 3, 5]
i = 0
for size in resources:
    if i < len(needs) and size >= needs[i]:
        i += 1
print(i)
展開範例結果
2

UNIT B / E

B｜最重者一定要出發

每艘船至多兩人，先考慮最重者：若連最輕者都無法與他同船，他只能單獨搭乘；若兩者能同船，把最輕者配給他也不會增加所需船數。每輪都移除最重者，並視情況移除最輕者，避免因為配不到人而卡住。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
weights = [2, 3, 5]
left, right, boats = 0, 2, 0
while left <= right:
    if weights[left] + weights[right] <= 7:
        left += 1
    right -= 1
    boats += 1
print(boats)
展開範例結果
2

UNIT C / E

C｜嚴格獲勝的配對

分數較大才算獲勝時，相等不能配成成功。將雙方排序後，用目前最小能獲勝的己方分數對付對手最小分數，可以保留更強的人選。無法勝過最弱對手的己方選手，也不可能勝過其他對手，因此可以跳過，不必強行配出一場勝利。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
opponents = [2, 4]
wins = 0
for score in [2, 3, 5]:
    if wins < len(opponents) and score > opponents[wins]:
        wins += 1
print(wins)
展開範例結果
2

UNIT D / E

D｜相鄰配對最小化差距總和

所有數都必須兩兩配對，且成本是絕對差時，排序後相鄰配對可達到最小總成本。若最小值與更遠的值配對，交換相關兩對，使最小值配給次小值，不會增加總差距。這個結論依賴偶數筆且每筆都要使用，不能直接套到任意選部分配對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = sorted([8, 1, 6, 3])
total = 0
for i in range(0, len(a), 2):
    total += a[i + 1] - a[i]
print(total)
展開範例結果
4

UNIT E / E

E｜反向排序降低乘積總和

兩串列一一配對，成本改成乘積時，策略也跟著改變。若兩邊都由小到大，交換其中一邊相鄰的大小值可降低或維持乘積總和，差異等於兩個差值的乘積。因此一邊遞增、一邊遞減得到最小總和；不能沿用差距題的相鄰配法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 3]
b = [2, 5]
print(a[0] * b[0] + a[1] * b[1])
print(a[0] * b[1] + a[1] * b[0])
展開範例結果
17
11
