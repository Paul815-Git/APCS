UNIT A / E

A｜一層一層擴張

廣度優先搜尋使用佇列，先處理較早發現的格子，因此會按步數由小到大擴張。每次移動成本都相同時，首次發現鄰格的距離就是目前距離加一，且已是最短。用負一表示未發現，距離零留給起點；成本不同則理由不成立。[[值]*c for _ in range(r)] 每次建立獨立新列，避免共用內層串列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from collections import deque
queue = deque([(0, 0)])
distance = {(0, 0): 0}
cell = queue.popleft()
distance[(0, 1)] = distance[cell] + 1
print(distance[(0, 1)])
展開範例結果
1

UNIT B / E

B｜有限步數內的範圍

只允許最多 k 步時，到達距離 k 的格子仍要計入，但不再由它擴張下一層。這可以減少無用工作，也清楚區分「不處理這格」與「不擴張這格」。起點距離為零，因此 k=0 仍計入起點本身。題目保證起點可走，無須另外處理從牆內出發的情形。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
distances = [0, 1, 1, 2, 3]
k = 1
count = 0
for d in distances:
    if d <= k:
        count += 1
print(count)
展開範例結果
3

UNIT C / E

C｜整張距離地圖

一次搜尋就能算出起點到所有可走格的最短距離，不必為每格重新執行。距離表同時充當已發現標記，保持一份狀態即可。牆與不可達格都可依題意輸出負一；在輸出階段仍逐列保留矩陣形狀，不能把二維資訊攤平成不清楚的長串列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python

for row in dist:
    print(*row)

UNIT D / E

D｜多個源點同時出發

若每個格子要找最近的服務站，可以把所有服務站距離設為零並一起放入佇列，再照常擴張。佇列會依距離層數混合處理各來源，因此第一次抵達就是離任一來源最近的距離。沒有服務站時佇列為空，所有格子保留不可達標記。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from collections import deque
queue = deque()
dist = [-1] * 5
for source in [0, 4]:
    dist[source] = 0
    queue.append(source)
print(list(queue))
print(*dist)
展開範例結果
[0, 4]
0 -1 -1 -1 0

UNIT E / E

E｜保存前一步還原路徑

距離只告訴步數，要輸出路線還需在首次發現格子時記錄從哪格走來。到終點後沿前一步反向追蹤直到起點，再反轉得到正向路線。若有多條最短路，本題固定鄰格檢查順序，讓首次發現的路線可重現；不要在後來再遇到同格時覆蓋前一步。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parent = {(0, 0): None, (0, 1): (0, 0), (1, 1): (0, 1)}
path, cell = [], (1, 1)
while cell is not None:
    path.append(cell)
    cell = parent[cell]
for x, y in path[::-1]:
    print(x, y)
展開範例結果
0 0
0 1
1 1
