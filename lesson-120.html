UNIT A / E

A｜相鄰日最大改善

改善量是今天減昨天，所以不能用整體最大值減整體最小值代替，兩者可能不是相鄰日期。每一對相鄰資料都是合法候選，先用第一對初始化，才能保留全部變差時的負答案。只有一天時沒有可比較的前日，依題目輸出零，這個情形需要明確分支。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [8, 5, 7]
print(a[1]-a[0], a[2]-a[1])
展開範例結果
-3 2

UNIT B / E

B｜兩份材料能配成幾組

兩份清單中相同品名可以一對一配成組，每件最多使用一次，因此某品名的配對量是兩邊次數較小者。集合交集只能回答有哪些品名，不能回答可配幾組。分別建立兩份頻率表，再加總各鍵的較小次數，沒有出現的品名用零補足，空清單也能自然處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = {"x": 3}
b = {"x": 2}
print(min(a["x"], b["x"]))
展開範例結果
2

UNIT C / E

C｜同時是列小值與欄大值

這題把兩種局部條件合併到同一格：值等於該列最小值，也等於該欄最大值。相等允許多格同時符合，不能只記錄一個最小值所在索引。先預算每列最小及每欄最大，再逐格比較，可以把複雜文字拆成兩個明確判斷；全相等矩陣所有格都成立。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = [[2, 3], [1, 4]]
print(g[0][0] == min(g[0]) and g[0][0] == max(g[0][0], g[1][0]))
展開範例結果
True

UNIT D / E

D｜預算內有幾對商品

兩個不同位置的商品可形成無序配對，重複價格仍代表不同商品。排序後若最小端加最大端不超預算，這個最小端和中間所有位置都能配，因此一次增加右端減左端；若超過就縮右端。這個計數方法需要先說明排序的單調性，再用小資料枚舉核對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 2, 4]
left, right, budget = 0, 2, 5
print(a[left] + a[right] <= budget, right - left)
展開範例結果
True 2

UNIT E / E

E｜完成任務後剩餘多少時間

任務依序執行且每項時間為正，所以累積完成時間嚴格遞增。查詢給總可用時間，先用上界找到已完成項數，再減去該前綴取得剩餘時間；剩餘時間可能用在未完成任務上，本題仍稱未用於完整任務的餘額。恰好完成一項時餘額為零，全部完成後則保留多餘時間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_right
p = [0, 2, 5]
budget = 4
finished = bisect_right(p, budget) - 1
print(finished, budget - p[finished])
展開範例結果
1 2
