UNIT A / E

A｜報名名單：聯集與重疊人數

第20課問只報一班的人；現在同時問總人數與兩班共同人數。先把每班變成集合，消除同班重複報名，再分別做聯集與交集。不要把兩行長度相加，因為同一人可能出現多次。請先手算每個集合有哪些元素，再算數量。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a={1,2,3}
b={2,4}
print(len(a|b),len(a&b))
展開範例結果
4 1

UNIT B / E

B｜先計次，再篩選排行榜

第14課先計次，第16課排序，第20課合併兩者。本題再增加最低出現次數，應在計數完成後篩選。某字在讀到一半時不達門檻，後面仍可能再出現，所以不能過早丟掉。排序依次數遞減，再依字母遞增。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
d={"a":2,"b":3,"c":1}
def rank(word):
    return (-d[word],word)
for word in sorted(d,key=rank):
    if d[word]>=2:
        print(word,d[word])
展開範例結果
b 3
a 2

UNIT C / E

C｜兩個期間的支出差

第17課的前綴和可查一個期間；同一張表也能回答兩段期間，再比較其差。題目指定第一段減第二段，負數答案有意義。兩段可以重疊，分別查詢仍然正確，不需先拆掉共同部分。每筆查詢前先寫清四個端點。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p=[0,10,30,60]
first=p[2]-p[0]
second=p[3]-p[1]
print(first-second)
展開範例結果
-20

UNIT D / E

D｜多個目標的鄰近搜尋

第20課只找一個目標的最近數；現在資料固定、目標有很多個，排序應放在所有查詢之前。每個目標只看下界位置與前一個位置。下界可能是0或n，必須先判斷候選存在，才能取值；距離相同仍選小值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left
a=[2,6,10]
pos=bisect_left(a,8)
print(a[pos-1],a[pos])
展開範例結果
6 10

UNIT E / E

E｜括號：指出第一個問題位置

第20課只輸出合法與否；本題要留下第一個違規位置。遇到錯的右括號可立刻定位，若掃完仍有左括號，錯誤是在輸入結束才確定。本題用n+1表示這種缺少右括號的情況，並非要求找最早未關閉的左括號。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。
