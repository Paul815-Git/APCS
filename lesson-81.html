UNIT A / E

A｜從每個未發現節點開始

一次搜尋只涵蓋一個連通分量，圖可能還有其他互不相通的群組。依編號掃描節點，遇到未發現者就啟動新搜尋並增加群組數，直到所有節點都標記。孤立節點雖沒有邊，自己也算一個分量；不能只從邊的端點開始統計。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
adj = [[], [2], [1], []]
seen = set()
groups = 0
for start in range(1, 4):
    if start in seen:
        continue
    groups += 1
    stack = [start]
    seen.add(start)
    while stack:
        u = stack.pop()
        for v in adj[u]:
            if v not in seen:
                seen.add(v); stack.append(v)
print(groups)
展開範例結果
2

UNIT B / E

B｜每次走訪有自己的大小

群組大小只計算這一次搜尋取出的節點，因此計數器必須在每個新起點重新歸零。將每個分量大小收集後排序，得到整張圖的群組分布。全域標記要保留，局部大小要重設；兩者生命週期不同，混用會把前面群組的節點重複加入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
sizes = [3, 1, 2]
sizes.sort()
print(*sizes)
print(sum(sizes))
展開範例結果
1 2 3
6

UNIT C / E

C｜群組加總不能只看節點數

每個節點帶有重量時，最大群組不一定是節點最多的群組。搜尋時把本群節點重量累加，完成後再比較不同群的總和。若重量可為負，最佳答案不能從零開始，因為所有群組可能皆為負；用尚無答案的狀態表示第一次更新較清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
weights = [0, -5, -2, -1]
group1 = weights[1] + weights[2]
group2 = weights[3]
print(max(group1, group2))
展開範例結果
-1

UNIT D / E

D｜格子也能分連通群

格子是一種鄰居由座標產生的圖，同樣可以從每個未走訪的陸地開始搜尋，數出島嶼。題目指定四方向時，斜角相碰的兩格仍是不同島。全海地圖沒有起點，島數自然為零；不要為了初始化答案而預設至少一座島。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = ['10', '01']
print(grid[0][0] == '1')
print(abs(0 - 1) + abs(0 - 1) == 1)

False

UNIT E / E

E｜預先編號回答同區查詢

若有很多是否相通的查詢，不必每次重新搜尋。先為每個分量配置一個編號，走訪時把所有到達節點標成同號。之後兩點編號相同就相通，查詢只需一次比較。編號本身沒有大小意義，只代表群組身分，因此不應以編號差距推測圖上距離。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
component = [0, 1, 1, 2]
print(component[1] == component[2])
print(component[1] == component[3])
展開範例結果
True
False
