def 定義、呼叫才執行

函式是一組可以重複呼叫的步驟。def 後面是名稱與參數，return 把答案交回呼叫的位置。

範例 · 先讀再預測
def double(x):
    return x * 2

print(double(4))
print(double(7))
想好結果了？展開核對
執行結果
8
14

定義函式不會立即執行內容；double(4) 才是呼叫。參數 x 接收這次的資料。return 負責交回數值，print 負責顯示；兩者不同。

02 / 05

兩個參數與區域變數

函式可以接收多個參數。裡面建立的變數通常只在函式內使用，要交給外面就 return。

範例 · 先讀再預測
def rectangle_area(length, width):
    area = length * width
    return area

print(rectangle_area(3, 5))
想好結果了？展開核對
執行結果
15

不要在外面直接 print(area)，那不是外面定義的變數。用 result = rectangle_area(3, 5) 保存回傳值。

03 / 05

搜尋第一個符合的位置

把串列和目標交給函式，找到第一筆就 return。走完仍沒有找到，回傳 -1。

範例 · 先讀再預測
def find_first(nums, target):
    for i in range(len(nums)):
        if nums[i] == target:
            return i
    return -1

print(find_first([4, 7, 7], 7))
想好結果了？展開核對
執行結果
1

return 會立刻離開函式。最後的 return -1 要在 for 外面；如果放進 for，就可能只看第一筆便宣告找不到。索引從 0 開始。

排序產生有序資料

sorted(nums) 產生由小到大的新串列，原串列不變。這一課先使用內建排序，之後進階課程再研究排序方法。

範例 · 先讀再預測
nums = [8, 2, 5]
ordered = sorted(nums)
print(ordered)
print(nums)
想好結果了？展開核對
執行結果
[2, 5, 8]
[8, 2, 5]

排序後 ordered[0] 最小，ordered[len(ordered)-1] 最大。題目若要求一行一個數，就逐一 print；不要直接印出帶中括號的串列。

05 / 05

把計算與輸入分開

讓函式只接收資料、回傳答案，主程式負責 input 和 print，比較容易用不同資料測試。範例計算最大與最小的差。

範例 · 先讀再預測
def spread(nums):
    ordered = sorted(nums)
    return ordered[-1] - ordered[0]

print(spread([8, 2, 5]))
想好結果了？展開核對
執行結果
6

索引 -1 代表最後一筆。把問題拆解成：讀取 → 轉成整數串列 → 呼叫函式 → 輸出。函式的輸入條件仍要清楚，例如這裡不接受空串列。
