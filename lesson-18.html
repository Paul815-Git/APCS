單元 A / E

先理解搜尋區間

二分搜尋需要有序資料。使用左閉右開區間 [lo,hi)，lo 包含、hi 不包含。當 lo==hi 時區間為空。mid=(lo+hi)//2；若向右搜尋，lo=mid+1，才會真的縮小。

範例 · 先預測，再核對
nums = [2, 4, 6, 8]
lo, hi = 0, len(nums)
mid = (lo + hi) // 2
print(mid, nums[mid])
展開範例結果
2 6

單元 B / E

找第一個不小於目標的位置

若 nums[mid]<target，中點及更左都不可能是答案，移動 lo；否則中點可能是答案，令 hi=mid 保留它。最後 lo 是第一個 >=target 的位置，可能等於長度，表示全都太小。

範例 · 先預測，再核對
nums = [2, 4, 4, 8]
target = 4
lo, hi = 0, len(nums)
while lo < hi:
    mid = (lo+hi)//2
    if nums[mid] < target:
        lo = mid+1
    else:
        hi = mid
print(lo)
展開範例結果
1

單元 D / E

標準函式與重複值

Python 標準函式庫 bisect 不需額外安裝。bisect_left 找第一個 >=目標的位置，bisect_right 找第一個 >目標的位置；兩者相減就是相等元素個數。每次搜尋約 O(log n)。

範例 · 先預測，再核對
from bisect import bisect_left, bisect_right
nums = [2, 4, 4, 8]
print(bisect_left(nums, 4))
print(bisect_right(nums, 4))
展開範例結果
1
3

單元 E / E

在數值範圍內計數

數值範圍 [a,b] 不等於位置區間。第一個 >b 的位置減去第一個 >=a 的位置，就是 a 到 b 之間的元素數，包含重複。未排序資料先排序一次。

範例 · 先預測，再核對
from bisect import bisect_left, bisect_right
nums = sorted([8, 2, 4, 4])
print(bisect_right(nums, 4)-bisect_left(nums, 2))
展開範例結果
3
