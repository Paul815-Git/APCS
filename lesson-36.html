矩陣轉換

UNIT A / E

A｜左右鏡射每一列

左右鏡射改變欄順序，不會改變列順序。對每列使用[::-1]得到反向的新串列，再依原列順序輸出即可。可以先在紙上標出原本最左、最右兩格的位置，確認它們只交換左右，沒有上下對調，避免把整份矩陣的列順序反轉當成左右鏡射。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [[1, 2, 3], [4, 5, 6]]
for row in grid:
    print(*row[::-1])
展開範例結果
3 2 1
6 5 4

UNIT B / E

B｜上下翻轉只換列順序

上下翻轉保留每列內部的左右順序，但最下面一列必須最先輸出。因此要先讀完所有列，再反向走訪外層串列。這和上一題反轉內層串列不同；兩種操作都叫翻轉，作用的層級卻不一樣，先描述哪一條邊會交換，再選擇要反轉的串列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [[1, 2], [3, 4]]
for row in grid[::-1]:
    print(*row)
展開範例結果
3 4
1 2

UNIT C / E

C｜順時針旋轉九十度

順時針旋轉後，原本第一欄由下往上成為新矩陣第一列，所以新列數等於舊欄數。外層逐一選舊欄，內層由最後一列往第一列取值。range(r-1,-1,-1)不包含終點負一，恰好走過r-1到0，與負索引讀取最後一列是不同用途。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [[1, 2, 3], [4, 5, 6]]
for c in range(3):
    row = []
    for r in range(1, -1, -1):
        row.append(grid[r][c])
    print(*row)
展開範例結果
4 1
5 2
6 3

UNIT D / E

D｜旋轉很多次只看餘數

連續四次九十度旋轉會回到原圖，因此只需執行k對4的餘數次。每一次旋轉都要依目前矩陣的列數與欄數重算，不能一直使用最初尺寸；長方形旋轉一次後兩個尺寸就交換。把旋轉寫成回傳新矩陣的函式，可讓重複操作仍然保持清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
print(1000003 % 4)
print(4 % 4)
展開範例結果
3
0

UNIT E / E

E｜轉換順序會改變結果

多種矩陣操作通常不能任意交換順序，先鏡射再旋轉與先旋轉再鏡射可能得到不同圖形。每讀一個指令就以目前矩陣產生下一個矩陣，完成後才替換grid。這種舊資料讀完才更新的結構，也能避免旋轉過程改到仍需要讀取的來源格。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = [1, 2, 3]
flipped = row[::-1]
print(*flipped)
print(*row)
展開範例結果
3 2 1
1 2 3
