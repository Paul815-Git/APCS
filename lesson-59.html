UNIT A / E

A｜小於、等於、大於各有幾筆

bisect_left找到第一個不小於t的位置，前面都是小於t的值；bisect_right找到第一個大於t的位置，兩位置的差就是等於t的數量。剩下尾段則是大於t。三個分類互斥而且涵蓋所有資料，數量加起來必須等於n，可用這個關係檢查重複值與邊界。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [1, 3, 3, 8]
lo, hi = bisect_left(a, 3), bisect_right(a, 3)
print(lo, hi-lo, len(a)-hi)
展開範例結果
1 2 1

UNIT B / E

B｜查詢價格範圍內的總金額

二分找到的是排序後的位置區間，不是金額本身。把排序資料再建立前綴和，價格在[L,R]中的所有元素就位於[lo,hi)，總額為p[hi]-p[lo]。這裡的前綴索引直接對應切片端點，不使用lo-1；要分清數值範圍與題目位置區間的不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [2, 4, 4, 9]
p = [0, 2, 6, 10, 19]
lo, hi = bisect_left(a, 4), bisect_right(a, 8)
print(p[hi]-p[lo])
展開範例結果
8

UNIT C / E

C｜距離限制內的最近讀值

排序後離目標最近的值，只可能在下界位置或其前一格；更遠的索引不會更接近。先收集合法候選，再按距離比較，平手取較小數值。多加一個最大容許距離時，應在選好最近值之後判斷是否合格，找不到範圍內候選就輸出NONE，而不是任意回傳邊界值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
target, limit, value = 6, 1, 4
print(abs(value-target) <= limit)
展開範例結果
False

UNIT D / E

D｜第k次相同值可能不存在

同值在排序序列中形成一個連續區塊。找到第一個t的位置lo後，第k個t應在lo+k-1，但還要檢查它是否越界、是否仍等於t，不能只算索引就輸出。資料中沒有t時，下界可能指向下一個更大值，這也是需要檢查相等的原因。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
lo, k = 2, 3
print(lo+k-1)
展開範例結果
4

UNIT E / E

E｜多個預算各能買幾件

若只想讓件數最多且每件至多買一次，固定件數k時選最便宜k件成本最低，因此排序後的前綴和給出各件數的最低成本。價格非負讓前綴和非遞減，可用bisect_right找最後一個不超過預算的位置。零元商品會造成相同前綴值，右界才能把免費件數全部納入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_right
p = [0, 0, 0, 5]
print(bisect_right(p, 0)-1)
展開範例結果
2
