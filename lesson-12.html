串列裡再放串列

範例 · 先預測，再核對

print(grid[1][0])

單元 B / E

逐列統計

一列本身就是串列，for row in grid 取得整列，再用內層累加。每一列的 total 都要重新歸零。

範例 · 先預測，再核對
grid = [[1, 2], [3, 4]]
for row in grid:
    total = 0
    for value in row:
        total += value
    print(total)
展開範例結果
3
7

單元 C / E

逐欄統計

要統計一欄，固定 c、改變 r。讀入時每次 append 一個新 row，不要用 [[0]*c]*r 建立可修改的矩陣，那會讓各列共用同一個串列。

範例 · 先預測，再核對
grid = [[1, 2, 3], [4, 5, 6]]
for c in range(3):
    total = 0
    for r in range(2):
        total += grid[r][c]
    print(total)
展開範例結果
5
7
9

單元 D / E

轉置不是旋轉

轉置把原本第 c 欄變成新矩陣的第 c 列。print(*row) 的星號會把串列拆成多個 print 參數，輸出空格分隔的值，不含中括號。

範例 · 先預測，再核對
grid = [[1, 2, 3], [4, 5, 6]]
for c in range(3):
    row = []
    for r in range(2):
        row.append(grid[r][c])
    print(*row)
展開範例結果
1 4
2 5
3 6

單元 E / E

鄰格一定先檢查邊界

上下左右可表示為四組位移 (-1,0)、(1,0)、(0,-1)、(0,1)。先確認新座標 0<=nr<列數 且 0<=nc<欄數，才讀 grid[nr][nc]。Python 的負索引有效，所以漏檢查可能悄悄讀到最後一列。

範例 · 先預測，再核對
r, c = 0, 0
for dr, dc in [(-1,0),(1,0),(0,-1),(0,1)]:
    nr, nc = r + dr, c + dc
    if 0 <= nr < 2 and 0 <= nc < 2:
        print(nr, nc)
展開範例結果
1 0
0 1
