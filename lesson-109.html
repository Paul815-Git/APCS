UNIT D / E

D｜考後選做：遞迴數零位

數字中零的數量與數值為零的基底容易混淆。直接把零當作一位數並回傳一，其他單位數回傳零，多位數才檢查末位並遞迴。這能避免把遞迴最後的空前綴再算成額外一個零；用沒有零的數字和整數零本身分別驗證兩種情況。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def zeros(n):
    if n < 10:
        return int(n == 0)
    return int(n % 10 == 0) + zeros(n // 10)
print(zeros(1002))
展開範例結果
2
