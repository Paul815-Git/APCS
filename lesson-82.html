UNIT A / E

A｜父節點與直接孩子

樹選定根後，除根以外每個節點都有唯一父節點。孩子只指直接相連的下一層，後代則包含更深層節點，兩者不能混用。本課輸入保證父編號小於子編號，因此一定能一路往較小編號回到根，不需要先寫圖合法性檢查。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parents = [1, 1, 2]
children = [0] * 5
for p in parents:
    children[p] += 1
print(*children[1:])
展開範例結果
2 1 0 0

UNIT B / E

B｜深度由父節點加一

深度是從根到節點的邊數，根的深度為零，孩子深度是父親加一。因為題目保證父編號較小，依編號順序計算時父親答案一定已經存在。這個順序前提若被取消，就需要先從根走訪，不能對任意父編號資料直接照同樣迴圈計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parent = [0, 0, 1, 2]
depth = [0] * 4
for u in range(2, 4):
    depth[u] = depth[parent[u]] + 1
print(*depth[1:])
展開範例結果
0 1 2

UNIT C / E

C｜根也可能是葉節點

有根樹的葉節點定義為沒有孩子，與無向圖的度數為一不完全相同。只有根的一節點樹，根沒有孩子，所以也是葉。可以先標記每個出現過的父節點，再掃出沒有孩子者；輸出依節點編號遞增，與樹的左右畫法無關。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
has_child = [False, True, False, False]
for u in range(1, 4):
    if not has_child[u]:
        print(u)
展開範例結果
2
3

UNIT D / E

D｜由孩子向父親累加

子樹包含節點自己與所有後代。先讓每點大小為一，再倒序將孩子的完整大小加入父親。因為父編號較小，倒序處理確保所有後代都已先累積完成，這是後序處理的一種簡化。若正序加上去，父親收到的可能只是尚未完整的孩子大小。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parent = [0, 0, 1, 2]
size = [1] * 4
for u in range(3, 1, -1):
    size[parent[u]] += size[u]
print(*size[1:])
展開範例結果
3 2 1

UNIT E / E

E｜沿父節點尋找共同祖先

樹上兩點的唯一路徑會先向上到共同祖先，再向下到另一點。先把較深者往上移到相同深度，再讓兩者一起向上，首次相遇就是最近的共同祖先。每上移一次增加一條邊；本題規模較小，直接走父鏈即可，不需要額外引入進階跳躍表。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parent = [0, 0, 1, 1, 2]
u = 4
chain = []
while u != 0:
    chain.append(u)
    u = parent[u]
print(*chain)
展開範例結果
4 2 1
