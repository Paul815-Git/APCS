UNIT A / E

A｜奇數位置不是奇數數值

題目若依位置篩選，就不能拿元素本身的奇偶判斷。本題使用一開始的位置，第一筆屬奇數位置，對應Python索引零。先把位置與值各寫一列，再標出應加入的元素；用偶數值放在奇數位置的資料，最容易看出把兩種奇偶混用的錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [8, 1, 6]
print(a[0] + a[2])
展開範例結果
14

UNIT B / E

B｜庫存每件只能使用一次

查詢是否存在和實際領取一件不同，成功領取後必須扣除次數，後面才能看見新的庫存。集合無法表達多件同款商品，所以使用頻率字典。庫存降到零仍可留在字典，但判斷應是次數大於零，而不是鍵還在不在，否則會讓已用完的品項繼續成功。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stock = {"a": 1}
stock["a"] -= 1
print(stock.get("a", 0) > 0)
展開範例結果
False

UNIT C / E

C｜環狀鄰居同步相加

同步更新必須讀取舊陣列，若直接覆蓋左邊元素，後面就會用到已更新的新值。這題每格的新值是原左右鄰居的和，環狀索引用取模處理；當長度只有一時，左右鄰居都指向自己，依規則要加兩次，不能自行把重複座標去重。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 5, 7]
print(a[-1] + a[1])
展開範例結果
12

UNIT D / E

D｜約分保留分母正號

分數約分要用分子絕對值與正分母的最大公因數，之後分子、分母都以整數除法除去。負號只保留在分子，零分子約分後應得到零比一。這題避免浮點除法，因為題目要求整數形式，且數字很大時浮點數無法精確保存每一個整數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from math import gcd
a, b = -6, 8
g = gcd(abs(a), b)
print(a // g, b // g)
展開範例結果
-3 4

UNIT E / E

E｜查詢指令沒有第二欄

不同指令的欄位數不同，讀入後不能無條件存取第二欄。先判斷指令種類，再讀它需要的欄位；ASK只要求輸出目前狀態，RESET則清空，ADD才帶數值。把沒有參數的指令放在第一行測試，可以立即發現解析器是否錯誤假設每行都有兩欄。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parts = "ASK".split()
print(parts[0], len(parts))
展開範例結果
ASK 1
