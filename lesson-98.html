UNIT A / E

A｜指定格的可走出口

鄰格檢查分成座標存在與內容可走兩個條件，順序不可交換。Python 的負索引可能讀到另一邊，因此看起來沒有報錯不代表座標正確。這裡只統計一步可以走到的方向，不計目前格，也不計對角；一格地圖是檢查四個邊界最直接的資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = ["..", ".#"]
count = 0
for dr, dc in [(1,0),(-1,0),(0,1),(0,-1)]:
    r, c = dr, dc
    if 0 <= r < 2 and 0 <= c < 2 and g[r][c] == ".":
        count += 1
print(count)
展開範例結果
2

UNIT B / E

B｜碰壁原地停留

移動指令先產生候選座標，再檢查候選是否在地圖內且不是障礙，最後才更新目前座標。把檢查和賦值分開，就不必在失敗時倒退回去。多個連續撞牆指令不會改變位置；測試中要保留這種重複失敗，確認狀態沒有逐步漂移。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
x, y = 0, 0
nx, ny = x - 1, y
if 0 <= nx < 2 and 0 <= ny < 2:
    x, y = nx, ny
print(x, y)
展開範例結果
0 0

UNIT C / E

C｜只擴散一輪

同步更新的所有新狀態都只能讀取舊地圖。若在原地逐格修改，剛變成感染的格子可能同輪繼續傳播，造成方向相關的結果。先複製每一列，再由舊的一標記新鄰格；本題只做一輪，所以相隔兩格的位置不應因中間格剛被改變而連帶更新。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
old = [[1, 0, 0]]
new = []
for row in old:
    new.append(row[:])
new[0][1] = 1
print(*old[0])
print(*new[0])
展開範例結果
1 0 0
1 1 0

UNIT D / E

D｜格子周長看四邊

每個填色格先考慮四條邊，某邊外側出界或是空格，這條邊就屬於外露周長。內部共享邊不應算入，但不需要另外找整個形狀的輪廓。此方法也適用多個分離區塊與洞，因為題目計算所有外露邊，包括洞邊；全空地圖則自然得到零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = [[1, 1]]
print(4 * 2 - 2)
展開範例結果
6

UNIT E / E

E｜最短步數含零步

每一步成本相同時，佇列搜尋會先處理較近的格子，所以第一次記錄距離就是最少步數。距離初始化為負一表示尚未到達，起點則是零；加入佇列時立即設定距離，能避免同一格被多個鄰格重複加入。起終點相同應得到零，不必真的移動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from collections import deque
q = deque([(0, 0)])
distance = [[0, -1]]
distance[0][1] = distance[0][0] + 1
q.append((0, 1))
print(distance[0][1])
展開範例結果
1
