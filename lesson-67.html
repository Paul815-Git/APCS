UNIT A / E

A｜用出現次數重建順序

數值只在小範圍內時，可為每種值配置一格次數。先掃輸入計數，再按值由小到大輸出對應次數，便完成排序。工作量約為資料筆數加值域大小；若最大值非常大，直接配置巨大串列就不適合，應改用一般排序或座標壓縮。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = [0] * 4
for x in [3, 1, 3]:
    count[x] += 1
answer = []
for x in range(4):
    for _ in range(count[x]):
        answer.append(x)
print(*answer)
展開範例結果
1 3 3

UNIT B / E

B｜負數要平移索引

串列索引不能直接拿負數作一般桶號，因為負索引會從尾端回數。若值域下界是負五十，可將每個值加五十映射到非負索引；輸出時再減五十還原。平移保持大小順序，而且桶數應等於上界減下界再加一，包含兩端。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
offset = 2
count = [0] * 5
for x in [-2, 0, -2]:
    count[x + offset] += 1
for i in range(5):
    if count[i]:
        print(i - offset, count[i])
展開範例結果
-2 2
0 1

UNIT C / E

C｜不重建全部排序結果找排名

要求第幾小的值，不一定需要展開整份排序串列。按桶從小到大累加次數，第一次累積數量達到排名的位置，就是答案。排名從一開始，而桶索引從零開始，兩者不可混淆；重複值佔多個排名，不能先去重再計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = [0, 2, 0, 1]
k, total = 2, 0
for x in range(len(count)):
    total += count[x]
    if total >= k:
        print(x)
        break
展開範例結果
1

UNIT D / E

D｜眾數的平手規則

眾數依據次數比較，並不是排序後最大的數。本題同次數選較小值，因此從小到大掃桶且只在嚴格更高次數時更新，便可自然保留較小者。若寫成大於或等於，後來的較大值會覆蓋答案，這正是需要特別測試的平手邊界。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = [0, 2, 2]
best = 0
for x in range(len(count)):
    if count[x] > count[best]:
        best = x
print(best, count[best])
展開範例結果
1 2

UNIT E / E

E｜桶內保存同分輸入順序

如果每筆資料還有姓名，單純次數不足以還原紀錄，可以把每個分數的桶改成姓名串列。依輸入順序加入同一桶，再按分數順序輸出，便保有同分原順序。建立多個桶時每次要建新串列，避免使用重複參照讓所有桶一起變動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
buckets = []
for _ in range(3):
    buckets.append([])
buckets[2].append('Amy')
buckets[2].append('Bob')
print(*buckets[2])
print(len(buckets[0]))
展開範例結果
Amy Bob
0
