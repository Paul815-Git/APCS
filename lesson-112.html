UNIT A / E

A｜獨立題一：連續合格批次

開始計時前只確認輸入輸出格式，作答時先自行決定狀態，不立即看提示。題目要的是最長連續合格片段，並非合格總數；相等門檻仍合格。完成後用全合格、全不合格與中間斷開各測一次，這些資料分別檢查累積、重設與結束位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
threshold = 5
print(5 >= threshold, 4 >= threshold)
展開範例結果
True False

UNIT B / E

B｜獨立題二：累計配送榜

同一站可能有多筆配送紀錄，應先按名稱合併數量，再比較總量。若直接挑最大單筆，可能忽略多次小額累加的站點。同總量時名稱較前者優先，這是答案的一部分；作答時先寫一組單筆冠軍與累計冠軍不同的測資，驗證自己真的使用正確資訊。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = {"a": 4, "b": 4}
print(sorted(count)[0])
展開範例結果
a

UNIT C / E

C｜獨立題三：展位用電核對

查詢對象是連續展位的位置區間，且每次資料不變，適合先保存累積量。輸出包含實際總量以及是否超出上限，兩部分都必須符合；剛好等於上限不算超出。獨立作答時先手算第一格到最後一格的查詢，確認位置編號與端點公式，再測單格區間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
used, limit = 7, 7
print(used, "SAFE" if used <= limit else "OVER")
展開範例結果
7 SAFE

第一行n q（1–10000），第二行n個0–1000用電量，後q行l r limit（1≤l≤r≤n，0≤limit≤10^7）。每行輸出區間總量及SAFE（不超上限）或OVER。

前綴差p[r]-p[l-1]，判斷<=limit。

UNIT D / E

D｜考後訂正：並列最多的所有站

這個新題不只選一個冠軍，而是輸出所有並列最高者，因此前題保留單一最佳名稱的變數不足以回答。先完成全部累計，再取得最高量，最後按名稱排序篩選相等者。把求最高與列名單分成兩段，可以避免暫時領先者在後面被追過時仍留在名單。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
totals = {"a": 3, "b": 3, "c": 1}
best = max(totals.values())
print(best)
展開範例結果
3

UNIT E / E

E｜考後加練：區間淨變化

把用量改成正負變化後，前綴差仍然成立，因為它只依賴加法可相減；但依非負條件設計的伸縮視窗不一定適用。這題讓每個查詢判斷區間淨變化是增加、減少或不變，必須保留符號，不能把負值直接忽略或取絕對值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = [0, 3, 1, 0]
print(p[3] - p[1])
展開範例結果
-3
