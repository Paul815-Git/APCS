保存每一步的累積結果

prefix[0]=0，prefix[i] 代表前 i 個元素的總和。比原串列多一格，是為了讓空的前綴也能表示。每次 append(prefix[-1]+value)。

範例 · 先預測，再核對
prefix = [0]
for value in [3, 5, 2]:
    prefix.append(prefix[-1] + value)
print(*prefix)
展開範例結果
0 3 8 10

單元 B / E

含端點的区間公式

本課題目位置從 1 起算。第 l 到第 r 個元素總和，是前 r 個的和減去前 l-1 個的和，也就是 p[r]-p[l-1]。不要和 Python 的切片終點混淆。

範例 · 先預測，再核對
p = [0, 3, 8, 10]
l, r = 2, 3
print(p[r] - p[l-1])
展開範例結果
7

單元 C / E

多次查詢只建立一次

建立 p 需要 O(n)，每次查詢只做一次減法 O(1)，q 次總計 O(n+q)。這裡 n 是資料筆數，q 是查詢數；不要在每個查詢內重建前綴和。

範例 · 先預測，再核對
p = [0, 2, 6, 12]
for l, r in [(1, 3), (2, 2)]:
    print(p[r] - p[l-1])
展開範例結果
12
4

單元 D / E

把條件換成 0 與 1

前綴和不只加原數值。若每筆及格記 1、不及格記 0，區間和就代表區間及格人數。將問題轉成可累積的數值很有用。

範例 · 先預測，再核對
p = [0]
for score in [50, 60, 90]:
    flag = 0
    if score >= 60:
        flag = 1
    p.append(p[-1] + flag)
print(p[3] - p[1])
展開範例結果
2

單元 E / E

固定長度的最佳區間

長度 k 的片段，若右端位置 r，左端就是 r-k+1，總和 p[r]-p[r-k]。右端從 k 到 n，每次前進一格即可。全負數時不要用 0 當最佳值。

範例 · 先預測，再核對
nums = [-5, -2, -3]
p = [0]
for v in nums:
    p.append(p[-1]+v)
k = 2
best = p[k]
for r in range(k, len(nums)+1):
    best = max(best, p[r]-p[r-k])
print(best)
展開範例結果
-5
