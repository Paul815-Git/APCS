UNIT A / E

A｜保留原始版本

把串列指定給另一個變數，只是多一個名稱指向同一份資料。若要保留修改前版本，一維整數串列可以用切片建立副本。本題要印出修改前後兩份結果，讓看不見的共用關係變成可觀察的輸出；只印修改後版本會漏掉原始資料被改壞的問題。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 4]
b = a[:]
b[0] = 9
print(*a)
print(*b)
展開範例結果
2 4
9 4

UNIT B / E

B｜每一列都要新建

二維串列包含的是一列一列的串列。用同一列重複填入外層，修改一格就可能讓很多列一起改變。正確方法是每次外層迴圈重新建立一列；以不同列、同一欄的兩次更新測試，才能確認各列真的互不影響，而不只是外觀看起來有多列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = []
for i in range(2):
    g.append([0] * 2)
g[0][1] = 5
print(g[1][1])
展開範例結果
0

UNIT C / E

C｜巢狀資料逐列複製

外層切片只能複製外層容器，裡面的各列仍可能共用。當每格都是整數時，逐列切片就足以建立可獨立修改的矩陣。本題以整列增加作為修改操作，並同時輸出原矩陣總和及副本總和，檢查原資料是否真的保持不變。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [[1, 2], [3, 4]]
b = []
for row in a:
    b.append(row[:])
b[0][0] = 9
print(a[0][0], b[0][0])
展開範例結果
1 9

UNIT D / E

D｜快照不能隨未來變動

紀錄歷史時應保存當下內容，而不是保存日後仍會修改的同一個容器。這裡在指定步驟建立一次快照，後續操作只改目前狀態。零步快照代表初始資料，不需要任何更新；把零步和最後一步分開測試，能檢查存檔時機是否放對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
current = [1]
saved = current[:]
current.append(2)
print(*saved)
print(*current)
展開範例結果
1
1 2

UNIT E / E

E｜計畫與現況分離

同一份初始庫存可以產生兩套獨立計畫；兩者都必須從初始狀態出發，不能讓第二套接續第一套的結果。字典的值如果都是整數，copy 就能分開各鍵的數值更新。先讀完整初始資料，再建立兩份副本，能清楚界定資料生命週期。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
base = {"a": 3}
plan = base.copy()
plan["a"] += 2
print(base["a"], plan["a"])
展開範例結果
3 5
