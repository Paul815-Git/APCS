UNIT A / E

A｜合法括號的最深層

只計算最大深度之前，仍需先確認整個括號序列合法。左括號讓目前深度增加，右括號減少；任何時刻變負表示出現沒有配對的右括號，最後不為零表示仍有未關閉者。空字串合法且深度零，不能把沒有任何括號當作錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
depth = peak = 0
for ch in "(())":
    depth += 1 if ch == "(" else -1
    peak = max(peak, depth)
print(peak)
展開範例結果
2

UNIT B / E

B｜右括號找到左端位置

堆疊不一定只存括號字元，也可以存對應位置。遇到右括號時，最近未配對的左位置就是它的夥伴，所以彈出索引即可。輸入已保證合法，本題重點是順序：按右括號出現順序輸出，不是按左端排序；內層配對會比外層更早完成。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stack = []
for i, ch in enumerate("(())", 1):
    if ch == "(":
        stack.append(i)
    else:
        print(stack.pop(), i)
展開範例結果
2 3
1 4

UNIT C / E

C｜每人最多做兩單位

輪轉佇列每回合處理固定上限的工作量，未完成者回到隊尾，完成者離開。工作編號要隨紀錄一起保存，不能用當下佇列位置代表身分。與一次做一單位相比，本題每次減二但可能只剩一；以剩餘量不大於零作完成條件，能正確處理最後一小段。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from collections import deque
q = deque([(1, 3), (2, 1)])
job, remaining = q.popleft()
remaining -= 2
q.append((job, remaining))
print(q[0][0])
展開範例結果
2

UNIT D / E

D｜左右都能加入的候車列

deque 可以在左端或右端加入元素，移除方向仍由題目指定。這次一般乘客加到右端，優先乘客加到左端，服務一律取左端；連續優先加入會讓後來者更前面，這是本題明訂規則。空隊列服務必須輸出標記，不可直接移除而發生錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from collections import deque
q = deque(["a"])
q.appendleft("b")
print(q.popleft())
展開範例結果
b

UNIT E / E

E｜撤回一次設定值

撤回設定與撤回加法不同，必須記住修改前的舊值，不能只存變動後的新值。每次設定先把目前值放進堆疊，再更新；撤回時取回最近保存的舊值。被忽略的空撤回不會新增歷史，因此下一次設定仍從目前狀態開始，這能用連續撤回檢查。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
value = 3
history = []
history.append(value)
value = 8
value = history.pop()
print(value)
展開範例結果
3
