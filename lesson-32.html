UNIT A / E

A｜展開一個片段

字串乘上非負整數會重複該字串，例如"ab"乘三會得到三份ab。壓縮片段的字元和次數屬於不同型別，split後的次數仍是文字，必須先轉成int。這題只展開一段，先把解析與重複的規則確認清楚，再處理多段資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
ch, count = "x 4".split()
print(ch * int(count))
展開範例結果
xxxx

UNIT B / E

B｜依序接回多個片段

解碼不能按照字母排序，因為片段出現順序就是原資料順序。逐段展開後存入串列，最後用空分隔符join接回，可以清楚區分「讀一段」與「組合整份結果」。相鄰片段就算字元相同也可以直接接上，解碼不要求先重新壓縮。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parts = ["a" * 2, "b" * 1, "a" * 2]
print("".join(parts))
展開範例結果
aabaa

UNIT C / E

C｜只問長度就不展開

當題目只問解碼長度，每段的字元內容不影響答案，長度就是所有次數的總和。即使次數非常大，整數加法仍不需要建立對應字串。這與前綴和先累積數值的想法相同：只保存輸出真正需要的資訊，會讓程式更快也更省空間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total = 0
for count in [1000000, 0, 8]:
    total += count
print(total)
展開範例結果
1000008

UNIT D / E

D｜先檢查容量再建立結果

輸出長度有上限時，應先讀完片段並加總次數，再決定要不要展開，不能先做出巨大字串才檢查。長度恰好等於上限仍合法；超過才拒絕。把片段保存成字元與次數兩欄，通過檢查後再走一次迴圈，時間仍與輸入及合法輸出長度成正比。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
length, limit = 6, 6
if length <= limit:
    print("OK")
else:
    print("TOO LONG")
展開範例結果
OK

UNIT E / E

E｜不用展開也能找第幾個字

想找解碼後的第p個字，可以把p視為尚未跨過的距離。若p大於本段長度，就減去整段長度；否則答案位於這一段。這裡位置從一開始，故p等於段長時仍屬於本段。零長度片段自然被略過，也不會改變剩餘距離。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = 5
for ch, count in [["a", 3], ["b", 4]]:
    if p <= count:
        print(ch)
        break
    p -= count
展開範例結果
b
