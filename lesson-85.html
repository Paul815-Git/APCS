UNIT A / E

A｜每個小答案只算一次

動態規劃先為每格定義明確意思，再依賴已算好的小問題填表。每次走一或二階時，到第 i 階的最後一步只可能來自 i-1 或 i-2，所以方法數相加。第零階有一種不走的方法，是後續轉移的起點；它不是零種，否則所有答案都無法產生。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dp = [0] * 5
dp[0] = 1
for i in range(1, 5):
    dp[i] = dp[i - 1]
    if i >= 2:
        dp[i] += dp[i - 2]
print(*dp)
展開範例結果
1 1 2 3 5

UNIT B / E

B｜最小成本用最小值合併

狀態改成到某階的最低成本時，合併方式就由相加方法數改成取較小成本，再加落腳這一階的費用。到達方式相同，不代表狀態與運算也相同。起點不收費，第一階只能由零階過來；第二階開始才有兩個合法前驅，避免使用負索引當不存在的階梯。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
cost = [0, 5, 1, 4]
dp = [0, 5, 0, 0]
for i in range(2, 4):
    dp[i] = min(dp[i - 1], dp[i - 2]) + cost[i]
print(dp[3])
展開範例結果
5

UNIT C / E

C｜二維狀態的依賴方向

格子只准向右或向下走時，到一格的最後一步只可能來自左邊或上面。按列由上到下、每列由左到右填表，就保證兩個依賴都已經完成。左上角是唯一基底，其餘位置依合法鄰格相加；沒有前驅的方向應略過，不能用負索引繞到最後一列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dp = [[0] * 3 for _ in range(2)]
dp[0][0] = 1
for r in range(2):
    for c in range(3):
        if r > 0:
            dp[r][c] += dp[r - 1][c]
        if c > 0:
            dp[r][c] += dp[r][c - 1]
print(dp[-1][-1])
展開範例結果
3

UNIT D / E

D｜禁止落腳的狀態維持零

破損階梯不能落腳，因此對應狀態應維持零種方法，不進行一般轉移。仍可從前兩階跨越它，只要落點合法即可。禁止某格與禁止跨過某格不同，必須按題意分清楚；終點破損時答案為零，起點則依本題保證不破損。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
blocked = {2}
dp = [1, 0, 0, 0]
for i in range(1, 4):
    if i in blocked:
        continue
    dp[i] = dp[i - 1]
    if i >= 2:
        dp[i] += dp[i - 2]
print(dp[3])
展開範例結果
1

UNIT E / E

E｜選目前項就跳過前一項

選取不能相鄰的數值時，處理前 i 項的最佳值有兩種來源：不選第 i 項，沿用前 i-1 項；選它，就只能加上前 i-2 項最佳值。兩種情況涵蓋所有合法選法，取最大即可。允許空選時，全負數應得到零，初始化也要遵守這項定義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [5, 1, 6]
dp = [0] * 4
for i in range(1, 4):
    take = a[i - 1]
    if i >= 2:
        take += dp[i - 2]
    dp[i] = max(dp[i - 1], take)
print(dp[3])
展開範例結果
11
