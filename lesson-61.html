UNIT A / E

A｜手寫第一個不小於

下界的位置把串列分成兩部分：左邊全部小於目標，右邊全部不小於目標。使用左閉右開的搜尋區間，讓長度也能當答案。中點值相等時仍保留左半邊，因為更早的位置可能相等；只有確定太小時，才把中點一起排除。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 5, 5, 9]
lo, hi = 0, len(a)
while lo < hi:
    mid = (lo + hi) // 2
    if a[mid] < 5:
        lo = mid + 1
    else:
        hi = mid
print(lo)
展開範例結果
1

UNIT B / E

B｜相等時也往右找

上界要找第一個嚴格大於目標的位置，所以遇到相等值仍要往右移。這與下界只差一個等號，語意卻不同。上界左側的元素都小於或等於目標，因此上界位置本身也等於這類元素的個數；資料必須先有序，才有連續的左右分界。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 4, 4, 7]
lo, hi = 0, len(a)
while lo < hi:
    mid = (lo + hi) // 2
    if a[mid] <= 4:
        lo = mid + 1
    else:
        hi = mid
print(lo)
展開範例結果
3

UNIT C / E

C｜嚴格前驅與嚴格後繼

要找比目標小的最大值，可以取下界前一格；要找比目標大的最小值，可以取上界那一格。兩者刻意跳過所有相等值。先檢查位置是否存在才取值，不能把索引負一當成不存在，因為 Python 會把它解讀成最後一個元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [2, 4, 4, 9]
print(a[bisect_left(a, 4) - 1])
print(a[bisect_right(a, 4)])
展開範例結果
2
9

UNIT D / E

D｜空的開區間

開區間不包含兩個端點。大於左端的起點用上界，小於右端的終點用下界，兩者相減得到數量。不過左右端相等時，起點可能越過終點，直接相減會得到負數；題意上的空集合必須明確回傳零，不能讓公式掩蓋前提。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [1, 2, 2, 3]
print(bisect_left(a, 3) - bisect_right(a, 1))
l, r = 2, 2
if l == r:
    print(0)
else:
    print(bisect_left(a, r) - bisect_right(a, l))
展開範例結果
2
0

UNIT E / E

E｜半開時間窗查詢

資料的時間戳記可能重複，但每筆事件都要計數。時間窗採左含右不含，讓相鄰兩個窗不會重複計入交界事件。兩個端點都使用下界，先排序一次再回答多次查詢；空時間窗會自然得到零，不需要逐事件重新掃描。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left
times = [2, 5, 5, 8]
print(bisect_left(times, 8) - bisect_left(times, 5))
展開範例結果
2
