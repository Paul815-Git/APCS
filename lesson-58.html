UNIT A / E

A｜排序後只比較最後一段

先依起點排序，新的區間若起點不超過目前段的終點，就與目前段重疊或相接，可以延伸終點。延伸要取max，因為新區間可能完全被包住。若起點更大，就開始新段；已完成的更早區間不可能再被後面的區間碰到，所以只需查看最後一段。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
current = [1, 8]
new = [3, 5]
current[1] = max(current[1], new[1])
print(*current)
展開範例結果
1 8

UNIT B / E

B｜總覆蓋長度不能直接加原長度

重疊區間的長度若直接相加，交集會算很多次。先合併成互不重疊的段，再累加每段end-start即可。這裡是連續時間的半開區間，不是整數格點個數，所以長度不加一。即使座標上億，也只處理輸入區間，不需要建立每個時間點的陣列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
merged = [[1, 5], [8, 10]]
total = 0
for start, end in merged:
    total += end-start
print(total)
展開範例結果
6

UNIT C / E

C｜合併後才能找真正空檔

尋找空檔時，原區間相鄰兩筆的端點不一定代表空白，因為較早的長區間可能仍覆蓋那裡。先合併，再用上一段終點到下一段起點作為空檔。還要納入觀察範圍開頭到第一段、最後一段到結尾的兩個空白區，不能只看中間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
merged = [[2, 5], [8, 9]]
previous, best = 0, 0
for start, end in merged:
    best = max(best, start-previous)
    previous = end
best = max(best, 12-previous)
print(best)
展開範例結果
3

UNIT D / E

D｜沒有長度的區間不算一段

允許s=e時，半開區間[s,s)是空集合，不占時間也不能把兩個區間連接起來。因此讀入時先忽略空區間，再套合併規則。所有輸入都空或n為零時，合併結果就是空串列，段數為零；不要直接用第一段初始化，否則會遇到不存在的元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
intervals = [[2, 2], [3, 5]]
kept = []
for start, end in intervals:
    if start < end:
        kept.append([start, end])
print(len(kept))
展開範例結果
1

UNIT E / E

E｜找最早能預約的空檔

要放入長度D的新預約，不必枚舉每個時間點。合併忙碌區間後，最早可能開始的位置是零或某個忙碌段的終點；若到下一段開始前至少有D長，就立即找到最早答案。整個日程最後還有一個到L的空檔，也必須檢查，恰好放滿是合法情況。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
candidate, next_busy, duration = 4, 7, 3
print(candidate + duration <= next_busy)
