UNIT A / E

A｜最佳連續和在此結尾

最大連續片段和不能跳過中間元素。令ending表示一定以目前位置結尾的最佳總和，新值可以獨立開始，也可以接在前一個ending後。整體最佳值另行保存，不能把「在此結尾」與「截至目前的最佳」混成一個狀態。非空片段要求全負時也選一個元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [-4, 3, -1, 2]
ending = best = a[0]
for x in a[1:]:
    ending = max(x, ending + x)
    best = max(best, ending)
print(best)
展開範例結果
4

UNIT B / E

B｜遞增子序列可以跳過元素

子序列保留原順序，但不必連續。令dp[i]為以a[i]結尾的最長嚴格遞增子序列長度，嘗試所有較早且值更小的位置接過來，再加一。每個元素自己就是長度一的子序列；相等不符合嚴格遞增，因此不能用小於或等於，空資料則另有零答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [3, 1, 2, 4]
dp = [1] * len(a)
for i in range(len(a)):
    for j in range(i):
        if a[j] < a[i]:
            dp[i] = max(dp[i], dp[j] + 1)
print(max(dp))
展開範例結果
3

UNIT C / E

C｜記錄前一位置還原子序列

若要輸出實際子序列，更新長度時也保存最佳前一位置。結束後從最長狀態沿前驅回走，反轉得到原順序。本題明定平手保留較早前驅，且同長結尾取較早索引；按索引遞增並只在嚴格改善時更新，就能得到可重現的選法，並非宣稱字典序最小。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 3, 2, 4]
parent = [-1, 0, 0, 1]
path, i = [], 3
while i != -1:
    path.append(a[i])
    i = parent[i]
print(*path[::-1])
展開範例結果
1 3 4

UNIT D / E

D｜同樣遞增條件改求總和

遞增子序列的轉移條件不變，但目標若改成最大總和，每格初始值應是自己的數值，轉移也應加目前值而非加一。長度最長未必總和最大，尤其有負數時更明顯。本題要求非空，所以不能用全零初始化來偷偷允許不選任何元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [-5, 2, 3]
dp = a.copy()
for i in range(len(a)):
    for j in range(i):
        if a[j] < a[i]:
            dp[i] = max(dp[i], dp[j] + a[i])
print(max(dp))
展開範例結果
5

UNIT E / E

E｜相鄰選取值需奇偶交替

子序列的相容條件也可以不是大小，而是最後一個值的奇偶性不同。仍令dp[i]表示在i結尾的最佳長度，掃所有較早、奇偶不同的位置接續。Python對負整數取二的餘數仍可分奇偶；要比較餘數是否不同，不要用數值正負代替奇偶分類。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 4, 3, 5, 8]
dp = [1] * len(a)
for i in range(len(a)):
    for j in range(i):
        if a[j] % 2 != a[i] % 2:
            dp[i] = max(dp[i], dp[j] + 1)
print(max(dp))
展開範例結果
3
