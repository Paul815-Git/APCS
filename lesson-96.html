UNIT A / E

A｜區間和雙算

前綴和公式可能寫錯一個端點，而逐項累加能直接對應題目定義。小資料時同時輸出兩個答案，便能用差異定位問題。兩個方法應獨立取得結果，不要讓慢解也呼叫前綴和公式；否則相同錯誤可能在兩邊一起出現，失去交叉驗證的意義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 5, 1]
print(sum(a[1:3]))
p = [0, 2, 7, 8]
print(p[3] - p[1])
展開範例結果
6
6

UNIT B / E

B｜配對頻率核對

兩層迴圈直接枚舉位置配對，適合拿來驗證字典計數版本。快速版先查過去出現的補數，再把目前值加入頻率表，才能避免配到自己。重複值是本題必要測試，因為集合只能表示出現與否，無法保留同值出現多次形成的不同位置配對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
seen = {2: 2}
x, target = 3, 5
print(seen.get(target - x, 0))
展開範例結果
2

UNIT C / E

C｜下界的線性證人

下界不是最近值，而是第一個不小於目標的位置。慢解由左往右找第一個符合者，快速版用二分排除不可能的半邊；兩者結束時都可能回傳長度。測試目標小於所有值、落在重複值上、以及大於所有值，可以同時涵蓋兩端與中間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 3, 3]
t = 4
answer = len(a)
for i in range(len(a)):
    if a[i] >= t:
        answer = i
        break
print(answer)
展開範例結果
3

UNIT D / E

D｜視窗最大值不假設非負

慢解逐一重新加總每個固定長度片段，快速版維護滑動總和。這兩個方法都適用含負數的資料，但最佳值都必須從實際片段初始化。若兩邊都以零起算，全負數測試會同時出錯，因此核對答案之外，還要核對初始化是否符合題目定義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [-4, -2, -3]
print(max(sum(a[0:2]), sum(a[1:3])))
展開範例結果
-5

UNIT E / E

E｜計算被覆整數點

小值域可以逐點查詢是否落在任一閉區間，差分則把每段影響記在起點及終點後一格。兩個答案分別來自直接定義與累加狀態，適合抓出右端點漏算。相接區間共享的點只算一次，這與把所有區間長度相加不同，重疊測資不可省略。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
diff = [0] * 5
diff[1] += 1
diff[3] -= 1
active = 0
for x in range(4):
    active += diff[x]
    print(active)
展開範例結果
0
1
1
0
