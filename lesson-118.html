UNIT A / E

A｜去掉一高一低的總分

讀題先確認刪除的是各一個位置，而不是刪掉所有等於最高或最低的值。即使全部分數相同，也只去除兩筆，因此至少三筆資料的保證很重要。總和減最大值再減最小值就能表達這個規則；用多個相同最高分測試，確認重複值沒有被整批移除。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [5, 5, 2]
print(sum(a) - max(a) - min(a))
展開範例結果
5

UNIT B / E

B｜每段警報只記一次

連續超標只觸發一個警報事件，回到安全範圍後再次超標才算下一個。用布林狀態記錄上一筆是否正在超標，新值超標且之前不是才增加事件數。這比把所有超標筆數相加更符合事件定義；第一筆就超標也應觸發一次，初始狀態需設為安全。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
active = False
value, limit = 8, 5
print(value > limit and not active)
展開範例結果
True

UNIT C / E

C｜預約占用總時長

占用總時長要計算區間聯集，重疊時間不能重複相加。先按起點排序，維持目前合併段的左右端；遇到接得上的區間就擴大右端，遇到分離段才結算前一段。時間區間長度是右端減左端，不是整數點數，因此不需要加一，空預約答案為零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
left, right = 2, 5
right = max(right, 7)
print(right - left)
展開範例結果
5

UNIT D / E

D｜路線經過幾個不同格

路線長度和經過不同格數不同，走回原地不會增加新格數。每次依方向更新座標後放入集合，並且先放入起點，才能讓空路線也有一個經過的格子。本題平面沒有邊界與障礙，不能擅自沿用先前地圖的限制；座標可以為負，tuple可作集合元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
visited = {(0, 0)}
visited.add((0, 1))
visited.add((0, 0))
print(len(visited))
展開範例結果
2

UNIT E / E

E｜預算能完成幾項任務

每項成本非負，所以前綴成本非遞減，才能用二分查詢預算容許的最長前綴。成本為零時可能有多個相等前綴，應取最右邊仍不超預算的位置，才能包含免費任務。前綴含起始零，因此搜尋結果要減一；答案最多是任務數，不能把那個額外前綴算成任務。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_right
p = [0, 0, 2, 2]
print(bisect_right(p, 2) - 1)
展開範例結果
3
