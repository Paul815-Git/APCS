UNIT A / E

A｜二分真的縮小幾次

二分搜尋的效率來自每次去掉一部分候選位置，而不是程式裡出現除以二就算完成。本題把迴圈次數也輸出，讓位置正確與確實縮小可以一起檢查。計數只在進入迴圈時增加，最後的相等確認不算一次新的搜尋步驟。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
lo, hi, steps = 0, 1, 0
while lo < hi:
    hi = (lo + hi) // 2
    steps += 1
print(lo, steps)
展開範例結果
0 1

UNIT B / E

B｜比較總數有公式

無序配對只需要比較不同位置一次，第零格會比後面全部，下一格少一次，最後一格不再比較。總數可用等差和推導，也能用小資料迴圈確認。本題輸入可能很大，所以正式解答使用整數公式；除以二時用整數除法避免浮點誤差。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
count = 0
for i in range(4):
    for j in range(i + 1, 4):
        count += 1
print(count)
展開範例結果
6

UNIT C / E

C｜目前總和等於目前視窗

固定視窗向右移動時，移出最左一個值並加入新的最右值，視窗總和才會保持正確。這個等式是每次迴圈都應成立的不變量。練習先輸出所有視窗和，讓中途錯誤不會被最後最大值掩蓋；負數也適用，因為只是加減相同元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, -1, 4]
total = sum(a[:2])
print(total)
total += a[2] - a[0]
print(total)
展開範例結果
1
3

UNIT D / E

D｜保留處理過的最大值

掃描到某個位置後，best 應等於到目前為止看過的最大值，這就是可用歸納方式檢查的不變量。全負數時從零開始會製造不存在的候選值，因此從第一個實際元素初始化。新紀錄只計嚴格變大，相同最大值不算另一筆紀錄。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
best = -5
for x in [-3, -3, -1]:
    if x > best:
        best = x
print(best)
展開範例結果
-1

UNIT E / E

E｜每筆工作只進出一次

堆疊遇到可消除的相鄰相同值時彈出，否則推入。雖然消除可能讓新的相鄰關係出現，每個輸入元素仍只被推入一次或拿來消除一次，不需要反覆掃描整個串列。堆疊隨時代表目前前綴消除完成後的結果，空堆疊則不能讀取頂端。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stack = []
for x in [1, 2, 2, 1]:
    if stack and stack[-1] == x:
        stack.pop()
    else:
        stack.append(x)
print(len(stack))
展開範例結果
0
