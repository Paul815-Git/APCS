UNIT A / E

A｜壓縮路線的終點

路線以方向和次數表示時，若平面沒有邊界、牆壁或途中事件，就能一次把位移乘上次數，不必真的走每一步。這個簡化依賴每一步的效果可以相加；若題目需要領取沿路金幣，就不能只看終點。本題先把解碼規則轉成數學位移再更新位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dx, dy, count = 1, 0, 100
x, y = 2, 3
x += dx * count
y += dy * count
print(x, y)
展開範例結果
102 3

UNIT B / E

B｜調整時鐘與讀取紀錄

時鐘指令把文字解析與循環狀態結合。內部只存一天中的總分鐘，SHIFT在加上偏移後立刻取餘數，READ再拆成時分輸出。每次更新後都保持0到1439的範圍，能讓後續指令不必擔心累積很多天，也不必另寫跨日、借位的分支。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
minute = 5
minute = (minute - 10) % 1440
print(minute // 60, minute % 60)
展開範例結果
23 55

UNIT C / E

C｜旋轉後的座位查詢

旋轉矩陣後再查詢，座標必須依旋轉後的尺寸解讀。先完成所有旋轉，之後查詢只讀最終矩陣，就不必對每個查詢重做轉換。以函式集中旋轉規則能避免重複程式，也讓「建構資料」和「回答問題」兩階段的責任分得清楚。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = [[3, 1], [4, 2]]
row, col = 1, 0
print(grid[row][col])
展開範例結果
4

UNIT D / E

D｜可撤回的有限步行

移動被拒絕時不算成功操作，因此不應新增復原紀錄。成功前保存原座標tuple，UNDO就能一次恢復兩個維度，避免只還原其中一個。單格場地是很好的邊界測試：所有移動都失敗，無論執行多少次UNDO，歷史都應保持空且位置不變。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
position = (1, 2)
history = [position]
position = (1, 3)
position = history.pop()
print(*position)
展開範例結果
1 2

UNIT E / E

E｜帶障礙的多輪訊號報告

完整模擬先釐清每輪哪些格會改變：障礙永遠固定，訊號保持亮起，只有空地可能變成訊號。同步輪次使用新矩陣，計數則只增加本輪由零變一的格。每輪輸出新增數量，比只看最後圖形更容易檢查是否偷用了同輪新訊號，以及是否重複計入舊訊號。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
old = [1, 0, 0]
new = [1, 1, 0]
added = 0
for i in range(len(old)):
    if old[i] == 0 and new[i] == 1:
        added += 1
print(added)
展開範例結果
1
