UNIT A / E

A｜平均以上不用浮點數

比較一個值是否大於平均，可以把兩邊乘上正的資料數，改成整數比較。這能避開浮點數表示誤差，也能明確分辨等於平均是否算入。題目至少有一筆資料，所以乘法不會改變不等號方向；全相等時應沒有任何一筆嚴格高於平均。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 2, 6]
total = sum(a)
print(a[2] * len(a) > total)
展開範例結果
True

UNIT B / E

B｜最長同字片段

總次數不能回答最長連續片段，因為相同字元可能分散在不同位置。掃描時保留上一個字元與目前連續長度，字元改變就重新開始；同時維護歷來最長長度。空字串需要獨立的初始答案零，避免為了初始化而讀取不存在的第一個字元。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s = "aabbba"
run = best = 0
previous = ""
for ch in s:
    run = run + 1 if ch == previous else 1
    best = max(best, run)
    previous = ch
print(best)
展開範例結果
3

UNIT C / E

C｜同分要共同名次

名次定義為比自己高分的人數加一，因此同分者必須得到相同名次，後續名次也可能跳號。本題分數只有零到一百，可先統計各分數人數，再由高到低累加已經較高的人數。最後依原輸入順序查名次表，既保留同分關係，也不會把輸出改成排序後順序。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
scores = [90, 90, 70]
answer = []
for score in scores:
    higher = 0
    for other in scores:
        if other > score:
            higher += 1
    answer.append(higher + 1)
print(*answer)
展開範例結果
1 1 3

UNIT D / E

D｜每欄是否遞增

矩陣題常把列和欄弄反，所以先用文字說明一個比較會固定哪個座標。本題固定欄、比較上下相鄰兩列，所有比較都成立才算該欄嚴格遞增。只有一列時沒有違反條件的相鄰對，所有欄都成立；不要自行加上題目沒有要求的至少兩列限制。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = [[1, 3], [2, 3]]
print(g[0][0] < g[1][0])
print(g[0][1] < g[1][1])
展開範例結果
True
False

UNIT E / E

E｜撤回最近有效加分

撤回的是最近一次仍有效的加分操作，不是把目前總分清空，也不是撤回其他撤回指令。用堆疊保存尚未撤回的分數，總分則與堆疊內容總和保持一致。正負分數都合法，因此撤回負分時總分會增加；這組測試能抓出一律減去絕對值的誤解。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stack = [5, -2]
total = sum(stack)
total -= stack.pop()
print(total)
展開範例結果
5
