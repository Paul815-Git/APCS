UNIT A / E

A｜候補名單

先分清名單內重複與兩份名單的關係。候補者是報名但尚未錄取的人，與第20課只屬於其中一班的對稱差不同。輸出又要求編號排序，所以先用集合差得到人選，再排序。空結果也是一個合法答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
registered={1,2,3}
admitted={2,4}
print(*sorted(registered-admitted))
展開範例結果
1 3

UNIT B / E

B｜正規化後的查詢

大小寫是否視為相同由題目決定。若忽略大小寫，建立字典與查詢都要使用同一種正規化，不能只改其中一邊。本題單字以空白分隔，不要求去除標點，所以不要額外套用題目沒有要求的清理規則。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
print("Apple".lower()=="APPLE".lower())

UNIT C / E

C｜區間平均是否達標

不必真的算出浮點平均值，就能判斷區間平均是否至少門檻：總分≥門檻×人數。先用前綴和取得總分，再以r-l+1求人數。這避免小數精度與四捨五入，也提醒你題目只問比較，不一定要算出完整的中間量。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total,count,threshold=179,3,60
print(total>=count*threshold)
展開範例結果
False

需要時再看提示

區間總分p[r]-p[l-1]；與t*(r-l+1)比較，相等算YES。

UNIT D / E

D｜容量足夠的最小箱型

第20課找最近值要看下界兩側，但本題要求容量至少需求，較小的候選再接近也不合法。因此只要下界位置，不看前一格。題目中的箱型可以重複選用，查詢後不刪除；若要有限庫存就會是不同問題。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left
a=[3,7,10]
pos=bisect_left(a,8)
print(a[pos])
展開範例結果
10

UNIT E / E

E｜合法括號的最大巢狀深度

括號合法性仍需第20課的種類與順序檢查。每遇左括號推入後，堆疊長度就是當時深度；歷史最大值是答案。若最後發現非法，不能繼續回報之前曾出現的深度，而要按題目輸出-1。空字串合法且深度為0。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stack=[]
peak=0
for ch in "(())":
    if ch=="(":
        stack.append(ch)
        peak=max(peak,len(stack))
    else:
        stack.pop()
print(peak)
展開範例結果
2
