UNIT A / E

A｜線性搜尋的比較次數

線性搜尋由第一個位置逐一比較，找到就停止。比較次數包含最後那次成功比較；查無資料則必須看完全部。計數器應在每次比較之前加一。這是指定操作的次數，不是電腦實際執行的全部指令或秒數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[4,7,9]
checks=0
for x in a:
    checks+=1
    if x==7:
        break
print(checks)
展開範例結果
2

B｜配對總數與符合數不同

第11課用i<j避免重複配對。符合目標的配對數可能是0，但檢查次數仍可能很多；不能用輸出答案大小推斷速度。分開保存檢查次數與符合次數，對照n(n-1)//2，就能驗證枚舉範圍是否正確。

UNIT C / E

C｜二分搜尋真正縮小範圍

本題沿用第18課左閉右開版本，回傳第一個至少目標的位置。每輪只計一次「a[mid]<t」比較，不計while條件。若更新不能縮小區間，就可能無窮迴圈。請同時列lo、hi、mid，觀察右端不包含的規則如何維持。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[2,4,6,8]
lo,hi=0,4
mid=(lo+hi)//2
print(mid,a[mid])
展開範例結果

UNIT D / E

D｜多次區間查詢的工作量

重複查詢時，慢法每次讀取區間所有元素，讀取數為各區間長度相加。前綴法先讀n筆，再每次取兩個前綴。本題明確只比較這些讀取動作，沒有把加減、輸入和配置都當成零成本，因此模型結果不能直接換算成秒數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n=5
queries=[(1,5),(2,3)]
slow=0
for l,r in queries:
    slow+=r-l+1
print(slow,n+2*len(queries))
展開範例結果
7 9

E｜依明確模型判斷可行
