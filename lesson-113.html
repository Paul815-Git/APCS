UNIT A / E

A｜最長不合格片段起點

把合格改成不合格後，更新條件也要跟著改，而不是只換題目名稱。這次除了長度還要輸出最早起點，遇到更長片段時才更新，平手保留先前結果。沒有不合格批次時輸出零零；這個不存在狀態必須和合法的一開始起點分開。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
right, run = 5, 3
print(right - run + 2)
展開範例結果
4

UNIT B / E

B｜合格段至少有兩筆

連續段統計不能只在遇到不合格時結算，否則最後一段若一直延伸到輸入結尾就會漏算。這題要計算長度至少二的合格段數，當段落結束時檢查一次，迴圈後再結算尾段。每段只算一次，不可對段內每一對相鄰合格都重複增加答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
run, count = 3, 0
if run >= 2:
    count += 1
print(count)
展開範例結果
1

UNIT C / E

C｜累計後選最低站

累計任務換成找最小值時，不能沿用零作最佳值，因為所有實際總量可能都大於零。先從已存在的站名取得候選，或使用尚無答案的標記，再依規則比較。這題以名稱逆序處理同量，迫使你重新閱讀同分規則，而不是照搬先前選最前名稱。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
totals = {"a": 2, "b": 2}
print(sorted(totals, reverse=True)[0])
展開範例結果
b

UNIT D / E

D｜區間以外的總量

前綴差算出區間內的量，但這次題目要的是其餘位置，還要從全體總和扣除。先明確區分全體、選取區間與補集，再套公式，能避免看到l、r就直接輸出同一種答案。若區間包含全體，外部是空集合，答案為零，不能多算任一端點。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = [0, 2, 5, 9]
inside = p[2] - p[0]
print(p[-1] - inside)
展開範例結果
4

UNIT E / E

E｜區間平均的精確比較

比較區間平均與整數門檻，可以改成區間總和與門檻乘元素個數比較。區間含兩端，所以個數是右端減左端再加一；少加一會讓單格區間失去正確意義。使用整數乘法也能避免浮點誤差，且允許負數門檻，因為乘上的長度始終為正。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total, length, target = 7, 2, 3
print(total >= length * target)
展開範例結果
True
