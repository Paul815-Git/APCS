UNIT A / E

A｜回傳修正後數值

函式契約先寫參數範圍與回傳值意義。clamp把過低的值提高、過高的值降低，中間值保持；三個分支都要回傳。參數x是本次呼叫的區域名稱，主程式要接住回傳值，不能期待函式替外部的同名變數改值。print只顯示資料，不把結果交給呼叫者。將輸出留在主程式，方便同一函式連續處理多筆。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def clamp(x):
    if x<0:
        return 0
    if x>100:
        return 100
    return x
print(clamp(-2),clamp(60),clamp(150))
展開範例結果
0 60 100

UNIT B / E

B｜多個回傳值

函式可回傳一個tuple，呼叫者用多個變數解包。寫return low,high時，真正回傳的是一對結果；不要分成兩個return，因為第一次return就結束函式。先保證輸入非空，才能以第一筆初始化最大與最小。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def bounds(a):
    return min(a),max(a)
lo,hi=bounds([5,-1,3])
print(lo,hi,hi-lo)
展開範例結果
-1 5 6

UNIT C / E

C｜布林函式檢查順序

回傳布林值的函式可以在發現一個反例時立即return False；只有檢查完所有相鄰位置才能return True。若True放在迴圈內，第一對合法就停止，後面可能仍亂序。單一元素沒有違規相鄰對，按本題定義視為有序。輸出時可用普通if/else，也可寫條件運算式："YES" if ordered(a) else "NO"，意思是條件成立選前面的值，否則選後面的值；只會求出被選中的那一邊。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def ordered(a):
    for i in range(1,len(a)):
        if a[i]<a[i-1]:
            return False
    return True
print(ordered([1,1,2]))
print(ordered([1,3,2]))
展開範例結果
True
False

UNIT D / E

D｜搜尋函式與找不到的記號

函式回傳索引時，合法索引包含0，因此不能用if pos判斷有沒有找到。本題使用-1代表不存在，呼叫者要比較pos!=-1。寫出契約後，找第一個符合的位置就能return，其餘情況在迴圈結束後統一回傳-1。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
pos=0
print(bool(pos))
print(pos!=-1)
展開範例結果
False
True

UNIT E / E

E｜規則作用在單筆還是整批

相同函式套用的位置不同，結果可能不同。若運費依整張訂單總額決定，就應先累加每項商品再呼叫費用函式，而不是每項商品都收一次運費。先畫資料流：商品明細→總額→運費規則→應付金額，避免把正確函式放錯位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def shipping(total):
    return 0 if total>=100 else 10
print(60+60+shipping(120))
展開範例結果
120
