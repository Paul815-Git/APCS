UNIT A / E

A｜收支最低點

最後餘額無法指出途中是否曾經不足，必須每筆更新後保留到目前為止的最低餘額。最低點包含開始前的狀態，因此初始化為起始餘額。用先支出後收入的資料測試，能抓出只看總和的錯誤；順序不同時，即使最後總額相同，最低點仍可能不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
balance = 5
lowest = balance
for delta in [-8, 9]:
    balance += delta
    lowest = min(lowest, balance)
print(balance, lowest)
展開範例結果
6 -3

UNIT B / E

B｜第一次重複的位置

偵測重複時，答案是第二次出現的位置，並非那個值第一次出現的位置。集合記住已看過的值，讀到新值時先查再加入；第一次碰到已存在者就固定答案。題目使用一開始的位置編號，因此輸出時要把串列索引加一，不能和內部索引混用。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
seen = {7, 2}
print(7 in seen)
展開範例結果
True

UNIT C / E

C｜每日增加是否連續

連續上升的天數由相鄰比較決定，不能直接計算所有大於首日的資料。每個值本身都能形成長度一的片段，上升時接到前一段，否則重新開始。相等不算嚴格上升，所以全相等資料只能得到一；先確認這個定義，再決定使用大於或大於等於。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 3, 3, 5]
run = 1
for i in range(1, len(a)):
    run = run + 1 if a[i] > a[i-1] else 1
print(run)
展開範例結果
2

UNIT D / E

D｜第一段達標

固定長度片段的起點有明確先後，本題只找第一個達到門檻的片段，不需要最大值。用前綴差或滑動總和都能取得每一段的總和，再由左往右停止。沒有答案時使用零作輸出標記，與一開始的合法位置編號分開，避免最後一段剛好達標卻漏掉。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = [0, 2, 5, 9]
print(p[3] - p[1])
展開範例結果
7

UNIT E / E

E｜服務完成時間

單一櫃台一次只能服務一人，開始時間是抵達時間與前一人完成時間兩者較大值。輸入已按抵達先後排列，所以不需要再排序，也不會允許後來的人插隊。空閒時間不能累加成工作時間；用中間有空檔的資料檢查，能分辨連續忙碌與重新開始。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
finish = 3
arrival, duration = 8, 2
finish = max(finish, arrival) + duration
print(finish)
展開範例結果
10
