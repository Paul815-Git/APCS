UNIT A / E

A｜兩份有序名單合成一份

兩串列都遞增時，尚未處理的最小元素必在兩個目前指標之一。比較後取較小值，只有被取出的那一邊前進，另一邊保留。任一串列用完後，另一串列剩餘部分本來就有序，可直接接上。總共每個元素只取一次，比先合併再排序更能利用輸入既有順序。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = [1, 4], [2, 3]
i, j = 0, 0
if a[i] <= b[j]:
    print(a[i])
    i += 1
print(i, j)
展開範例結果
1
1 0

UNIT B / E

B｜兩份名單共有的不同值

若a[i]小於b[j]，a[i]不可能在b尚未讀取的部分出現，因為那些值都至少是b[j]，所以可以安心前進i。反之移動j；相等才找到共同值。題目只要不同值，加入答案前需與上一個答案比較，避免把連續重複資料當成多個共同種類。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
result = []
for value in [2, 2, 5]:
    if not result or result[-1] != value:
        result.append(value)
print(*result)
展開範例結果
2 5

UNIT C / E

C｜排序後從兩端找指定總和

同一有序序列找兩數和，可把左指標放最小值、右指標放最大值。和太小時，固定左值搭配更小右值只會更小，所以左端不可能成功，將左指標前進；和太大時同理後退右指標。必須保持left<right，才能避免用同一位置配對自己。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, target = [1, 3, 7], 8
left, right = 0, len(a)-1
print(a[left] + a[right] == target)
展開範例結果
True

UNIT D / E

D｜每個元素只能配走一次

多重集合交集保留每個值在兩邊次數的較小者，不能像不同值交集那樣去重。指標相等時輸出一次並各前進一格，就代表兩份名單各消耗一個位置。空序列須讀取對應空行，while的雙邊長度檢查會讓比較直接跳過，不應先讀a[0]或b[0]。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b = [2, 2, 2], [2, 2]
print(min(len(a), len(b)))
展開範例結果
2

UNIT E / E

E｜兩清單不超預算的所有配對

對每個遞增的a值，找b中最後一個使總和不超過預算的位置j，則b[0]到b[j]全部合法，共j+1組。a變大後，合法j只可能不變或左移，因此不用重新從尾端搜尋。重複值代表不同位置，這個批次計數會自然保留它們，總工作量為兩串列長度之和。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, b, budget = 3, [1, 2, 6], 5
j = len(b)-1
while j >= 0 and a+b[j] > budget:
    j -= 1
print(j+1)
展開範例結果
2
