UNIT A / E

A｜入堆疊時就標記

深度優先搜尋每次取出最後發現但尚未處理的格子，再加入合法鄰格。格子入堆疊時就標記，可以避免不同鄰格把它重複加入。這裡求可到達範圍，不保證最短路徑；堆疊可避免深遞迴。串列生成式 [input() for _ in range(r)] 表示重複讀入r行並組成新串列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stack = [(0, 0)]
seen = {(0, 0)}
for cell in [(0, 1), (0, 1)]:
    if cell not in seen:
        seen.add(cell)
        stack.append(cell)
print(len(stack))
print(stack.pop())
展開範例結果
2
(0, 1)

UNIT B / E

B｜是否能到達指定終點

若題目只問能否到達，完成走訪後檢查終點是否被發現即可，不必記錄距離。牆格不能加入堆疊，對角接觸也不算相連。起點等於終點時，起點一開始就已標記，所以應立即視為可到達，不必強迫至少移動一步。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
seen = {(0, 0), (1, 0)}
print((1, 0) in seen)
print((0, 1) in seen)

False

UNIT C / E

C｜走訪區域同時計算外露邊

每個可到達格子的四條邊，若鄰側越界或是牆，就貢獻一條外露邊；若鄰側也是可走格，則是內部共享邊，不計。外露邊的判斷與鄰格是否已走訪無關，不能把尚未走訪的可走鄰格誤當邊界。搜尋只負責限定同一連通區域。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
grid = ['..']
r, c, perimeter = 1, 2, 0
for y in range(c):
    for dx, dy in [(-1,0),(1,0),(0,-1),(0,1)]:
        x2, y2 = dx, y + dy
        if not (0 <= x2 < r and 0 <= y2 < c):
            perimeter += 1
print(perimeter)
展開範例結果
6

UNIT D / E

D｜可走條件與收集條件分開

帶有寶物的格子仍可以走過，因此可走條件應是「不是牆」，收集條件才是「等於寶物符號」。若只允許點字元入堆疊，寶物反而成為障礙。每格只處理一次便自然每件只收一次；起點若是牆，本題定義無法出發，答案應為零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for cell in ['.', 'T', '#']:
    print(cell != '#', cell == 'T')
展開範例結果
True False
True True
False False

UNIT E / E

E｜是否能走到地圖邊界

出口不一定只有一格，題目可以把所有邊界可走格都當出口。每取出一格就檢查它是否位於第一列、最後列、第一欄或最後欄；任一條件成立即可成功。起點本身在邊界也算成功，且不需要真的跨出地圖，避免把非法索引當作合法移動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
r, c = 3, 4
for x, y in [(1, 1), (0, 2), (2, 3)]:
    print(x == 0 or x == r - 1 or y == 0 or y == c - 1)
展開範例結果
False
True
True
