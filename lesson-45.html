UNIT A / E

A｜把質數的倍數劃掉

篩法先假設2到n都是質數，再把已確認質數的倍數劃成False。從pp開始劃，因為更小倍數已有較小因數，早已被處理。當pp>n時，所有合數都已有不大於平方根的因數，因此可以停止。串列索引直接代表數值，所以需要n+1格。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
prime = [True] * 11
prime[0] = prime[1] = False
for multiple in range(4, 11, 2):
    prime[multiple] = False
print(prime[2], prime[4])
展開範例結果
True False

UNIT B / E

B｜依值域查表輸出

建立篩表後，判斷一個值是否為質數只需讀取prime[value]，不必再試除。逐一走訪索引就能按大小輸出質數。這種方法的成本取決於最大值n，不只取決於質數數量；若n非常大但只有少數查詢，整張表可能不適合，應改回逐筆判斷。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
prime = [False, False, True, True, False, True]
result = []
for value in range(len(prime)):
    if prime[value]:
        result.append(value)
print(*result)
展開範例結果
2 3 5

UNIT C / E

C｜質數表再接前綴計數

把質數記為一、非質數記為零，就能使用已學過的前綴和回答範圍內質數數量。先完成篩表，再建立prefix[x]表示1到x的質數數，查詢[l,r]便是prefix[r]-prefix[l-1]。兩個預處理階段各有責任，不能在篩到一半時就計入尚未劃掉的合數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
prefix = [0, 0, 1, 2, 2, 3]
print(prefix[5] - prefix[1])
展開範例結果
3

UNIT D / E

D｜範圍裡沒有下一個質數

尋找範圍內下一個質數時，可能根本找不到，因此答案先設為負一。題目允許n等於零或一，初始化prime[1]前必須確認該索引存在，不能沿用只接受n≥2的版本。掃描起點也必須至少為二，因為零與一不會因為尚未被劃掉就變成質數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 0
prime = [True] * (n+1)
prime[0] = False
if n >= 1:
    prime[1] = False
print(prime[0])
展開範例結果
False

UNIT E / E

E｜找相差二的質數配對

質數配對可把第二個值直接由第一個值決定：若要相差二，只需檢查p與p+2是否都在質數表中。每對以較小者作代表，因此不會重複。迴圈上限要保證p+2不超過n；同一個質數可以屬於不同配對，例如三、五與五、七是兩對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
prime_values = {2, 3, 5, 7}
for p in range(2, 6):
    if p in prime_values and p+2 in prime_values:
        print(p, p+2)
展開範例結果
3 5
5 7
