UNIT A / E

A｜區間內上升了幾次

上升事件發生在相鄰兩個位置之間，而不是單一位置。把第i筆大於第i-1筆記在位置i，區間[l,r]內只應計入l+1到r的事件，不能包含從l-1進入l的那次。因此查詢是p[r]-p[l]；單點區間沒有相鄰比較，答案自然為零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [5, 7, 6, 9]
p = [0, 0]
for i in range(1, len(a)):
    flag = 0
    if a[i] > a[i-1]:
        flag = 1
    p.append(p[-1]+flag)
print(p[4]-p[2])
展開範例結果
1

UNIT B / E

B｜批次補貨後再查詢總庫存

資料先接受所有區間加值，之後才查詢，正好可以串接差分與前綴和。第一階段記更新端點，第二階段累積還原每個位置的最終值，同時建立總和前綴，第三階段才回答查詢。若更新與查詢交錯，這套一次預處理就不成立，所以讀題時先確認事件順序。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
difference = [0, 2, 0, -2]
current, prefix = 0, [0]
for i in range(1, 4):
    current += difference[i]
    prefix.append(prefix[-1]+current)
print(prefix[3]-prefix[0])
展開範例結果
4

UNIT C / E

C｜每個值都不同的最長視窗

視窗不一定維護數值和，也可以維護每個值的次數。加入右端的新值後，只有這個值可能從一次變成重複，因此只要縮左端到它的次數回到一，整個視窗就恢復互不重複。移除左端時也要更新字典，不能只移動指標，否則次數會描述已離開的資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
counts = {2: 2, 3: 1}
counts[2] -= 1
print(counts[2])
展開範例結果
1

UNIT D / E

D｜同值但不同組別才配對

一筆資料帶有數值與組別，合法配對要求同值又不同組。讀到新資料時，先前同值的總數減去同值同組的數量，就是可配對筆數。用tuple作字典鍵可同時辨識兩個欄位；先計算再增加兩張次數表，仍維持只與前面位置配對的規則，避免重用自己。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
by_value = {5: 4}
by_group = {(5, "A"): 1}
print(by_value.get(5, 0)-by_group.get((5, "A"), 0))
展開範例結果
3

UNIT E / E

E｜預算內的最佳矩形展區

每個格子同時有成本與收益，先為兩張矩陣分別建立二維前綴。枚舉固定高寬區域時，用成本表檢查預算，再用收益表更新最佳值，不能把兩種資料加在一起。以負一表示尚無合法展區，因為收益皆非負；合法區域收益為零時仍應輸出零，不能誤判成無解。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
cost, value, budget = 7, 20, 6
best = -1
if cost <= budget:
    best = max(best, value)
print(best)
展開範例結果
-1
