UNIT A / E

A｜不建串列也能找分界

二分搜尋需要的是判斷結果有固定的真假分界，不一定需要實體串列。對非負整數來說，平方會隨數值增加而增加，因此「平方至少為目標」先假後真。先找一定含答案的範圍，再保留可能的第一個真值，避免用浮點誤差判斷整數邊界。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
target = 10
lo, hi = 0, target
while lo < hi:
    mid = (lo + hi) // 2
    if mid * mid >= target:
        hi = mid
    else:
        lo = mid + 1
print(lo)
展開範例結果
4

UNIT B / E

B｜時間越長產量不會減少

一台機器每隔固定時間完成一件，經過時間除以週期取整數，就是完成件數。多台同時工作時加總產量。時間增加不會讓產量變小，所以「達到需求」具有單調性；最快機器獨自完成所有需求的時間一定可行，可當搜尋上界。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
periods = [2, 3]
total = 0
for p in periods:
    total += 6 // p
print(total)
展開範例結果
5

UNIT C / E

C｜最大可行值的中點

切割長度越大，同樣木料能切出的段數越少，因此本題是真值在左、假值在右。找最大可行值時，中點要向上取整，否則只剩相鄰兩數且左邊可行時可能停滯。長度零不能拿來除，應只把它當成「沒有正長度解」的保留答案。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
lengths = [7, 10]
pieces = 0
for length in lengths:
    pieces += length // 3
print(pieces)
print((0 + 1 + 1) // 2)
展開範例結果
5
1

UNIT D / E

D｜固定順序的容量判斷

每批必須保持原順序時，給定容量後可盡量裝滿目前一批，再開下一批。這樣不會比提早結束一批使用更多批次。容量至少等於最大單件重量；容量加大不會使需要的批次增加，因此可以二分滿足批次限制的最小容量。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
weights = [3, 2, 4]
capacity = 5
batches, used = 1, 0
for w in weights:
    if used + w > capacity:
        batches += 1
        used = 0
    used += w
print(batches)
展開範例結果
2

UNIT E / E

E｜最大化最小間隔

先將位置排序，給定最小間隔後，每次放在最早合法的位置，可以替後面留下最多空間。若某間隔能放下指定數量，更小間隔也能放下；因此可二分最大可行間隔。這裡要先能寫對一次放置判斷，再把它包進搜尋，不可只背更新公式。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
positions = [0, 3, 4, 9]
gap = 4
count, last = 1, positions[0]
for x in positions[1:]:
    if x - last >= gap:
        count += 1
        last = x
print(count)
展開範例結果
3
