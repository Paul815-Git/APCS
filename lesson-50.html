UNIT A / E

A｜數字條件篩選候選

枚舉題先確定候選範圍，再把每個候選送進判斷函式。位數總和只是一個篩選條件，不會改變候選順序；由小到大掃描就能自然產生排序輸出。保留原數字給輸出，拆位或轉字串都在函式內完成，避免把候選變數除到零之後失去原值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def digit_sum(n):
    total = 0
    for ch in str(n):
        total += int(ch)
    return total
print(digit_sum(203))
展開範例結果
5

UNIT B / E

B｜互質且總和固定的拆分

一個等式能決定配對的另一半：選a後令b=N-a。題目不分順序就限制a≤b，讓每組只出現一次，再用gcd判斷互質。先處理結構上的範圍，再處理數學條件，能降低迴圈層數；若把a走到N-1又計算全部，便會把顛倒的拆分重複算入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 7
for a in range(1, n//2+1):
    print(a, n-a)
展開範例結果
1 6
2 5
3 4

UNIT C / E

C｜兩件商品的價格和必須為質數

把小函式組合可以讓條件保持可讀：雙層迴圈負責選兩個位置，is_prime負責判斷總價。數值為零或一時，配對和可能小於二，質數函式必須自行處理，不能假設呼叫者已經檢查。相同商品價格仍保留不同位置，所以不要先轉成集合去重。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [1, 1, 2]
for i in range(len(a)):
    for j in range(i+1, len(a)):
        print(a[i] + a[j])
展開範例結果
2
3
3

UNIT D / E

D｜有限枚數的湊款

有庫存上限的硬幣枚舉，算出第三種數量後仍要檢查能否整除及是否超過庫存。剩餘金額為負不能使用，剩餘恰好為零則代表第三種取零枚，是合法情況。把一元、五元、十元的數量當成組合，不計投入先後順序，才不會把相同付款方式重複計數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
remaining = 20 - 5 * 2
if remaining >= 0 and remaining % 10 == 0:
    print(remaining // 10)
展開範例結果
1

UNIT E / E

E｜固定面積下最接近正方形

矩形面積固定時，合法邊長就是因數配對。只枚舉短邊a到平方根，長邊b=N//a自然不小於a，且每個矩形只出現一次。目標是周長最小，可以逐候選比較，不必先背公式。完全平方數會找到兩邊相等的最佳矩形，面積一也同樣能處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n, a = 12, 3
b = n // a
print(a, b, 2*(a+b))
展開範例結果
3 4 14
