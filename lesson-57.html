UNIT A / E

A｜先查互補值，再存目前值

讀到x時，若之前已出現target-x，就存在兩個不同位置的配對。一定先查再加入x，否則target等於2*x時，第一筆資料就可能配到自己。集合只記出現與否，適合回答是否存在；若要算有幾組，就需要改用次數字典，不能把兩種任務混為一談。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
seen = set()
for x in [3, 3]:
    print(6-x in seen)
    seen.add(x)
展開範例結果
False
True

UNIT B / E

B｜互補值出現幾次就新增幾組

計算配對數時，先前若有三個互補值，現在這筆就新增三組不同位置配對。用count.get(need,0)取得次數，先加入答案，再增加目前值的次數。每組配對都在較晚位置讀到時被計入一次，因此不需要最後除以二，重複值也不會被集合合併而漏算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
counts = {2: 3}
value, target = 5, 7
print(counts.get(target-value, 0))
展開範例結果
3

UNIT C / E

C｜保留最早索引找最早完成的配對

題目要求位置時，集合不足以保存答案，應把每個值對應到首次出現的索引。依序讀到第二個位置j，第一次成功就具有最小j；字典又保留最小i，便完成平手規則。後來相同值不能覆寫舊索引，否則雖然仍有合法配對，卻不是題目要求的最早版本。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
first = {}
for i, value in [(0, 4), (1, 4)]:
    if value not in first:
        first[value] = i
print(first[4])
展開範例結果
0

UNIT D / E

D｜差距為零不能把同一條件加兩次

絕對差為k的互補值可能是x-k或x+k，當k>0時兩者不同，可以把先前次數相加；當k=0時兩者相同，只能加一次。仍採先查再存，保證兩個位置不同。這個特例不是效能問題，而是同一合法集合被兩個相同條件描述造成的重複計數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
x, k = 4, 0
print(x-k == x+k)
展開範例結果
True

UNIT E / E

E｜固定一個位置後轉為兩數和

三數和計數可以固定最左位置i，剩下問題就是後方序列中找兩數和target-a[i]。每個i都建立新的次數字典，掃描k時字典只包含i與k之間的位置，因此每組自然滿足i<j<k。若沿用上一輪字典，就會混入不合法位置，產生重複或重用元素。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
target, fixed, current = 10, 2, 5
print(target-fixed-current)
展開範例結果
3
