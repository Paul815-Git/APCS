UNIT A / E

A｜價格內最貴一件

找不超過預算的最大值，可以找第一個大於預算的位置，再取其前一格。若那個位置是零，就表示沒有任何商品符合，不能直接使用負一索引。先排序一次，再回答多個預算，查詢時既不用重排，也不需要掃描全部商品，重複價格不影響結果。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_right
a = [2, 5, 5, 9]
pos = bisect_right(a, 5)
print(a[pos-1])
展開範例結果
5

UNIT B / E

B｜嚴格超過的筆數

至少門檻與嚴格超過門檻只差一個等號，卻需要不同的二分邊界。第一個大於目標的位置右側，全部都是嚴格超過者；用資料長度減去該位置即可。重複值剛好等於門檻時最能看出左右界的差異，因此必須安排這類測試，不只測落在兩值中間的門檻。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_right
a = [3, 3, 7]
print(len(a) - bisect_right(a, 3))
展開範例結果
1

UNIT C / E

C｜先完成再比名稱

複合排序的每個欄位都要對應題目的優先順序。本題時間越小越前面，同時間才比較名稱，因此不能先依名稱挑選再看時間。用二元素 tuple 直接排序，結果會先比第一欄，只有相同才比第二欄；所有資料都保留，即使時間相同也不是重複紀錄。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
records = [(8, "amy"), (5, "zoe"), (5, "bob")]
for time, name in sorted(records):
    print(name, time)
展開範例結果
bob 5
zoe 5
amy 8

UNIT D / E

D｜第幾小的不同值

排序與去重的先後要依題意決定。這題把重複值視為同一名次，因此先用集合取不同值，再排序。查詢的一開始名次要轉成零開始索引，而且名次可能超過種類數；先檢查範圍，才可讀取串列，找不到時用指定文字回覆。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = sorted(set([4, 1, 4, 2]))
print(a[1])
展開範例結果
2

UNIT E / E

E｜最近值同距選較大

最近值仍只可能在下界及其前一格，但同距規則已改成選較大值。候選排序鍵可用距離及負的數值，讓第二欄越小代表原值越大。不要沿用前課同距選小的規則；把恰好位於兩值中間的目標放入測資，就能直接檢查這個差異。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def key(x):
    return (abs(x - 5), -x)
print(min([2, 8], key=key))
展開範例結果
8
