UNIT A / E

A｜區間偶數筆數

前綴陣列存的是可相加的資訊，不一定是原值。把偶數轉成一、奇數轉成零，就能讓前綴差回答區間內偶數數量。零與負偶數都符合取餘數為零的條件；建表時若錯用大於零的限制，這些合法資料就會被漏算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
p = [0]
for x in [-2, 3, 0]:
    p.append(p[-1] + int(x % 2 == 0))
print(p[3] - p[1])
展開範例結果
1

UNIT B / E

B｜數量乘單價再加總

同一筆資料由數量與單價組成，查詢要的是金額，應先把兩欄相乘再累積。若分別加總數量與單價後相乘，會產生原本不存在的交叉項。這是一種加權前綴和，查詢公式與一般總和相同，但建表前先確認每筆貢獻代表的物理意義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
quantity = [2, 1]
price = [3, 5]
print(quantity[0]*price[0] + quantity[1]*price[1])
展開範例結果
11

UNIT C / E

C｜最高總量的最早起點

除了最大視窗總和，這次還必須記住起點。由左向右掃描時，只有嚴格較大的總和才更新答案，相同就保留較早位置。先用第一個實際視窗初始化，才能處理全負數；若用零初始化，可能留下不存在的空片段，也會讓起點答案失去意義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
best, start = -3, 1
candidate = -3
if candidate > best:
    best, start = candidate, 2
print(best, start)
展開範例結果
-3 1

UNIT D / E

D｜批次加值後再輸出

所有區間更新完成後才需要最終陣列，差分能把一整段加值變成兩個端點修改。終點後一格放相反變化，恢復時累加差分就得到目前增加量。因為沒有更新途中查詢，這個做法適用；若題目改成每步立刻查詢，就不能直接沿用一次恢復的流程。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
diff = [0, 0, 0, 0]
diff[0] += 2
diff[2] -= 2
current = 0
for i in range(3):
    current += diff[i]
    print(current)
展開範例結果
2
2
0

UNIT E / E

E｜連續可負擔的最長天數

本題金額皆非負，因此增加右端不會降低總額，移除左端不會提高總額。這個單調性使雙指標視窗成立；超出預算就縮左端，直到重新符合條件。零金額可能連續出現，不能用總額為零判斷視窗空不空，長度必須由左右索引計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [0, 2, 0]
print(sum(a), len(a))
展開範例結果
2 3
