UNIT A / E

A｜獨立題一：首次庫存告警

本題的判斷對象是每步完成後的累積狀態，不是單筆變化量，也不是最後庫存。先處理初始庫存是否已低於門檻，再依序更新；第一次告警後仍要讀完資料，但不能覆蓋第一次時間。起始時刻以零表示，完全未告警用負一，兩者意義不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
stock, limit = 5, 3
stock += -3
print(stock < limit)
展開範例結果
True

UNIT B / E

B｜獨立題二：座位列交換

每條交換指令都作用在當前座位表，因此後面的列號指目前位置，不是最初的列身分。若矩陣每列已獨立讀入，交換外層兩列參照就能完成整列交換，無須逐格移動。作答後用連續交換同一列與自己交換測試，確認流程沒有把指令誤當成一次性的排列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = [[1, 2], [3, 4]]
g[0], g[1] = g[1], g[0]
print(*g[0])
展開範例結果
3 4

UNIT C / E

C｜獨立題三：趕上最早班次

乘客可以搭上與到達時間相同的班次，因此要找第一個不小於到達時間的發車。資料先排序，再對每位乘客獨立查詢；某位乘客搭車不會消耗班次。答案是等待時間，還要用發車時間減到達時間，不能把搜尋到的索引直接當作輸出。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
departures = [3, 8]
arrival = 5
print(departures[1] - arrival)
展開範例結果
3

UNIT D / E

D｜考後訂正：列身分追蹤

前題輸出座位內容，這次只問每個位置最後放著哪個原始列號。把每列身分當成一個整數，依相同交換指令更新即可，不需要建立實際矩陣。這種縮小表示能幫助除錯：先確認交換順序正確，再回到包含更多欄位的資料，不讓無關數值掩蓋索引問題。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
ids = [0, 1, 2]
ids[0], ids[2] = ids[2], ids[0]
print(*ids)
展開範例結果
2 1 0

UNIT E / E

E｜考後加練：要保留登車緩衝

規則改成必須在發車前至少指定分鐘到達，等價於尋找不小於到達時間加緩衝的班次。把題意先轉成新的搜尋門檻，再沿用下界方法，才能避免只改輸出等待時間卻沒改可搭條件。緩衝可以為零，此時應退回原本規則，適合用來核對兩題關係。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
arrival, buffer = 5, 2
print(arrival + buffer)
展開範例結果
7
