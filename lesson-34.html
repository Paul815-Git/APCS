UNIT A / E

A｜把分鐘放回一天之內

一天有1440分鐘。把時與分先合成總分鐘，再加上經過時間，最後對1440取餘數，就能回到當天時刻。整除60取得小時，除以60的餘數取得分鐘。此題只問時刻，不問過了幾天，因此取餘數丟掉整天資訊正好符合輸出需求。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total = (23 * 60 + 50 + 25) % 1440
print(total // 60, total % 60)
展開範例結果
0 15

UNIT B / E

B｜跨午夜的等待時間

兩個時刻相減可能得到負數，對一天長度取餘數可以得到向前等待的分鐘數。但這需要先定義相同時刻的意思：本題代表立即發生，等待為零，而不是等明天。若題目要求嚴格下一次，就要另把零改成一天，不能混用兩種規格。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
start = 23 * 60 + 40
end = 15
print((end - start) % 1440)
展開範例結果

UNIT C / E

C｜每週循環的排程

循環不一定只有一天。把星期與時分一起換成「本週第幾分鐘」，就能使用相同方法處理一整週。單位轉換要從大到小：先把星期換成天，再換成分鐘；還原時先取出星期，再處理當天剩下的分鐘，避免把小時誤當成整週的小時數。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total = (6 * 1440 + 23 * 60 + 30 + 60) % 10080
print(total // 1440, total % 1440 // 60, total % 60)
展開範例結果
0 0 30

UNIT D / E

D｜向前調整時鐘

在Python中，對正整數取餘數的結果不會是負數，所以負的時間偏移也可以套用同一公式。例如零點往前一分鐘，總分鐘為負一，對1440取餘數後是1439。先做整體加法再取餘數，比只修正小時或只修正分鐘更不容易漏掉借位。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total = (-1) % 1440
print(total // 60, total % 60)
展開範例結果
23 59

UNIT E / E

E｜跨日營業時間判定

跨午夜的營業區間若直接比較開始與結束，會變成兩段。把所有時刻都改成「距離開店的向前分鐘」，區間就重新變成從零開始的一段。採開始包含、結束不包含的規則，只要距離小於營業長度就開店；相等的端點屬於關店，必須明確處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
start, end, query = 1320, 120, 60
length = (end - start) % 1440
print((query - start) % 1440 < length)
展開範例結果
True
