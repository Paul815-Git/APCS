UNIT A / E

A｜同時刻先合併增減

每個半開區間在開始時加一、結束時減一，將同時刻的變化合併後再累加，就得到該時刻之後的使用量。合併可避免先加後減造成瞬間假高峰。本題只問每個事件時刻的狀態，沒有事件的中間時間不必逐秒模擬。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
change = {}
for start, end in [(1, 3), (3, 5)]:
    change[start] = change.get(start, 0) + 1
    change[end] = change.get(end, 0) - 1
active = 0
for t in sorted(change):
    active += change[t]
    print(t, active)
展開範例結果
1 1
3 1
5 0

UNIT B / E

B｜最大同時使用量

掃描的累積值表示目前尚未結束的區間數，最大累積值就是同時需要的設備數。這不是最多能挑幾個活動，因此不能使用最早結束選取。事件只需按時間排序一次，同時出現多少開始與結束，都由同一個差分值一起處理。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
change = {0: 1, 2: 1, 4: -1, 6: -1}
active, peak = 0, 0
for t in sorted(change):
    active += change[t]
    peak = max(peak, active)
print(peak)
展開範例結果
2

UNIT C / E

C｜有使用的總時間

兩個相鄰事件之間沒有狀態變化，所以整段都使用相同數量的設備。先套用目前事件的變化，再用下一個時間減目前時間取得段長；若使用量大於零，整段都算入聯集長度。最後一個事件沒有後續段，不應憑空多算一秒。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
times = [1, 3, 6]
changes = {1: 1, 3: 0, 6: -1}
active, length = 0, 0
for i in range(len(times) - 1):
    active += changes[times[i]]
    if active > 0:
        length += times[i + 1] - times[i]
print(length)
展開範例結果
5

UNIT D / E

D｜重量超過容量的時長

事件變化可以是重量，不必固定為一。每個使用區間開始加重量、結束減重量，累積後即是該段負載。判斷超載時要依題意使用嚴格大於，剛好達到容量不算。計算的是超載持續時間，不是超載事件數，也不是多出來的總重量。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
load, capacity = 7, 7
print(load > capacity)
load += 2
duration = 5 - 2
if load > capacity:
    print(duration)
else:
    print(0)
展開範例結果
False
3

UNIT E / E

E｜精確覆蓋層數的長度表

把每個相鄰事件段依當時覆蓋層數分類，可以一次求出恰好一層、兩層直到所有層的總長度。段長屬於哪一類只由累積值決定，不必追蹤是哪幾個區間。零層是未覆蓋空白，本題不輸出；即使某層沒有出現，也要保留零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
lengths = [0, 0, 0]
for count, width in [(1, 2), (2, 3), (1, 4)]:
    lengths[count] += width
print(*lengths[1:])
展開範例結果
6 3
