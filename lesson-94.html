UNIT A / E

A｜回傳值要接住

函式內重新指定整數參數，只改變區域名稱，不會直接替呼叫端的整數變數賦值。要讓外面取得計算結果，必須 return 並接住回傳值。本題把原值和結果同時輸出，檢查自己是否把函式的計算行為誤認成原地修改。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def add_one(x):
    return x + 1
a = 4
b = add_one(a)
print(a, b)
展開範例結果
4 5

UNIT B / E

B｜數位和的基底

每次把非負整數除以十取整，位數就會變少，直到剩下一位。基底直接回傳該位數，其他層回傳末位加上剩餘位數的結果。零本身也是一位數，不能把它當成缺少輸入；先追蹤零，再追蹤中間含零的數字，確認遞迴會停止。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def digit_sum(n):
    if n < 10:
        return n
    return n % 10 + digit_sum(n // 10)
print(digit_sum(204))
展開範例結果
6

UNIT C / E

C｜回程才組合結果

遞迴回傳後才做的運算，發生在呼叫回來的階段。求乘積時先定義空乘積為一，才能讓第一個元素乘上一個不改變它的基底。參數索引每次增加一，直到等於長度；本題長度很小，目的在追蹤呼叫，不是用遞迴處理大型串列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def product(a, i):
    if i == len(a):
        return 1
    return a[i] * product(a, i + 1)
print(product([2, 3], 0))
展開範例結果
6

UNIT D / E

D｜停止範圍不是只有一種

回文檢查從兩端向中間縮小範圍，左右相遇或交錯都代表已檢查完。若只處理相遇，偶數長度可能錯過終止條件。每層先處理空範圍，再比較兩端，最後才遞迴；這個順序也會保護空字串，避免一開始就讀取不存在的索引。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def pal(s, l, r):
    if l >= r:
        return True
    return s[l] == s[r] and pal(s, l + 1, r - 1)
print(pal("abba", 0, 3))
展開範例結果
True

UNIT E / E

E｜遞迴下界的空區間

二分搜尋遞迴版同樣需要維持左閉右開範圍，空區間時回傳左端位置。每一步都要確保區間嚴格縮小；向右搜尋時跳過已證明太小的中點，向左搜尋則保留中點。答案可能等於長度，這是合法插入位置，不代表一定找到相等值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def lower(a, t, lo, hi):
    if lo == hi:
        return lo
    mid = (lo + hi) // 2
    if a[mid] < t:
        return lower(a, t, mid + 1, hi)
    return lower(a, t, lo, mid)
print(lower([2, 4, 4], 4, 0, 3))
展開範例結果
1
