UNIT A / E

A｜非零不等於正數

把非零條件寫成大於零，會漏掉所有負數。這種錯誤用全正範例完全看不出來，所以要讓負數、零與正數同時出現，逐筆列出預期分類。程式把兩個條件各自計數，輸出結果的差異便能成為反例證據，而不是只口頭說兩個條件不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [-2, 0, 3]
count = 0
for x in a:
    if x != 0:
        count += 1
print(count)
展開範例結果
2

UNIT B / E

B｜第一次與最後一次

掃描中找到就停止會得到第一次，持續覆蓋答案則得到最後一次，兩者都可能是正確方法，關鍵在題意。這題同時要求兩個位置，讓更新時機的差異可以直接比較。未找到時都保持負一；只有一次出現時，兩個答案應相同，不需要特別製造不同位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [4, 1, 4]
print(a.index(4), len(a)-1)
展開範例結果
0 2

UNIT C / E

C｜相同值仍有不同位置

集合會刪掉重複值，適合種類問題，卻不能直接計算相同值的位置配對。某值出現次數為c，就形成c乘c減一再除二個無序位置對。先計頻率，再對各值的貢獻加總，能清楚保留位置資訊；只有一筆的值貢獻零，不需要特別排除。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
c = 3
print(c * (c - 1) // 2)
展開範例結果
3

UNIT D / E

D｜改一列不能改全表

矩陣別名錯誤通常在首次修改時才出現，因此測資應同時檢查被改列與未改列。每次建立新列可保證各列獨立，整列加值也只影響指定列。這題最後逐列輸出總和，讓不同列的變化容易比較；同一列多次更新則必須累加，不能每次重設。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
g = []
for i in range(2):
    g.append([0] * 2)
g[0][0] = 3
print(sum(g[0]), sum(g[1]))
展開範例結果
3 0

UNIT E / E

E｜結束狀態也要檢查

括號序列在掃描途中沒有變負，仍不保證最後全部配對完成。這題不判合法與否，而是計算最少要補多少括號才會合法；缺左括號時立即記一個補入，最後剩餘深度則是需要補的右括號。兩種缺口分開處理，能凸顯過程條件和結束條件各有用途。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s = "(()"
print(s.count("(") - s.count(")"))
展開範例結果
1
