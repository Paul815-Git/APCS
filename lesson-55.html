UNIT A / E

A｜不超支的最長連續片段

非負數讓視窗向右擴張時總和不會下降，移除左端時總和不會上升。加入右端後若超支，就反覆移除左端直到合法，再更新長度。左右指標各最多前進n次，雖然有巢狀while，總工作量仍為線性。含負數時這個理由失效，不能只套程式外形。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, budget = [2, 3, 1], 4
left, total = 0, sum(a)
while total > budget:
    total -= a[left]
    left += 1
print(left, len(a)-left)
展開範例結果
1 2

UNIT B / E

B｜達到需求的最短片段

最短和至少S的視窗，縮窗時機與最長不超支題相反：只要目前總和已達標，先記錄長度，再移除左端試著變更短。S設為正數，可確保空視窗不會被視為合法。若全程沒達標，以n+1作為尚未找到的記號，最後轉成零輸出。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a, target = [2, 3, 1], 4
left, total, best = 0, sum(a), 4
while total >= target:
    best = min(best, len(a)-left)
    total -= a[left]
    left += 1
print(best)
展開範例結果
2

UNIT C / E

C｜一次數出所有合法左端

當右端固定，縮到總和不超過B的最左合法位置left後，所有更右的起點也合法，因為移除的是非負數。因此以right結尾的合法非空片段共有right-left+1個，可一次加入答案，不必逐一列出。每個片段只會在自己的右端被計入，便不會重複。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
left, right = 2, 5
print(right-left+1)
展開範例結果
4

UNIT D / E

D｜零會讓相同總和有多種起點

求總和恰好S時，若資料有零，一個右端可能對應多個相同總和起點，不能找到一次就只加一。對整數總和，可用「不超過S的片段數」減「不超過S-1的片段數」。S為零時第二個門檻是負一，而非負序列不可能達成，所以函式直接回傳零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
at_most_s, at_most_before = 6, 0
print(at_most_s - at_most_before)
展開範例結果
6

UNIT E / E

E｜同時限制金額與特殊項目數

一個視窗可以維護兩個指標，只要兩者在加入元素時都不會下降。金額與特殊標記皆非負，因此只要任一限制超標，就把同一個左端元素從兩個總量一起扣除。縮到兩條件都合法後再更新答案，不能各用一個左端，否則兩種統計會對應不同區間。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
cost, marked, budget, limit = 5, 2, 6, 1
print(cost > budget or marked > limit)
展開範例結果
True
