UNIT A / E

A｜先留下最多後續空間

在所有尚可參加的活動中，先選結束最早者，不會比選其他活動更晚釋放時間。任何最優選法的第一個活動都能換成它，後面的活動仍然可行。這個交換理由依賴每個活動價值相同；若改問總獎金最大，僅看結束時間就沒有保證。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
events = [(4, 1), (3, 0), (6, 3)]
events.sort()
end, count = -1, 0
for finish, start in events:
    if start >= end:
        count += 1
        end = finish
print(count)
展開範例結果
2

UNIT B / E

B｜保留被選活動的身分

只輸出數量時，活動可以只存起訖；要輸出實際選擇，就必須保存原編號。排序會改變處理順序，卻不應改變身分。多個活動結束時間相同時，本題用較小編號作固定規則，讓輸出能核對；這只是決定平手順序，不是新的最佳化目標。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
events = [(5, 2, 1), (3, 1, 0)]
events.sort()
for finish, number, start in events:
    print(number, finish)
展開範例結果
1 3
2 5

UNIT C / E

C｜加入固定整備時間

若每場結束後都要花固定時間整理設備，下一場必須晚於結束加上整備時間。因為每場都加上相同常數，原本的結束早晚順序不變，交換理由仍適用。第一場之前沒有整備負擔，初始化要與題意一致，不能平白禁止一開始就舉辦的活動。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
finish, cleanup = 4, 2
for start in [5, 6]:
    print(start >= finish + cleanup)
展開範例結果
False
True

UNIT D / E

D｜可用時間窗先篩選

有些活動跨出場地開放時間，即使彼此不衝突，也不能入選。先將不完全落在時間窗內的活動排除，再對剩下的活動做最早結束選取，能把合法性與最佳化分開。兩個端點都剛好等於開放端點時仍合法，空的候選集合則自然選零場。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
opening, closing = 3, 8
for start, finish in [(2, 5), (3, 8), (7, 9)]:
    print(opening <= start and finish <= closing)
展開範例結果
False
True
False

UNIT E / E

E｜用最少點命中閉區間

這次不是挑不重疊活動，而是挑時間點，使每個閉區間至少含一個點。先處理右端最早的未命中區間，把點放在它的右端，能兼顧最多較晚區間。若下一區間左端等於已選點，因為兩端包含，它已被命中，不需要再加一點。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
intervals = [(3, 1), (5, 3), (8, 6)]
intervals.sort()
point = None
chosen = []
for right, left in intervals:
    if point is None or left > point:
        point = right
        chosen.append(point)
print(*chosen)
展開範例結果
3 8
