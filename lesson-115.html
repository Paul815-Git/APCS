UNIT A / E

A｜考後選做：回傳與原值

若卷二把函式回傳值誤認成會自動改寫外部變數，可用三個輸出值重新驗證資料流。原值保留，第一次函式結果傳給第二次函式，最後依序列出。每次呼叫的參數要清楚標出來源，這能避免把第二次仍傳原值，或把尚未接住的結果當作已儲存。

def twice(x):
    return 2*x
a = 3
b = twice(a)
print(a, b, twice(b))

UNIT D / E

D｜考後選做：回程累計奇數

遞迴基底決定空前綴的答案，每次回程再加入目前項的貢獻。這題只累計一到n之間的奇數，偶數層仍須呼叫下一層，不能直接返回零而忽略前面的奇數。先把每層的局部貢獻寫為目前值或零，再加上下層結果，能看清楚哪些資料被保留。

def odd_sum(n):
    if n == 0:
        return 0
    return odd_sum(n-1) + (n if n % 2 else 0)
print(odd_sum(4))

UNIT E / E

E｜考後選做：保留相等的邊界

下界和上界相減能得到相等元素數，但若直接把資料轉集合，這個資訊就無法恢復。本題要求同時輸出小於、等於與大於目標的筆數，三個答案總和應等於原資料長度。這項總和檢查可以抓出漏掉相等者，或把端點在兩類同時計入的錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
from bisect import bisect_left, bisect_right
a = [1, 3, 3, 5]
l, r = bisect_left(a, 3), bisect_right(a, 3)
print(l, r-l, len(a)-r)

  4. 隔日收起提示重作不熟的題，記錄讀題、寫程式、除錯時間。
