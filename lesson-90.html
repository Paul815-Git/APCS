UNIT A / E

A｜不同群組的配對數

要選來自不同連通分量的兩人，不能只看兩人之間是否有直接邊，因為還可能透過其他人相通。先求各分量大小，再逐群把本群大小乘上先前總人數，得到跨群配對。每對只會在較晚處理的群出現一次，不必最後除二，也不用枚舉所有節點對。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
sizes = [2, 3, 1]
seen, pairs = 0, 0
for size in sizes:
    pairs += seen * size
    seen += size
print(pairs)
展開範例結果
11

UNIT B / E

B｜每個部門的整棵子樹總額

子樹統計不只計節點數，也能累積每個節點自己的金額。先以自身金額初始化，再按孩子先於父親的順序上傳總額。父編號較小的前提讓倒序迴圈可直接完成，負金額也照常相加。本題要輸出每點答案，不是只輸出根的全部總和。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
parent = [0, 0, 1, 1]
total = [0, 5, -2, 4]
for u in range(3, 1, -1):
    total[parent[u]] += total[u]
print(*total[1:])
展開範例結果
7 -2 4

UNIT C / E

C｜資料流中的第k大

每讀進一筆就要回報目前第k大，不能等全部輸入後只排序一次。維持至多k個最大值的最小堆，資料不足k筆時輸出指定標記；足夠時堆頂就是所需排名。這延伸了靜態前k大，但多了每一步輸出與早期資料不足的邊界。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
import heapq
heap = []
for x in [4, 1, 8]:
    heapq.heappush(heap, x)
    if len(heap) > 2:
        heapq.heappop(heap)
    print('WAIT' if len(heap) < 2 else heap[0])
展開範例結果
WAIT
1
4

UNIT D / E

D｜每件一次的精確計數

計算恰好總和的子集合數時，狀態由最佳價值改成方法數，選與不選兩類要相加。每件最多使用一次，仍需倒序容量，否則一件可能被計入多次。相同重量的不同位置是不同選擇，因此不能去重；正重量讓零總和只有空集合一種。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
ways = [1, 0, 0]
for weight in [1, 1]:
    for total in range(2, weight - 1, -1):
        ways[total] += ways[total - weight]
print(*ways)
展開範例結果
1 2 1

UNIT E / E

E｜有障礙與費用的單向路徑

格子只可向右或向下時，依賴不會形成循環，因此可用列序DP求最低費用，即使費用不相同也不必使用一般最短路演算法。牆格與不可達格保留None，只有合法前驅才產生候選。起點與終點費用都要計入，且起點本身若是牆就沒有路徑。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
dp = [[2, 5], [6, None]]
cost = 1
candidates = [dp[0][1], dp[1][0]]
dp[1][1] = min(candidates) + cost
print(dp[1][1])
展開範例結果
6
