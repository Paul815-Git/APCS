UNIT A / E

A｜選擇排序的一輪

選擇排序在尚未排好部分找最小值，再與該部分第一格交換。一輪只保證新增一個正確位置，不保證剩餘區域有序。尋找最小值時先記索引，整輪搜尋結束才交換；若邊找邊交換，過程和標準選擇排序不同，識讀時容易誤判。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [5, 3, 4, 1]
best = 0
for j in range(1, len(a)):
    if a[j] < a[best]:
        best = j
a[0], a[best] = a[best], a[0]
print(*a)
展開範例結果
1 3 4 5

UNIT B / E

B｜將一個新值插入有序前綴

插入排序先保存待插入值，再把較大的前綴元素逐格右移，最後把保存值放入空位。先保存很重要，否則右移會覆蓋原值。相等值不用右移，新值會落在已有相等值之後；前綴必須事先有序，這個過程才會得到完整有序串列。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [2, 5, 7, 4]
value = a[-1]
j = len(a) - 2
while j >= 0 and a[j] > value:
    a[j + 1] = a[j]
    j -= 1
a[j + 1] = value
print(*a)
展開範例結果
2 4 5 7

UNIT C / E

C｜移動次數與逆序對

一次右移代表前方有一個比目前值大的元素，兩者形成逆序。將每輪右移次數加總，就得到插入排序的搬移量，也等於逆序對數。這裡只計右移，不計保存或最後放回；相等元素不構成逆序，因此比較必須保持嚴格大於。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [3, 1, 2]
shifts = 0
for i in range(1, len(a)):
    value, j = a[i], i - 1
    while j >= 0 and a[j] > value:
        a[j + 1] = a[j]
        j -= 1
        shifts += 1
    a[j + 1] = value
print(shifts)
展開範例結果
2

UNIT D / E

D｜相等紀錄維持原序

穩定排序會保留鍵相等的紀錄原先順序。插入排序若只移動嚴格較大的鍵，已有的同鍵紀錄不會被跨越，因此具有穩定性。若把條件改成大於或等於，雖然分數仍有序，姓名順序卻可能改變；只測數字無法發現這種錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
rows = [('Amy', 2), ('Bob', 2)]
print(rows[0][1] > rows[1][1])
print(rows[0][1] >= rows[1][1])
展開範例結果
False
True

UNIT E / E

E｜停在第幾輪的狀態

排序識讀常問中途串列，不是最終答案。選擇排序完成第 k 輪後，前 k 格已是最小的 k 個值，後面仍可能混亂。要忠實執行指定輪數，不能直接排序整列；當輪數為零時，任何元素都還沒被處理，必須原樣輸出。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = [4, 3, 2, 1]
for i in range(2):
    best = i
    for j in range(i + 1, len(a)):
        if a[j] < a[best]:
            best = j
    a[i], a[best] = a[best], a[i]
print(*a)
展開範例結果
1 2 3 4
