UNIT A / E

A｜每列各有計數器

外層換到下一列時，列內計數必須重新開始；全表合計則應放在外層之前。用變數的生命範圍判斷初始化位置，而不是靠縮排印象。先做一列全符合、下一列全不符合的資料，最容易抓出把前一列答案累積到下一列的錯誤。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for row in [[1, -2], [-3, -4]]:
    count = 0
    for x in row:
        if x > 0:
            count += 1
    print(count)
展開範例結果
1
0

UNIT B / E

B｜每列第一個目標

break 只停止目前所在的那一層迴圈，不會自動結束整個程式。因此每一列都能各找自己的第一個目標。先用負一表示找不到，找到後記錄索引並跳出內層；外層仍要繼續讀下一列，避免少讀輸入而把後面資料錯當別種欄位。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for row in [[4, 4], [1, 4]]:
    for j in range(len(row)):
        if row[j] == 4:
            print(j)
            break
展開範例結果
0
1

UNIT C / E

C｜有序但不能同位置

兩個位置有先後順序時，交換位置會形成另一個結果；禁止同位置只代表排除 i 等於 j。continue 能跳過本輪剩下的工作，但不結束迴圈。先列出兩個位置能產生哪些有序配對，再加入數值條件，避免誤用只計一次的無序配對模板。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for i in range(2):
    for j in range(2):
        if i == j:
            continue
        print(i, j)
展開範例結果
0 1
1 0

UNIT D / E

D｜三角形走訪

內層終點隨外層位置改變，總工作量不一定是矩形。本題每一列只累加主對角線及右側，條件是欄索引不小於列索引。先畫出小方陣並標記選取位置，再把標記改成 range；這樣能清楚知道對角線是否包括，且不會重複計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
for i in range(2):
    for j in range(i, 2):
        print(i, j)
展開範例結果
0 0
0 1
1 1

UNIT E / E

E｜找最早的下降位置

當題目指定依序找第一筆，走訪順序就是答案規則的一部分。外層讀取每列，內層比較相鄰元素；找到後仍需讀完剩餘輸入，但不應覆蓋先前答案。用尚未找到的旗標區分讀取工作與搜尋工作，可以避免誤以為停止搜尋就能停止讀資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
row = [2, 5, 3]
for j in range(1, len(row)):
    if row[j] < row[j-1]:
        print(j)
        break
展開範例結果
2
