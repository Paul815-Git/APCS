UNIT A / E

A｜數一數換了幾段

相同字元只要被別的字元隔開，就屬於不同片段，不能用集合大小代替。非空字串先有第一段，從第二個字元開始，只在它與前一字元不同時加一。這個判斷把每個段首恰好計入一次，也避免把同一段的每個字元都當成新段。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s = "aabbaa"
runs = 1
for i in range(1, len(s)):
    if s[i] != s[i-1]:
        runs += 1
print(runs)
展開範例結果
3

UNIT B / E

B｜寫出每段的字元與長度

壓縮時需要同時記住目前字元與目前長度。遇到不同字元，先輸出已完成的片段，再把新字元設為長度一。迴圈結束不會再遇到「不同字元」，因此最後一段必須另外輸出。輸出格式中的冒號只是分隔符，不參與長度計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
ch = "b"
length = 3
print(ch + ":" + str(length))

UNIT C / E

C｜最長成功片段的最早起點

除了最長連續成功的長度，也要記住這一段從哪裡開始。讀到1且目前長度為零時，位置就是新段首；只有長度嚴格超過最佳值才更新答案，平手就保留較早的一段。遇到0只清除目前長度，不清除最佳紀錄；完全沒有成功時，起點與長度都用零表示。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
best_length, best_start = 2, 1
current_length, current_start = 2, 4
if current_length > best_length:
    best_length, best_start = current_length, current_start
print(best_start, best_length)
展開範例結果
1 2

UNIT D / E

D｜空字串也能去除相鄰重複

直接讀s[0]的寫法要求資料非空；允許空字串時可以改用結果串列保存段首。讀入字元後，若結果為空或字元與最後保存的字元不同，就加入結果。or會在左邊已成立時停止判斷，因此空串列不會被讀取[-1]，這也是邊界處理的一部分。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
out = []
for ch in "xxxyyx":
    if not out or out[-1] != ch:
        out.append(ch)
print("".join(out))
展開範例結果
xyx

UNIT E / E

E｜符合長度的感測片段

片段概念也適用於整數序列。這次要計算達到指定長度的片段數，必須在片段完成時才判斷，而不是長度每增加一次就加答案。先把相鄰相同值歸成一段，再用門檻篩選；同一數值在不同位置形成的片段仍分開計算。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
lengths = [2, 1, 3]
answer = 0
for length in lengths:
    if length >= 2:
        answer += 1
print(answer)
展開範例結果
2
