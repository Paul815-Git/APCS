UNIT A / E

A｜字母種類的交集

字元總數與不同字母種類是兩種問題。先統一大小寫再建立集合，才能把大小寫視為同一種；兩個集合交集只保留雙方都有的字母。輸出排序使結果固定，而空交集必須印題目指定文字，不能直接列印集合造成不可預期的呈現方式。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a = set("AaB".lower())
b = set("bc".lower())
print("".join(sorted(a & b)))
展開範例結果
b

UNIT B / E

B｜出現片段的個數

連續同字只算一段，因此每段的第一個位置才增加答案。掃描目標字時，同時檢查它是否在字串開頭，或前一字不是目標。開頭條件放在 or 左側，才能保護前一格索引，也清楚表示第一格不需要真的有前一字；空字串則自然沒有任何段。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
s, target = "aaabaa", "a"
count = 0
for i in range(len(s)):
    if s[i] == target and (i == 0 or s[i-1] != target):
        count += 1
print(count)
展開範例結果
2

UNIT C / E

C｜忽略大小寫的單字榜

本題的切分單位是空白分隔的單字，不是字元。split 不給參數會合併連續空白，再把每個單字轉小寫後統計。排序規則分成次數遞減及字母遞增兩層，使用具名排序函式可以明確表達；空輸入則直接印出沒有單字的指定標記。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
words = "Tea  tea MILK".lower().split()
print(words.count("tea"))
展開範例結果
2

UNIT D / E

D｜多出與缺少的字

要把一份字元庫存變成另一份，應逐字比較次數，而不是只比較不同字母集合。某字在來源多出就要刪除，在目標不足就要加入；把各字差值的絕對值相加就是最少新增刪除次數。交換順序不花成本，所以兩行字母排列不同但頻率相同時答案為零。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
left = {"a": 2, "b": 1}
right = {"a": 1, "b": 2}
print(abs(left["a"]-right["a"]) + abs(left["b"]-right["b"]))
展開範例結果
2

UNIT E / E

E｜最短完整單字

題目要從實際單字中選擇答案，不能只計算最短長度，因為還有同長度時選字母較小者的規則。使用長度及單字構成排序鍵，便可同時表達兩個條件。所有單字先轉小寫再比較，避免大小寫編碼順序意外影響答案；本題保證至少一個單字。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def key(word):
    return (len(word), word)
print(min(["pear", "tea", "ant"], key=key))
展開範例結果
ant
