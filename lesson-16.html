遞增與遞減

sorted(nums,reverse=True) 回傳遞減排列。nums.sort() 則直接修改原串列，回傳 None；不要寫 nums=nums.sort()。本課統一用 sorted，保留原資料。

範例 · 先預測，再核對
nums = [2, 9, 4]
print(*sorted(nums, reverse=True))
print(*nums)
展開範例結果
9 4 2
2 9 4

key 決定比較依據

sorted(words,key=len) 依字串長度排序。長度相同時，Python 的穩定排序保留原先順序。key 傳的是函式本身，不是 len() 的執行結果。

範例 · 先預測，再核對

print(*sorted(words, key=len))
展開範例結果

單元 C / E

用函式指定欄位

記錄可用 [姓名,分數] 表示。定義 key 函式回傳分數，再傳給 sorted。以下例子中 key 函式每次接收一筆記錄。

範例 · 先預測，再核對
def score_of(row):
    return row[1]
rows = [["Amy", 80], ["Bob", 60]]
for row in sorted(rows, key=score_of):
    print(*row)
展開範例結果
Bob 60
Amy 80

單元 D / E

多個排序條件

tuple（元組）可用 (第一條件,第二條件) 表示排序鍵，先比第一項，相同再比第二項。分數取負號可讓高分排前面，姓名保持正向字母序。

範例 · 先預測，再核對
def rank_key(row):
    return (-row[1], row[0])
rows = [["Bob", 80], ["Amy", 80], ["Cat", 90]]
for row in sorted(rows, key=rank_key):
    print(*row)
展開範例結果
Cat 90
Amy 80
Bob 80

單元 E / E

最接近的兩數會相鄰

排好序後，最小差距一定能在相鄰兩數間找到，因為跨過中間值不會比其中相鄰差距更小。如此不用枚舉每一對。排序約 O(n log n)，再走訪約 O(n)。

範例 · 先預測，再核對
nums = sorted([9, 2, 6])
best = nums[1] - nums[0]
for i in range(2, len(nums)):
    gap = nums[i] - nums[i-1]
    if gap < best:
        best = gap
print(best)
展開範例結果
3
