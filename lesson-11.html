單元 A / E

外層一次，內層跑完一輪

外層負責列，內層負責欄。每換一個 r，c 就重新從 1 開始。先在紙上列出 (r,c) 的順序，再看結果。縮排決定指令屬於哪一層。

範例 · 先預測，再核對
for r in range(1, 3):
    for c in range(1, 3):
        print(r, c)
展開範例結果
1 1
1 2
2 1
2 2

單元 B / E

一列組好再輸出

空字串可以逐次加上文字。每列開始時要重新設定 line，內層加字，內層結束後才 print。若在內層 print，便會印出尚未完成的列。

範例 · 先預測，再核對
for r in range(2):
    line = ""
    for c in range(3):
        line += "*"
    print(line)

單元 C / E

內層次數跟著列號變

range 可以使用外層變數。第 1 列做 1 次，第 2 列做 2 次，總次數不再是固定的列數乘欄數。

範例 · 先預測，再核對
for r in range(1, 4):
    line = ""
    for c in range(r):
        line += "+"
    print(line)
展開範例結果
+
++
+++

單元 D / E

枚舉所有有順序的組合

如果兩個選項都可重複選，兩層迴圈會列出所有有序配對。(1,2) 和 (2,1) 是不同結果。先枚舉，再用 if 篩選。

範例 · 先預測，再核對
count = 0
for a in range(1, 4):
    for b in range(1, 4):
        if a + b == 4:
            count += 1
print(count)
展開範例結果
3

單元 E / E

無序配對只選一次

串列中選兩個不同位置時，可令 j 從 i+1 開始。這樣不會選到自己，也不會把同一對顛倒計算。值相同但位置不同仍是不同元素。

範例 · 先預測，再核對
nums = [2, 2, 3]
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):
        print(nums[i], nums[j])
展開範例結果
2 2
2 3
2 3
