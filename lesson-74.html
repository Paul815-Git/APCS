UNIT A / E

A｜每個位置的二選一

對每個位置先決定不選，再決定選，就形成二分選擇樹。當位置等於長度，代表一整組決定已完成，才輸出結果。本題用不可變字串把路徑傳給下一層，每個分支得到自己的新字串；分支順序決定輸出順序，不能把基底提早到最後一個位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def choices(i, n, path):
    if i == n:
        print(path)
        return
    choices(i + 1, n, path + '0')
    choices(i + 1, n, path + '1')
choices(0, 2, '')
展開範例結果
00
01
10
11

UNIT B / E

B｜用回傳值計數葉節點

若只要符合條件的子集合數，不需保存所有選擇字串。把目前總和當參數，走到葉節點時符合目標回傳一，否則回傳零，再把兩個分支數量相加。相同數值的不同位置仍是不同選擇；目標為零時，空集合也應由正常分支計入。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def count(a, i, total, target):
    if i == len(a):
        return 1 if total == target else 0
    return count(a, i + 1, total, target) + count(a, i + 1, total + a[i], target)
print(count([1, 1, 2], 0, 0, 2))
展開範例結果
2

UNIT C / E

C｜共用串列要成對加入與撤回

路徑若使用同一個可變串列，選某位置時 append，處理完該分支後必須 pop，恢復成進入分支前的樣子，這就是回溯。否則後面的兄弟分支會看到不屬於自己的選擇。本題輸出索引，讓相同數值也能區分不同位置。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
path = [1]
path.append(3)
print(*path)
path.pop()
print(*path)

UNIT D / E

D｜禁止相鄰選擇的狀態

如果是否能選目前位置取決於前一格，只傳位置還不夠，必須再記錄前一格有沒有選。跳過目前格後，下一層的前一格狀態就是未選；選取後則是已選。這項限制只排除不合法分支，不會漏掉合法選法，因為每格仍只做一次決定。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def ways(left, previous):
    if left == 0:
        return 1
    total = ways(left - 1, False)
    if not previous:
        total += ways(left - 1, True)
    return total
print(ways(3, False))
展開範例結果
5

UNIT E / E

E｜正重量才能安全剪枝

總重量已超過容量時，若剩下所有重量皆為正，再選任何物品都不可能回到合法範圍，因此可以停止整個分支。這個剪枝依賴正重量前提，若存在負數就不成立。仍然先定義完整選或不選搜尋，再加上能證明安全的提前返回。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def best(a, i, total, cap):
    if total > cap:
        return -1
    if i == len(a):
        return total
    return max(best(a, i + 1, total, cap), best(a, i + 1, total + a[i], cap))
print(best([3, 5, 6], 0, 0, 8))
展開範例結果
8
