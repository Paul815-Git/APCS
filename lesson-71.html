UNIT A / E

A｜先停止，再縮小

遞迴是函式在執行中呼叫自己，但每次參數要更接近停止條件，稱為基底。倒數到零時直接 return，讓這次呼叫結束，不再呼叫下一層。少了基底或參數沒有變小就會持續呼叫。本課輸入很小，先理解流程，不用調整系統的遞迴深度限制。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def countdown(n):
    if n == 0:
        return
    print(n)
    countdown(n - 1)
countdown(3)
展開範例結果
3
2
1

UNIT B / E

B｜回傳值等待小問題

呼叫下一層後，外層會等待它回傳，再完成自己的運算。計算一到 n 的和，可以把答案寫成 n 加上一到 n-1 的和，零的答案是零。print 只把內容顯示出來，不能代替 return；要讓上一層取得數值，每個有結果的分支都必須回傳。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def total(n):
    if n == 0:
        return 0
    return n + total(n - 1)
print(total(4))
展開範例結果
10

UNIT C / E

C｜每層移除一個位數

縮小問題不一定是減一。非負整數除以十取商會移除最後一位，餘數則是最後一位的值。因此位數和可拆成最後一位加上其餘位數的和，遞迴深度只與位數有關。零的基底直接回傳零，避免以字串長度或特殊迴圈補救。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def digit_sum(n):
    if n == 0:
        return 0
    return n % 10 + digit_sum(n // 10)
print(digit_sum(407))
展開範例結果
11

UNIT D / E

D｜乘法的空次數

乘方可以定義成重複相乘，但零次方的基底應回傳一，因為一是乘法的起始單位。若誤寫成零，後面所有乘積都會變零。每層將指數減一，底數保持不變；本題也明確約定零的零次方為一，讓邊界符合相同程式定義。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def power(a, k):
    if k == 0:
        return 1
    return a * power(a, k - 1)
print(power(3, 3))
print(power(0, 0))
展開範例結果
27
1

UNIT E / E

E｜索引描述剩餘片段

處理串列時，可讓參數 i 表示還沒處理部分的起點。基底是 i 等於長度，表示已沒有元素；其他情況處理 a[i] 再交給 i+1。這樣不用每層複製切片，也不修改原串列。範例的 X if 條件 else Y 是條件運算式，成立取X，否則取Y。先寫清楚函式回傳的是從目前位置到尾端的結果。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def count_positive(a, i):
    if i == len(a):
        return 0
    flag = 1 if a[i] > 0 else 0
    return flag + count_positive(a, i + 1)
print(count_positive([-1, 0, 4, 2], 0))
展開範例結果
2
