單元 A / E

鍵與值

字典用 key 找 value，例如商品名稱找價格。{} 建立字典；d[key]=value 新增或更新。鍵不在字典內時直接 d[key] 會出錯，可先用 in 判斷。

範例 · 先預測，再核對
price = {"tea": 20, "milk": 30}
print(price["tea"])
price["tea"] = 25
print(price["tea"])
展開範例結果
20
25

單元 B / E

get 提供預設值

d.get(key,0) 在 key 不存在時回傳 0，不會自動新增。配合賦值 d[key]=d.get(key,0)+1，就能建立次數表。

範例 · 先預測，再核對
count = {}
for ch in "aba":
    count[ch] = count.get(ch, 0) + 1
print(count["a"])
print(count.get("z", 0))
展開範例結果
2
0

單元 C / E

多次查詢不必每次重數

先走訪全部資料建立字典，再回答多個查詢。建立一次計數表，可以避免每個查詢都重新掃描完整文字。

範例 · 先預測，再核對
count = {}
for word in ["tea", "milk", "tea"]:
    count[word] = count.get(word, 0) + 1
for word in ["tea", "water"]:
    print(count.get(word, 0))
展開範例結果
2
0

單元 D / E

指定輸出順序

字典記錄順序不代表字母排序。sorted(d) 會取得排序後的鍵；逐一輸出 key 和 d[key]。本課限定小寫英文字，使用 Python 字串排序。

範例 · 先預測，再核對
d = {"pear": 2, "apple": 3}
for key in sorted(d):
    print(key, d[key])
展開範例結果
apple 3
pear 2

單元 E / E

同分時也要有規則

最大次數可能不只一個字。先把鍵排序，再只在次數嚴格更大時更新，便能讓字母順序較前者在同分時保留。

範例 · 先預測，再核對
d = {"b": 2, "a": 2}
best = ""
best_count = -1
for key in sorted(d):
    if d[key] > best_count:
        best, best_count = key, d[key]
print(best, best_count)
展開範例結果
a 2
