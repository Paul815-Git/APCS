UNIT A / E

A｜平面上的絕對方向

先固定座標約定才能正確模擬：本題x向東增加、y向北增加，因此北移改y，東移改x。每個指令是一個位移向量，位置就是目前值加位移。這種數學座標與矩陣列號向下增加的慣例不同，不能看到N就直接搬用矩陣的列位移。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
x, y = 0, 0
move = {"N": (0, 1), "E": (1, 0)}
for ch in "NEN":
    dx, dy = move[ch]
    x += dx
    y += dy
print(x, y)
展開範例結果
1 2

UNIT B / E

B｜朝向與前進分開存

方向按照北、東、南、西排成循環，用0到3表示。右轉增加一，左轉減少一，再對4取餘數；轉向只改方向，不改座標。前進時才按照目前方向取得位移。分開保存位置與方向，可以避免把「朝東」誤解成「已經向東移動一步」。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
direction = 0
direction = (direction + 1) % 4
print("NESW"[direction])
direction = (direction - 1) % 4
print("NESW"[direction])

UNIT C / E

C｜超出邊界就拒絕移動

有邊界時先計算候選位置，確認合法後才寫回目前位置。若先移動再補救，容易只修正一個座標或忘記保留原狀。矩形寬w、高h的合法座標是0≤x<w且0≤y<h，右上角是(w-1,h-1)，不是(w,h)，兩個維度都要檢查。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
x, y = 0, 0
nx, ny = x - 1, y
if 0 <= nx < 3 and 0 <= ny < 2:
    x, y = nx, ny
print(x, y)
展開範例結果
0 0

UNIT D / E

D｜起點也是一個走過的位置

集合適合記錄曾經出現的座標，重走不會增加集合大小。座標要用不可變的tuple，例如(x,y)，才能放進集合；串列[x,y]不能作集合元素。起點在讀指令之前就已走過，必須先加入，這樣空指令或繞回起點時才會得到正確數量。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
visited = {(0, 0)}
visited.add((1, 0))
visited.add((0, 0))
print(len(visited))
展開範例結果
2

UNIT E / E

E｜轉彎不受邊界限制

整合方向與邊界時，各指令的有效條件不同：轉向永遠成功，只有前進需要檢查候選位置。被邊界擋住的前進不改位置，也不改方向，但可以增加失敗次數。將這些規則逐一放入對應分支，比在所有指令之後統一處理邊界更容易維持正確狀態。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
direction = 0
blocked = 0
# 面向北、位在最北列，前進被拒絕。
blocked += 1
direction = (direction + 1) % 4
print("NESW"[direction], blocked)
展開範例結果
E 1
