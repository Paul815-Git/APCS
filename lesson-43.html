UNIT A / E

A｜完整列出因數

正整數d若能讓n除以d的餘數為零，就是n的因數。先用從一到n的完整掃描建立正確基準，輸出自然已遞增。這個方法容易理解但工作量與n成正比，所以只適用小範圍；後續縮減搜尋前，可以用它檢查新方法的結果是否一致。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 6
for d in range(1, n+1):
    if n % d == 0:
        print(d)
展開範例結果

2
3

UNIT B / E

B｜成對因數與平方數

若d是因數，n//d也是因數；當兩者不同可一次計入兩個。每對因數至少有一個不大於平方根，所以只需測試d*d≤n。完全平方數在平方根處兩個因數相同，只能計一次。使用整數乘法判斷上限，可以避免浮點平方根的精度疑慮。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n, d = 9, 3
print(d, n // d)
print(d == n // d)
展開範例結果
3 3
True

UNIT C / E

C｜找到一個因數就能否定質數

質數必須大於一，而且除了1與自己外沒有因數。若合數有一對非平凡因數，其中至少一個不超過平方根，因此試除到平方根就足夠。找到第一個可整除的d即可停止，因為後面是否還有因數都不會改變「不是質數」的答案，這與列出全部因數的任務不同。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 15
prime = n >= 2
d = 2
while d * d <= n:
    if n % d == 0:
        prime = False
        break
    d += 1
print(prime)
展開範例結果
False

UNIT D / E

D｜最小非平凡因數的特殊值

最小因數題需要先定義1的輸出，因為1沒有大於一的因數。對n≥2，先假設答案為n；若從二開始找到更小因數，就立即回傳。試除結束仍沒找到時，n是質數，最小的大於一因數就是它自己。不同題目的「無解」定義不能混用。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
n = 17
answer = n
d = 2
while d*d <= n:
    if n % d == 0:
        answer = d
        break
    d += 1
print(answer)
展開範例結果
17

UNIT E / E

E｜多筆數字的質數統計

把單筆質數判斷包成回傳布林值的函式，主程式就能專心統計多筆資料。函式遇到n<2或找到因數即可return False，掃描完成才return True。重複數值仍代表不同輸入紀錄，必須分別計數；本題資料量不大，逐筆試除足夠，下一課程段再處理大量範圍查詢。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
def at_least_two(n):
    return n >= 2
count = 0
for n in [0, 2, 2]:
    if at_least_two(n):
        count += 1
print(count)
展開範例結果
2
