UNIT A / E

A｜門檻與整數折扣

先區分滿額前與滿額後的規則，再確認金額如何取整。當題目說「總價乘9後整除10」，就應直接用整數計算，不自行改為四捨五入。門檻恰好相等必須屬於滿額分支，測試時用門檻前後各一個值。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
total=101
print(total*9//10)
展開範例結果
90

UNIT B / E

B｜分段收費不是整批改價

分段收費的每一段分別計算，例如前10單位與超過10的單位使用不同單價。不能因總量超過門檻就把前面的單位也改成新價格。先用10與11手算，比較兩個答案應只差一個後段單位價格。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
amount=12
first=min(amount,10)
extra=max(0,amount-10)
print(first*3+extra*5)
展開範例結果
40

UNIT C / E

C｜同分規則也屬於題意

排名題要先確定比較順序，不是看到最高總分就停止。先比總分，再比某一科，最後用編號作唯一決定。把三個比較條件放進tuple，逐欄比較能避免複雜的巢狀if。本題只找第一名，不必排序所有資料。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
first=(150,80,-2)
second=(150,75,-1)
print(first>second)
展開範例結果
True

UNIT D / E

D｜文字座標與程式索引

第12課內部座標從0開始，但題目可能用第1列、第1欄。輸入後統一減1，比在每個存取處臨時修正容易檢查。輸出只需值，不要額外印出座標或矩陣。單列單欄能檢查轉換是否少減或多減一次。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
a=[[7,8],[9,10]]
r,c=2,1
print(a[r-1][c-1])
展開範例結果
9

UNIT E / E

E｜接受或拒絕的交易

模擬規格要分清「嘗試更新」與「更新成功」。餘額不夠時，這筆交易完全不發生，不能先扣完再把負數歸零。每一筆都要輸出狀態，使手算可逐步對照，而不只看最後結果。剛好扣到0仍然合法。

先手算輸出，追蹤關鍵變數，再展開結果核對；能說明原因後才開始練習。

教學範例 · Python
balance=5
x=-6
if balance+x>=0:
    balance+=x
print(balance)
展開範例結果
5
